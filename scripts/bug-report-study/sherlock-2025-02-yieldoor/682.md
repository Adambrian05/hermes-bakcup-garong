# The decimal of the usdValue returned by the function _calculateTokenValues is not 18, which is different from the decimal of minBorrow.

### Summary

When the function openLeveragedPosition is called, the USD value of the initial collateral is calculated and required to be above minBorrow (> 1e18). 

```solidity
    function _checkWithinlimits(Position memory up) internal {
        VaultParams memory vp = vaultParams[up.vault];
        (uint256 maxIndividualBorrow, uint256 maxLevTimes) =
            ILendingPool(lendingPool).getLeverageParams(up.denomination);

        uint256 positionLeverage = (up.initCollateralValue + up.borrowedAmount) * 1e18 / up.initCollateralValue;

        require(up.initBorrowedUsd >= minBorrow, "position must be at least minBorrow amount");
```

However, since the number of decimals in the USD value returned by the function _calculateTokenValues ​​is 8 (which is the number of decimals in the price returned by chainlink), the collateral  USD value will not be greater than minBorrow, causing the DOS of function openLeveragedPosition.

### Root Cause

The USD value returned by the function _calculateTokenValues ​​is not scaled to 1e18.
