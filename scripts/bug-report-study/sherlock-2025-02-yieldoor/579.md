# Incorrect `tickUpper` is used to collect the position fees for vesting position.

### Summary

In [`Strategy.sol:167`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167), `mainPosition.tickUpper` is used instead of `vestPosition.tickUpper` to collect the position fees for the vesting position, resulting in an incorrect calculation of the position fees.

### Root Cause

In [`Strategy.sol:167`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167), when collecting the position fees for the vesting position, the `tickUpper` parameter is wrongly passed as `mainPosition.tickUpper`, while in fact it should be `vestPosition.tickUpper`, thus resulting in an incorrect calculation of the position fees.

```solidity
// Strategy.sol: collectFees()

        if (ongoingVestingPosition) {
167:        collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
        }
```
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L166-L168
