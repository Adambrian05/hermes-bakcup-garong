# Incorrect calculation of `LinearInterest` in the `InterestRateUtils::calculateLinearInterest` function.

## summary 
the `InterestRateUtils::calculateLinearInterest` function will return Incorrect  value of `LinearInterest`.

## Bug Description:

The `calculateLinearInterest` function returns the interest accumulated over the time period between `lastUpdateTimestamp` and `block.timestamp`.

It uses the `rate` variable to calculate the interest accumulated and the time difference between  `lastUpdateTimestamp` and `block.timestamp`.

Now in the function the `PRECISION ` value is added in the denominator which is wrong since the 
SECONDS_PER_YEAR = 31536000 and PRECISION  = 1e27.
SECONDS_PER_YEAR + PRECISION  = 1000000000000000000031536000.

Adding the `PRECISION` value to `SECONDS_PER_YEAR` will make `SECONDS_PER_YEAR` irrelevant.
The interest is calculated based on time. If the interest rate is 10% per year, it means the interest amount will be 10% of the principal amount in one year.

```solidity
function calculateLinearInterest(uint256 rate, uint40 lastUpdateTimestamp) internal view returns (uint256) {
        //solium-disable-next-line
        uint256 timeDifference = block.timestamp - (uint256(lastUpdateTimestamp));

@>>        return rate * (timeDifference) / (SECONDS_PER_YEAR) + PRECISION;
    }
```

## Impact :- 
An incorrect interest amount will be calculated, and the time factor for interest will vanish since the value of `SECONDS_PER_YEAR` is very low compared to `PRECISION`.
The interest is calculated based on time. If the interest rate is 10% per year, it means the interest amount will be 10% of the principal amount in one year.
Adding the `PRECISION` value to `SECONDS_PER_YEAR` will make `SECONDS_PER_YEAR` irrelevant.

## Mitigation :- 
If the `rate` does not contain `PRECISION`, multiply `PRECISION` with it and remove `PRECISION` from the denominator to prevent the interest value for periods shorter than a year from rounding to zero.
If the  `rate` contain `PRECISION just remove the `PRECISION` from the denominator.
