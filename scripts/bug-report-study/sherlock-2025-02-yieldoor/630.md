# Missing rebalance for VestingPosition

### Summary

Since when VestingPosition is created by the owner it has same ticks as main position so it can accrue funds but if ticks gets changed from rebalance because current position liquidity is not really getting used. It updates only the ticks for the mainPosition and SecondPosition. Rebalance doensn't update the ticks for VestingPosition which will cause VestingPosition liquidity to now accrue any fees
