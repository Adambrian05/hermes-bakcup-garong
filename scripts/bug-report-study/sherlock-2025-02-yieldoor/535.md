# Wrong code implementation will DOS users when they try to withdraw from the leverager

### Summary

Setting `repayFromWithdraw` as `amountOut0` in the elif block when the borrowed token is `up.token1` will cause users to be unable to withdraw their tokens and pay off their debt.

### Root Cause

In [Leverager.sol::232](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L232), `repayFromWithdraw` is set to `amountOut0` when `amountOut1 < owedAmount`. This will cause the transaction to revert with underflow error in the next lines, when the condition is met and `amountOut0` is greater than either `amountOut1` or `owedAmount`

### Internal Pre-conditions

NIL

### External Pre-conditions

The returned token ratio from the pool should be such that `amountOut1 < owedAmount`

### Attack Path

Let's take a weth/usdc pool with usdc as denomination token: 
1. User successfully opens a leveraged position:
-  10 weth (1e19) and 25,000 usdc (25,000e6) with 2.5x leverage
- Borrowed amount of 15,000 usdc (15,000e6) 
2. As the tick trends higher, the amount of usdc available in the uniswap pool position decreases, while the weth amount increases
3. At some point, when the user tries to withdraw and pay off 100% of their loan, the usdc amount returned will be less than 15,000e6, lets say 13,000e6
4. This will satisfy the ternary operator condition and cause `repayFromWithdraw` to be set to the returned weth amount, which would be at least 1e19
5. Basically causing an underflow error in the next lines
- `owedAmount -= repayFromWithdraw;`, 15,000e6 - 1e19
-  `amountOut1 -= repayFromWithdraw;`, 13,000e6 - 1e19

### Impact

The user is unable to withdraw their tokens in a timely manner, suffering loss of funds due to accumulated borrowing interest as time goes on. If this happens on a large scale, lps for the lending pool would also be unable to redeem their tokens.

if (borrowed == up.token0) {
            uint256 repayFromWithdraw = amountOut0 < owedAmount ? amountOut0 : owedAmount;
            owedAmount -= repayFromWithdraw;
            amountOut0 -= repayFromWithdraw;
        } else if (borrowed == up.token1) {
-           uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut0 : owedAmount;
+          uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut1 : owedAmount;
