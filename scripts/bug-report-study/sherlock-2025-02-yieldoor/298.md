# Users pay interest for deactivation period


### Root Cause

Owner can active or deactive an asset and when an asset is deactive every function which uses`LendingPool::getReserve` will be reverted because of this line
```solidity
    function getReserve(address asset) internal view returns (DataTypes.ReserveData storage reserve) {
        reserve = reserves[asset];
    @>>>    require(reserve.getActive(), "reserve is not active");
    }
```
and `LendingPool::getReserve` is used by `LendingPool::deposit`, `LendingPool::borrow`, `LendingPool::repay`, `LendingPool::redeem` which are main functions in lendingPool but main point here is interest rate will be increased when an asset is deactive

### Internal Condition

Owner deactive TokenA

### Impact

Users cannot call `Leverager::withdraw` because `LendingPool::repay` will be reverted . hence, they should wait until owner actives the asset again and there is two important impact here:

1-When owner active the asset again they pay interest for deactivation period also because of this line

2-consider to update lastUpdateTimestamp when owner want to active the asset again in `ReserveLogic::setActive`
