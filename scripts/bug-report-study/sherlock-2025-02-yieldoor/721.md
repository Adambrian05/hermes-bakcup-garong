# Stale Debt Valuation Leads to Potential Undercollateralization

### Summary

The [`withdraw`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L209) function in the Leverager contract uses a static initial borrowed USD value, failing to adjust for real-time market price changes during partial withdrawals. This can lead to systematically undercollateralized positions and potential bad debt.

### Root Cause

In `Leverager.sol`, the partial withdrawal mechanism uses a naive linear reduction of initial borrowed USD:

```solidity
positions[wp.id].initBorrowedUsd -= (up.initBorrowedUsd * wp.pctWithdraw) / 1e18;
positions[wp.id].initCollateralValue -= (up.initCollateralValue * wp.pctWithdraw) / 1e18;
```

### Internal Pre-conditions

1. Position must be opened with borrowed assets
2. Significant price volatility exists
3. Partial withdrawal mechanism active

### External Pre-conditions

1. Price oracle provides real-time price updates
2. Sufficient market liquidity
3. Notable price divergence possible

### Attack Path

1. Open a leveraged position
2. Wait for borrowed asset price to increase
3. Perform partial withdrawal
4. Exploit undervalued remaining debt
5. Create systematically undercollateralized positions

### Impact

- Positions remain incorrectly collateralized
- Potential accumulation of bad debt
- Risk of protocol insolvency
- Attackers can create underwater positions

### PoC


```solidity
function test_staleDebtAccounting() public {
    vm.startPrank(depositor);
    ILeverager.LeverageParams memory lp;
    lp.amount0In = 0.5e8;
    lp.amount1In = 50_000e6;
    lp.vault0In = 1e8;
    lp.vault1In = 100_000e6;
    lp.vault = vault;
    lp.maxBorrowAmount = 200e18;
    lp.denomination = address(weth);

    deal(address(wbtc), depositor, 0.5e8);
    deal(address(usdc), depositor, 50_000e6);
    wbtc.approve(leverager, type(uint256).max);
    usdc.approve(leverager, type(uint256).max);

    uint256 posId = ILeverager(leverager).openLeveragedPosition(lp);

    MockOracle(wethOracle).setPrice(2500e18);
    uint256 initialBorrowedUsd = ILeverager(leverager).getPosition(posId).initBorrowedUsd;

    MockOracle(wethOracle).setPrice(6000e18);

    ILeverager.WithdrawParams memory wp;
    wp.id = posId;
    wp.pctWithdraw = 0.5e18;

    deal(address(weth), depositor, 300e18);
    weth.approve(leverager, type(uint256).max);

    ILeverager(leverager).withdraw(wp);

    Position memory remainingPosition = ILeverager(leverager).getPosition(posId);
    
    uint256 currentBorrowedUsdValue = remainingPosition.borrowedAmount 
        * IPriceFeed(priceFeed).getPrice(address(weth)) 
        / (10 ** ERC20(lp.denomination).decimals());

    assertGt(currentBorrowedUsdValue, remainingPosition.initBorrowedUsd);
}
```


### Mitigation

1. Implement real-time debt valuation during withdrawals
2. Use current market prices for debt accounting
3. Add dynamic collateralization checks
