# Liquidity in vesting position can be lost

### Summary

Implementation mistake in the function `Strategy::collectFees()` will cause the liquidity in the vesting position can be lost

### Root Cause

The [function `collectFees()`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L159) collects positions fees. However, it is incorrect that it uses vesting position's lower tick with main position's upper tick together to claim fees for vesting position.

Indeed, at creation the vesting position has the same ticks as the main position. But the value `mainPosition.tickUpper` can be updated after rebalancing, this can cause the call `collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper)` unable to claim vesting position fees

```solidity
    function collectFees() public {
        (uint256 preBal0, uint256 preBal1) = idleBalances();

        if (mainPosition.liquidity != 0) collectPositionFees(mainPosition.tickLower, mainPosition.tickUpper);
        if (secondaryPosition.liquidity != 0) {
            collectPositionFees(secondaryPosition.tickLower, secondaryPosition.tickUpper);
        }
        if (ongoingVestingPosition) {
@>            collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper); // <-- incorrect upper tick
        }

        (uint256 afterBal0, uint256 afterBal1) = idleBalances();

        uint256 protocolFees0 = (afterBal0 - preBal0) * protocolFee / 10_000;
        uint256 protocolFees1 = (afterBal1 - preBal1) * protocolFee / 10_000;

        if (protocolFees0 > 0) IERC20(token0).safeTransfer(feeRecipient, protocolFees0);
        if (protocolFees1 > 0) IERC20(token1).safeTransfer(feeRecipient, protocolFees1);

        if (ongoingVestingPosition) {
            _withdrawPartOfVestingPosition(); // doing that now, otherwise we'd charge protocol fee for the vested position
        }
    }
```

### Attack Path

1. Vesting position is added by owner
2. Rebalance happens, updating main position ticks
3. From this, fees of vesting position can not be claimed

### Impact

- Lost liquidity of vesting position
