# Users can bypass protocol fee


### Root Cause
Users can open leveraged position through `Leverager::openLeveragedPosition` to deposit borrowed amount to strategy to gain reward but when their collateral worth be less than borrowed amount their position be eligible for liquidation and liquidation bot can liquidate their position but users can withdraw their liquidated position 

Sponsor claims:
>We do not check whether position is liquidateable as we remove collateral and repay debt

but I believe there is loss of funds for protocol because liquidation fee just is paid in `Leverager::liquidatePosition`

### Impact

when the position is eligible for liquidating but total collateral worth is bigger than owed amount a portion of collateral will be paid to fee recipient and when users directly withdraw their liquidated position this causes loss of funds for protocol
```solidity
    function liquidatePosition(LiquidateParams calldata liqParams) external collectFees(liqParams.id) nonReentrant {
        Position memory up = positions[liqParams.id];
        ...

        if (totalValueUSD > borrowedValue) {
            // What % of the amountsOut are profit is calculated by `(totalValueUSD - borrowedUSD) / totalValueUSD`
            // Then, on top of that, we calculate the protocol fee and scale it in 1e18.

            @>>> uint256 protocolFeePct = 1e18 * liquidationFee * (totalValueUSD - borrowedValue) / (totalValueUSD * 10_000);
            uint256 pf0 = protocolFeePct * amount0 / 1e18;
            uint256 pf1 = protocolFeePct * amount1 / 1e18;

            @>>> if (pf0 > 0) IERC20(up.token0).safeTransfer(feeRecipient, pf0);
            @>>> if (pf1 > 0) IERC20(up.token1).safeTransfer(feeRecipient, pf1);
            amount0 -= pf0;
            amount1 -= pf1;
        }
```

### Attack Path
Users can trace their positions and withdraw their assets before liquidation bots

### Mitigation

consider to call `Leverage::isLiquidateable` in `Leverager::withdraw`
