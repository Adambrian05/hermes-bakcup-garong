# Collecting Fees from `vestPosition` May Revert Due to Incorrect `tickUpper` Usage

### Summary

In the `Strategy.collectFees()` function, fees from the `vestPosition` are collected by invoking the `collectPositionFees()` function with two function parameters: `(vestPosition.tickLower, mainPosition.tickUpper)`. The issue lies in the second parameter, `mainPosition.tickUpper`, which is incorrect. It should be replaced with `vestPosition.tickUpper`.

### Root Cause

The function [collectFees()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167) calls `collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper)` to collect fees from the `vestPosition`. However, the second parameter, `mainPosition.tickUpper`, is inappropriate. The correct parameters for `collectPositionFees()` should be the lower and upper ticks of the position from which fees are being collected. Therefore, the second parameter must be `vestPosition.tickUpper` instead of `mainPosition.tickUpper`.

Initially, the `vestPosition` has lower and upper ticks that are equal to those of the `mainPosition`. However, during rebalancing, the upper tick of the `mainPosition` may change. As a result, the upper tick of the `vestPosition` may differ from that of the `mainPosition`. This discrepancy can cause the fee collection from the `vestPosition` to revert, as it attempts to collect fees from a nonexistent position. Consequently, the `collectFees()` function becomes unusable, rendering both the `Vault` and `Leverager` ineffective, as their core functions rely on `Strategy.collectFees()`. For instance, users will be unable to withdraw their funds from the `Vault`.

```solidity
    function collectFees() public {
        (uint256 preBal0, uint256 preBal1) = idleBalances();

        if (mainPosition.liquidity != 0) collectPositionFees(mainPosition.tickLower, mainPosition.tickUpper);
        if (secondaryPosition.liquidity != 0) {
            collectPositionFees(secondaryPosition.tickLower, secondaryPosition.tickUpper);
        }
        if (ongoingVestingPosition) {
167         collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
        }

        (uint256 afterBal0, uint256 afterBal1) = idleBalances();

        uint256 protocolFees0 = (afterBal0 - preBal0) * protocolFee / 10_000;
        uint256 protocolFees1 = (afterBal1 - preBal1) * protocolFee / 10_000;

        if (protocolFees0 > 0) IERC20(token0).safeTransfer(feeRecipient, protocolFees0);
        if (protocolFees1 > 0) IERC20(token1).safeTransfer(feeRecipient, protocolFees1);

        if (ongoingVestingPosition) {
            _withdrawPartOfVestingPosition(); // doing that now, otherwise we'd charge protocol fee for the vested position
        }
    }
```
