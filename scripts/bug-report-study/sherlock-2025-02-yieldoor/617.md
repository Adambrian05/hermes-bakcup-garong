# Impossible to open positions more than 2x leverage

### Summary

When positions are opened, they are capped at 2x leverage although the check allows up to max leverage.


### Root Cause

When positions are first created at last function checks whether they are liquidatable or not which does the check if the `initCollateralValue` is lesser than the `owedAmount`. This means that the total leverage any user can do is capped to 2x because borrowed amount can not be greater than `initCollateralValue` and the leverage is calculated as:
```solidity
uint256 positionLeverage = (up.initCollateralValue + up.borrowedAmount) * 1e18 / up.initCollateralValue;
```
mathematically the leverage can be at most 2x assuming `initialCollateralValue` can not be greater than the `borrowedAmount`.
