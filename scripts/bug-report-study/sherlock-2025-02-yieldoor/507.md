# Missing Borrow Rate Cap in Borrow Function

### Summary

The `borrow()` function does not check the borrow rate before allowing users to borrow assets. While it enforces an available liquidity check, this alone does not prevent extremely high borrow rates caused by high utilization.
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/LendingPool.sol#L296 This line is missing in the borrow function 

### Root Cause

Missing borrow rate check in the borrow function 
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/LendingPool.sol#L296
This omission allows users to take out loans at unstable rates.

### Internal Pre-conditions

Borrowing at any condition even at high rate

### External Pre-conditions

100,000 to 150,00 
exactly like 10,000,000 wei

### Attack Path

Interest rate manipulation by increasing the utilization and trapping borrowers in unstainable debt.

### Impact

Excessive borrow rate
protocol insolvency risk
