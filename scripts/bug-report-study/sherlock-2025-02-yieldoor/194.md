# Precision Loss

### Summary
Although `PRECISION` is set to a large value to prevent loss of precision, there are instances where the amount is divided by the price without applying `PRECISION`.

### Root Cause
In line 447 of the `_calculateTokenValues` function, there is a division by `price`, and the multiplier `PRECISION` is not applied. 
This is because the `price` also has a decimal equal to `PRECISION`.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L445
```solidity
    function _calculateTokenValues(address token0, address token1, uint256 amount0, uint256 amount1, uint256 price)
        internal
        view
        returns (uint256 usdValue)
    {
        ...
        if (chPrice0 == 0) {
            usdValue += (amount0 * price / PRECISION) * chPrice1 / decimals1;
        } else if (chPrice1 == 0) {
447:        usdValue += amount1 * PRECISION / price * chPrice0 / decimals0;
        }

        return usdValue;
    }
```

### PoC
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L399
In the `isLiquidatable` function, the `_calculateTokenValues` function is used to calculate the total collateral amount.

Scenario1:
`decimals0 := 8`(exapmple : wbtc), `decimals1 := 6`(exapmple : usdc), the price of token1 := 1 usd.
In the `_calculateTokenValues` function: `amount1 := 1000e6`, `price := 100,000.01e30`.
Let's assume that there are no pricefeed of `token1`.
In L447, amount1 * PRECISION / price = 1000e6 * 1e30 / 100,000.01e30 = 9999.
However, this actual value = 9999.999.
Therefore, the precision loss is 0.01% (0.1 usd).
As a result, a leverager position can be liquidated even if their position exceeds the collateral by 0.1 usd above the liquidation threshold, resulting in the loss of all remaining collateral.

Scenario2: Let's also consider weird tokens with 2 decimals.
`decimals0 := 8`(exapmple : wbtc), `decimals1 := 2`(exapmple : cUSD, GUSD).
In the `_calculateTokenValues` function: `amount1 := 100,000e2`, `price := 100,000.01e30`.
Let's assume that there are no pricefeed of `token1`.
In L447, amount1 * PRECISION / price = 100,000e2 * 1e30 / 100,000.01e30 = 99.
However, this actual value = 99.99999.
Therefore, the precision loss is 1% (1000 usd) .

### Impact
The collateral is undervalued, and leveraged positions may be liquidated even when they should not be, resulting in the loss of all remaining collateral.
