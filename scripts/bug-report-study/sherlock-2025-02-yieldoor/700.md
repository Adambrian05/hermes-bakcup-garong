# Protocol overcharges borrowers with high interest rates due to approximation errors

### Summary

The compounded interest calculation in `InterestRateUtils.sol` overestimates the actual interest for high annual rates, leading to borrowers being overcharged

### Root Cause

In [InterestRateUtils.sol: calculateCompoundedInterest function](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/libraries/InterestRateUtils.sol?plain=1#L73-L99), the binomial approximation overestimates interest for high rates, e.g., returning 2.664x instead of 2x for 100% APR.

### Internal Pre-conditions

The borrowing rate is set to a high value (e.g., 100% APR).

### External Pre-conditions

None

### Attack Path

1. A borrower takes a loan with a high interest rate.
2. The interest calculation overestimates the actual interest, charging the borrower more than the correct compounded interest.
3. The borrower is overcharged, leading to potential dissatisfaction and financial disputes.

### Impact

Borrowers are overcharged, leading to loss of trust and potential financial disputes, with the protocol gaining extra revenue unsustainably.

### PoC

_No response_

### Mitigation

Implement a more accurate method for calculating compounded interest, such as using a library for precise exponentiation.
