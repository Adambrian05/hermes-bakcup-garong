# Improper Fee Deduction in deposit

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Vault.sol#L48#L72

### Issue:
 If shares * depositFee / 10_000 equals shares, the user gets nothing but still loses funds.
### Severity: medium 
### Impact:
Fund Loss Due to Improper Fee Deduction so it's medium

### POC:
```
Solidity 
vault.setDepositFee(10_000); // 100% fee
vault.deposit(100, 100, 100, 100); // All shares get deducted, user gets nothing.


```

### Fix: 
Prevent shares from becoming zero after fee deduction:

```
Solidity 
uint256 fee = (shares * depositFee) / 10_000;
if (fee >= shares) revert("Deposit fee too high");
shares -= fee;

```
