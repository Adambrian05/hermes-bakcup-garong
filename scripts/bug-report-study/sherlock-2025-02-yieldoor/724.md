# When liquidations are overdue position needs to be fully closed leaving bad debt to grow

### Summary

When a position is liquidatable and not a profitable situation, liquidation up to the amount that is repayable can't be repaid instead the entire liquidation has to be done including the bad debt part. 

### Root Cause

When someone gets liquidated the entire amount needs to be repaid. However, if the account is already in bad debt the liquidators should repay the debt that the collateral can cover and the rest can be deficit that is later repaid. 
https://github.com/sherlock-audit/2025-02-yieldoor/blob/b5a0f779dce4236b02665606adb610099451a51a/yieldoor/src/Leverager.sol#L369

### Internal Pre-conditions

1. Account is underwater, bad debt accruing

### External Pre-conditions

None

### Attack Path

None

### Impact

If the account is already accruing bad debt liquidators must need to repay the entire debt including the bad debt however, this is not ideal and the debt that can be covered by the collateral should be immediately repaid and the bad debt part can be repaid later by the protocol. 

### PoC

None

### Mitigation

Allow to liquidate an account that has bad debt up to maximum collateral amount.
