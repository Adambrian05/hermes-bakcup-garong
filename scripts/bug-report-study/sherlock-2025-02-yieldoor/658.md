# Incorrect calculation for the `repayFromWithdraw` param in the `Leverager` contract

### Summary

Incorrect calculation for the `repayFromWithdraw` param in the `Leverager` contract

### Root Cause
In `Leverager.sol:232`, where the wrong variable `amountOut0` is being used instead of `amountOut1` when calculating `repayFromWithdraw`.

### Internal Pre-conditions

None

### External Pre-conditions

None

### Code snippet
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L232


### Attack Path

1. User calls the `openLeveragedPosition` function
2. User calls the `withdraw` function

### Impact

The protocol and user may receive incorrect token values ​​after calling the `withdraw` function.

### PoC

_No response_
