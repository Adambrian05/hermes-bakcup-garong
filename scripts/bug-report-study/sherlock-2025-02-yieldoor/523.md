# Uninitialized feeRecipient address will cause loss of liquidation fees in the Leverager contract

### Summary

The missing initialization of `feeRecipient` in `Leverager.sol` will cause loss of liquidation fees when liquidator call `liquidatePosition()`.


### Root Cause

In [`Leverager.sol:47`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L47), the `feeRecipient` variable is declared but never initialized. 
In [`Leverager.sol:328`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L328C1-L329C76), the Leverager contract sends liquidation fee to `feeRecipient`.

### Internal Pre-conditions

1. Admin needs to set `liquidationFee` to be greater than 0.

### External Pre-conditions

1. The market needs to be volatile, causing the user's position to be liquidated.

### Attack Path

1. Liquidator needs to call `liquidatePosition()`.
2. A nonzero liquidation fee is collected.


### Impact

The protocol suffers a complete loss of liquidation fee.
