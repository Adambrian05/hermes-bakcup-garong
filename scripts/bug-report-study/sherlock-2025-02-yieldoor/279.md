# The CHAINLINK price decimal in USD is 1e8 rather then 1e18 which makes minBorrow=20e18 is too big

### Summary

The param `minBorrow` in the `Leverager` is set to be 20e18, which is used to check the minimum usd value of debt. However this is base on the assumption that the CHAINLINK price decimal in USD is 1e18. And actually, The CHAINLINK price decimal in USD is 1e8 rather then 1e18 which makes minBorrow=20e18 is too big.

In that way, a user has to open a leveraged position with at 20e12 debt in USD value which is too big.


[Leverager](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L54)
```solidity
    uint256 minBorrow = 20e18;
```



### Root Cause

The assumption on the CHAINLINK price decimal is incorrect.
