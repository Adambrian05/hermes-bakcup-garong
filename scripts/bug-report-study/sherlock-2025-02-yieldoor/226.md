# Unfair Share Distribution for First Depositor

### Summary
- In the Vault contract, the first depositor faces an unfair loss due to the way initial shares are minted. 
- The contract wrongly assigns 1000 shares to a burn address, reducing the shares the first user should receive.
- First depositor loses tokens unfairly – The depositor receives fewer shares than they should.
- Unbalanced share distribution – The burn address holds shares that are not backed by real tokens, causing issues for future depositors.

### Vulnerable Code
When a user makes the first deposit, the contract calculates their shares:
```solidity
if (totalSupply == 0) {
    amount0 = depositAmount0;
    amount1 = depositAmount1;
    shares = (amount0 > amount1 ? amount0 : amount1) - 1000;
    _mint(BURN_ADDRESS, 1000); // Burns 1000 shares unfairly
}
```
- The contract subtracts 1000 from the depositor's shares, making them lose tokens.
- The burn address gets 1000 shares, which do not have real tokens behind them.
- This creates an imbalance where future depositors can get a better deal than the first one.

### Example:

**First Depositor:**
- Deposits 5000 token0 and 4000 token1.
- The contract calculates: shares = 5000 - 1000 = 4000.
- 1000 shares go to burn, leaving only 4000 for the user.
- The user should have received 5000 shares, but they lose 1000.

**Future Depositor:**
- Deposits 5000 token0 and 5000 token1.
- Shares are calculated using a fair formula (proportional allocation).
- They receive the correct number of shares, unlike the first depositor.

### Impact
- High Loss for First Depositor – They lose a big portion of their tokens.
- Unfair Advantage for Later Depositors – Future users receive correct shares, but the first depositor gets fewer.
- Potential Exploit – A malicious user could deposit first, then manipulate deposits to drain funds unfairly

### Recommandation
**Use a Fair Share Calculation-**
- Instead of using max(amount0, amount1) - 1000, use the geometric mean of deposits:
```solidity
if (totalSupply == 0) {
    shares = Math.sqrt(depositAmount0 * depositAmount1); // Fair calculation
} else {
    shares = (depositAmount0 + depositAmount1) / totalSupply; // Normal case
}
```
