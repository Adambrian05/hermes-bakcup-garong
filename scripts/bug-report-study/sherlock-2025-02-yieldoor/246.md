# Fee collection logic will miscalculate fees for vesting position holders

### Summary

The erroneous reference of `mainPosition.tickUpper` instead of `vestPosition.tickUpper` will cause incorrect fee calculation for vesting positions as the fee collection logic will operate over an unintended tick range.

### Root Cause

- In **Strategy.sol:167** there is a mistake where the fee collection for vesting positions calls  
  ```solidity
  collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
  ```  
  instead of referencing the vesting [position’s upper tick](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167). This leads to an incorrect fee collection range.



### Internal Pre-conditions

1. The vesting position must be active with its own distinct tick bounds.  
2. The fee collection function (`collectFees()`) must be invoked while a vesting position exists.  
3. The vesting position’s `tickUpper` value differs from the main position’s `tickUpper`.

### External Pre-conditions

1. No external protocol conditions are required; the vulnerability arises solely from the internal logic of the contract.


### Attack Path

1. A vesting position is initialized with its own `tickLower` and `tickUpper` values.  
2. The fee collection function is executed, triggering a call to `collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper)`.  
3. Due to the incorrect upper tick reference, fees are collected over an unintended range.  
4. This misconfiguration leads to inaccurate fee calculation, potentially resulting in fee misallocation or revenue loss.


### Impact

The vesting position holders suffer from inaccurate fee collection, which may result in either overcharging or undercharging fees. Consequently, the protocol could experience financial discrepancies and eroded user trust due to misallocated fee revenue.


### PoC

```solidity
// Vulnerable code snippet in Strategy.sol around line 167:
function collectFees() public {
    // Incorrectly uses mainPosition.tickUpper instead of vestPosition.tickUpper for vesting position fee collection
    if (ongoingVestingPosition) {
        collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
    }
    // ... rest of the fee collection logic
}

// Corrected version should be:
function collectFees() public {
    if (ongoingVestingPosition) {
        collectPositionFees(vestPosition.tickLower, vestPosition.tickUpper);
    }
    // ... rest of the fee collection logic
}
```
