# calling collectFees will lead to wrong fees collected for vesting positon

### Summary

Use main position's `tickUpper` for collecting vesting positon fees. The vesting positon's `tickUpper` should be used.

### Root Cause

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L166-L168
The `mainPosition.tickUpper` is used to collect vesting position fees. When the vesting positon is added, the `vestPosition.tickUpper` == `mainPosition.tickUppper`. However, when the `rebalance` function is called, the mainPositon's tick will change. After some time, the `vestPosition.tickUpper` != `mainPosition.tickUppper`.

### Internal Pre-conditions

1. Admin call `Vault.sol::addVestingPosition`.
2. `collectFees` is called.

### External Pre-conditions

N/A

### Attack Path

1. Admin call `Vault.sol::addVestingPosition`.
2. `rebalance` is called and the main position is updated.
3. `collectFees` is called.

### Impact

Wrong vesting position fees are collected.

### PoC

_No response_

### Mitigation

```diff
        if (ongoingVestingPosition) {
-            collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
+            collectPositionFees(vestPosition.tickLower, vestPosition.tickUpper);
        }
```
