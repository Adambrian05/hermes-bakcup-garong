# Infinite loop in openLeveragedPosition() when swap path has multiple pools

### Summary

In [Leverager.sol:openLeveragedPosition()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L103) if the amount of token deposited is more than the user provided then denomination token will be swapped to this token. Swap path may include two or more pools. But contract fails to decode data if path has multiple pools because it goes to infinite loop in [_getTokenIn()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L566) where function does not update the path variable.

### Root Cause

In `openLeveragedPosition()` if swap is necessary contract will call `_getTokenIn()` to get `tokenIn`:
```solidity
function openLeveragedPosition(LeverageParams calldata lp) external nonReentrant returns (uint256 _id) {
    ...
    if (a0 > lp.amount0In && up.token0 != lp.denomination) {
        //@audit Decodes the swap parameters for token0
        swapParams = abi.decode(lp.swapParams1, (IMainnetRouter.ExactOutputParams));

        address tokenIn = _getTokenIn(swapParams.path); //@audit get token in
        require(tokenIn == lp.denomination, "token should be denomination");

        IERC20(tokenIn).forceApprove(swapRouter, swapParams.amountInMaximum);

        swapParams.amountOut = a0 - lp.amount0In;
        IMainnetRouter(swapRouter).exactOutput(swapParams);
        IERC20(tokenIn).forceApprove(swapRouter, 0);
    }
    ...
}
```
In `_getTokenIn()` function `path` variable is not updated in the loop, leading to infinite loop if `path.hasMultiplePools() = true`:
```solidity
/// @notice Gets the tokenIn in a exactOutput swap path
function _getTokenIn(bytes memory path) internal pure returns (address) {
    while (path.hasMultiplePools()) {
        path.skipToken(); //@audit skipToken() doesn't modify current path variable so path.hasMultiplePools() always will be true
    }

    (, address tokenIn,) = path.decodeFirstPool();
    return tokenIn;
}
```
[Path.sol:skipToken()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/libraries/Path.sol#L58):
```solidity
function skipToken(bytes memory path) internal pure returns (bytes memory) {
    return path.slice(NEXT_OFFSET, path.length - NEXT_OFFSET);
}
```

### Internal Pre-conditions

_No response_

### External Pre-conditions

1. `path.hasMultiplePools() = true`
2. Amount of `token0` or `token1` deposited to the vault is more than the user provided

### Attack Path

_No response_

### Impact

DoS of `openLeveragedPosition()` function if `path.hasMultiplePools() = true` and amount of `token0` or `token1` deposited to the vault is more than the user provided.

### Mitigation

Update path variable in the loop:
```solidity
function _getTokenIn(bytes memory path) internal pure returns (address) {
    while (path.hasMultiplePools()) {
        path = path.skipToken();
    }
    // ...
}
```
