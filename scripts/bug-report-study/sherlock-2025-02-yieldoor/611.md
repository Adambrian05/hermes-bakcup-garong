# openLeveragePosition may revert due to not collecting fees before `isLiquidatable` check

### Title
openLeveragePosition may revert due to not collecting fees before `isLiquidatable` check

### Severity
Medium

### Difficulty
Low

### Type
Bug

### Target
src/Leverager.sol

## Description
In `Leverage.sol` contract in order to find out whether position is liquidatable or not `Strategy.collectFees` function should be called or modifier `collectFees` modifier added to function before `isLiquidatable` function. However, it not called before check in `openLeveragePosition` function which may revert. 


## Recommendations
Call function collectFees from Strategy contract in order to get more accurate values to check whether position is liquidateable or not.
