# Incorrect calculation of `initCollateralValue` and `positionLeverage` in `Leverager` contract.

### Summary

In `_checkWithinlimits` function, `positionLeverage` is calculated and checked whether is too high.
This calculation is incorrect and this leads to opening too high leverage position.

### Root Cause

In [`_checkWithinlimits`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L459-L467) function, `positionLeverage` is calculated with `initCollateralValue` and `borrowedAmount`, but this logic is incorrect.

```solidity
    function _checkWithinlimits(Position memory up) internal {
        VaultParams memory vp = vaultParams[up.vault];
        (uint256 maxIndividualBorrow, uint256 maxLevTimes) =
            ILendingPool(lendingPool).getLeverageParams(up.denomination);

@>      uint256 positionLeverage = (up.initCollateralValue + up.borrowedAmount) * 1e18 / up.initCollateralValue;

        require(up.initBorrowedUsd >= minBorrow, "position must be at least minBorrow amount");
        require(positionLeverage <= vp.maxTimesLeverage && positionLeverage <= maxLevTimes, "too high x leverage");
        ...
    }
```
Position's `initCollateralValue` is calculated in [`openLeveragedPosition`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L129-L131) function as the worth of position.

```solidity
    function openLeveragedPosition(LeverageParams calldata lp) external nonReentrant returns (uint256 _id) {
        ...

        up.initCollateralUsd = _calculateTokenValues(up.token0, up.token1, a0, a1, price); // returns the USD price in 1e18
        uint256 bPrice = IPriceFeed(pricefeed).getPrice(lp.denomination);
@>      up.initCollateralValue = up.initCollateralUsd * (10 ** ERC20(lp.denomination).decimals()) / bPrice;
        ...
    }
```

[Security Docs](https://docs.google.com/document/d/1FUjXMXBRBRVgOYSMGORTFmS9fj_nh-ifQhoY0jjhwPY) explains a numerical example:
> To put it into a numerical example, user opens up a $1,250 position with $1,000 of collateral (1.25x leverage). User’s position would have to fall below $275 value ($250 borrowed, $25 collateral) in order to become liquidateable. 

In this example, `position.borrowedAmount` is 250 and `position size` is 1250 and `initCollateralValue` is 1000. (Assume that borrow token is usdc.)
But according to current code implementation, `initCollateralValue` is 1250 and `positionLeverage` is calculated as `(1250 + 250) / 1250 = 1.2`.

In short, `initCollateralValue` should be calculated as `worth of position - borrowedAmount` or `positionLeverage` calculation logic should be updated.

### Internal Pre-conditions

No response

### External Pre-conditions

No response

### Attack Path

1. User opens with following values:
`_calculateTokenValues`=1200$, `initBorrowedUsd` = 1000$
2. According to current code implementation, `positionLeverage` is calculated as:
`positionLeverage` = (1200 + 1000) / 1200 = 1.83
3. But real user's collateral is `1200 - 1000 = 200` and real `positionLeverage` is `1200 / 200 = 6`.

### Impact

high leverage position can be opened.

No response

### Mitigation
`initCollateralValue` calculation logic or `positionLeverage` calculation logic should be updated.

1. Update `initCollateralValue` calculation logic:
```diff
    function openLeveragedPosition(LeverageParams calldata lp) external nonReentrant returns (uint256 _id) {
        ...
        up.initCollateralUsd = _calculateTokenValues(up.token0, up.token1, a0, a1, price); // returns the USD price in 1e18
        uint256 bPrice = IPriceFeed(pricefeed).getPrice(lp.denomination);
        up.initCollateralValue = up.initCollateralUsd * (10 ** ERC20(lp.denomination).decimals()) / bPrice;
        ...
        up.borrowedAmount = lp.maxBorrowAmount - denomBalance;
+       up.initCollateralValue -= up.borrowedAmount;
        ...
    }
```

2. Update `positionLeverage` calculation logic:
```diff
    function _checkWithinlimits(Position memory up) internal {
        VaultParams memory vp = vaultParams[up.vault];
        (uint256 maxIndividualBorrow, uint256 maxLevTimes) =
            ILendingPool(lendingPool).getLeverageParams(up.denomination);

-       uint256 positionLeverage = (up.initCollateralValue + up.borrowedAmount) * 1e18 / up.initCollateralValue;
+       uint256 positionLeverage = up.initCollateralValue * 1e18 / (up.initCollateralValue - up.borrowedAmount);
        require(up.initBorrowedUsd >= minBorrow, "position must be at least minBorrow amount");
        require(positionLeverage <= vp.maxTimesLeverage && positionLeverage <= maxLevTimes, "too high x leverage");
        ...
    }
```
