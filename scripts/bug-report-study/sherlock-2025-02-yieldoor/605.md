# Missing check that `borrowed` amount in Usd is above the `max` tokens in  `usd` allowed while `openingLeveragePosition()` and no Setter `Once` is set

### Summary

There is a missing check, while calling `openLeveragedPosition(`, it calculates and updates what a user has borrowed, however the code doesnt check if `borrowed` amount is greater than `vaultParams[vault].maxUsdLeverage = _maxUsdLeverage;`, which is set in the constructor

### Root Cause

In `openLeveragedPosition(`, while opening a `leveraged`, position there, is no check that the amount borrowed in usd is greater than the amount set by the owner which will led to issues if tokens get high in value, allowing users to borrow in big quantities during a bull run.
