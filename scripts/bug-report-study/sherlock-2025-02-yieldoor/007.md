# Attacker will manipulate asset prices to profit

#### Summary
The reliance on external price feeds will cause a financial loss for users as an attacker will manipulate the price feeds to affect the contract's operations.

#### Root Cause
The choice to use external price feeds is a mistake as they can be manipulated, affecting the contract's operations.

#### Internal Pre-conditions
Protocol needs to rely on external price feeds for asset valuation.

#### External Pre-conditions
External price feeds need to be vulnerable to manipulation.

#### Attack Path
1. Attacker manipulates the external price feed.
2. Contract uses the manipulated price feed to calculate asset values.
3. Users suffer financial loss due to incorrect asset valuation.

#### Impact
The users suffer an approximate loss due to the manipulated asset prices. The attacker gains this difference.
