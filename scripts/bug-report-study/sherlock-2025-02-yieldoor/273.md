# Incorrect `collectPositionFees` for Vesting Position

## Description

The vesting position’s fees are collected using mainPosition.tickUpper instead of vestPosition.tickUpper in strategy.sol:167. This means fees are collected from an incorrect tick range (e.g., vestPosition.tickLower to mainPosition.tickUpper).

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167

## Impact

1. Miss fees owed to the vesting position.
2. Collect fees from a range that doesn’t correspond to the vesting position.

## Recommendation

Fix: Update the call to in line strategy.sol:167

```solidity
collectPositionFees(vestPosition.tickLower, vestPosition.tickUpper);
```
