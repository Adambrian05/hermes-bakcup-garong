# Issues with `tickUpper` may cause fee collection from `vestPosition` to fail

### Summary

The `Strategy.collectFees()` function is intended to gather fees from the `vestPosition`. This is done by calling the `collectPositionFees()` function. However, the second parameter, `mainPosition.tickUpper`, is incorrectly used and should be substituted with `vestPosition.tickUpper`.

### Root Cause

In the function `collectFees()`, fees are collected using the line `collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper)`. The problem arises from the second parameter being `mainPosition.tickUpper`, which is not appropriate. The correct parameters for `collectPositionFees()` should include the lower and upper ticks of the position from which fees are being collected, necessitating the use of `vestPosition.tickUpper` instead.

Initially, the `vestPosition` has its lower and upper ticks set identically to those of the `mainPosition`. However, during the rebalancing process, the upper tick of the `mainPosition` can change, potentially leading to a mismatch between the upper ticks of the two positions. This discrepancy can cause the fee collection from the `vestPosition` to fail, as it attempts to collect fees from an empty position.
