# Missing update regarding the path.

### Summary
There is an infinite loop in the `Leverager::_getTokenIn` function.

### Root Cause
In the `_getTokenIn` function, the `path` does not updated.
Therefore, if the `path` contains multiple pools, the loop repeats infinitely.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L568
```solidity
    function _getTokenIn(bytes memory path) internal pure returns (address) {
        while (path.hasMultiplePools()) {
568:        path.skipToken();
        }

        (, address tokenIn,) = path.decodeFirstPool();
        return tokenIn;
    }
```
