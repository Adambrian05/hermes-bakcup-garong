# Main position ticks can be set wrongly

### Summary

Main position ticks are not validated against Univ3 protocol's max tick and min tick can cause the main position to be set incorrectly

### Root Cause

[Function `Strategy::_setMainTicks()`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L232-L244) calculates and sets the ticks of the main position. However, the calculated ticks are not validated against Univ3 protocol's `MIN_TICK` and `MAX_TICK`. This can cause the main position to be invalid.
```solidity
    function _setMainTicks(int24 tick) internal {
        int24 halfWidth = int24(positionWidth / 2);
        int24 modulo = tick % tickSpacing;
        if (modulo < 0) modulo += tickSpacing; // if tick is negative, modulo is also negative
        bool isLowerSided = modulo < (tickSpacing / 2);

        int24 tickBorder = tick - modulo;
        if (!isLowerSided) tickBorder += tickSpacing;
@>        mainPosition.tickLower = tickBorder - halfWidth; // <<--- not validated/adjusted against MIN_TICK
@>        mainPosition.tickUpper = tickBorder + halfWidth; // <<--- not validated/adjusted against MAX_TICK

        emit NewMainTicks(tickBorder - halfWidth, tickBorder + halfWidth);
    }
```

### Internal Pre-conditions

N/A

### External Pre-conditions

- Pool current tick is near the tick range limits `MIN_TICK` or `MAX_TICK`

### Attack Path

N/A

### Impact

- Protocol will be unable to operate due to invalid position ticks

### Mitigation

```diff
    function _setMainTicks(int24 tick) internal {
        int24 halfWidth = int24(positionWidth / 2);
        int24 modulo = tick % tickSpacing;
        if (modulo < 0) modulo += tickSpacing; // if tick is negative, modulo is also negative
        bool isLowerSided = modulo < (tickSpacing / 2);

        int24 tickBorder = tick - modulo;
        if (!isLowerSided) tickBorder += tickSpacing;
-        mainPosition.tickLower = tickBorder - halfWidth;
-        mainPosition.tickUpper = tickBorder + halfWidth;
+        mainPosition.tickLower = tickBorder - halfWidth < TickMath.MIN_TICK ? TickMath.MIN_TICK : tickBorder - halfWidth;
+        mainPosition.tickUpper = tickBorder + halfWidth > TickMath.MAX_TICK ? TickMath.MAX_TICK : tickBorder + halfWidth;

        emit NewMainTicks(tickBorder - halfWidth, tickBorder + halfWidth);
    }
```
