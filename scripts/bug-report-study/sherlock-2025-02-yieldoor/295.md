# The "Sandwich Attack" vulnerability in the Token Swap mechanism.

### Summary

`exactOutput` is a mechanism designed to ensure that the output quantity of a transaction matches a specified value, guaranteeing that the transaction's output (`amountOut`) does not fall below expectations. However, if an attacker can manipulate the order or price of transactions, they may exploit logical vulnerabilities in the contract through a "Sandwich Attack" to profit.

### Root Cause

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L143-L166
This code uses `exactOutput` for token swaps, which means:  
Attackers can leverage MEV bots to insert transactions before and after this transaction, front-running and manipulating prices to make the swap price favorable to the attacker.

### Impact

Attackers manipulate market prices through front-running and back-running trades, significantly increasing the cost of targeted transactions.  
This impacts users and the protocol, leading to unreasonable price fluctuations, increased transaction costs, market instability, and potential losses for the protocol.

### Mitigation

* Implement a "price protection" mechanism by setting a maximum acceptable slippage.  
* Enhanced anti-trade manipulation measures: Introduce transaction delays and strengthen transaction signature verification.  
* Utilize MEV protection mechanisms, such as Flashbots or CoW.
