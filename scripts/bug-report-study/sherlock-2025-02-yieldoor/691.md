# There is no mechanism to add collateral to positions, which results in forced liquidation of positions.

### Summary

The protocol allows users to deposit collateral to open leveraged positions, but does not provide users with the ability to add collateral, which means that leveraged positions will be forced to be liquidated. This could result in large leveraged positions being liquidated in times of market volatility.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L103-L201

### Root Cause

No mechanism to add collateral to positions.

### Internal Pre-conditions

None

### External Pre-conditions

1. Users deposit collateral to open leveraged positions.

### Attack Path

None

### Impact

There is no way for users to add collateral to keep their positions healthy.

### PoC

_No response_

### Mitigation

Add a mechanism to add collateral to positions.
