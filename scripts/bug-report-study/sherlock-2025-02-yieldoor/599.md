# `Strategy::mainPosition` will never be 50/50 when tick spacing is 1

### Summary

When rebalancing the position ticks are calculated within `_setMainTicks`.

```solidity
 function _setMainTicks(int24 tick) internal {
        int24 halfWidth = int24(positionWidth / 2);
        int24 modulo = tick % tickSpacing;
        if (modulo < 0) modulo += tickSpacing; // if tick is negative, modulo is also negative
        bool isLowerSided = modulo < (tickSpacing / 2);

        int24 tickBorder = tick - modulo;
        if (!isLowerSided) tickBorder += tickSpacing;
        mainPosition.tickLower = tickBorder - halfWidth;
        mainPosition.tickUpper = tickBorder + halfWidth;

        emit NewMainTicks(tickBorder - halfWidth, tickBorder + halfWidth);
    }
```

Depending on the current tick the function tries to create an even position:

For example:
- `positionWidth = 200`
- `tick = 16200`
- `tickSpacing = 200`

- `modulo = 0`
- `isLowerSided = true`
- `tickBorder = 16200 = 16200`
- `tickLower = 16000`
- `tickUpper = 16400` 

The position is exactly 50/50 in the current scenario. However, for the lowest tick spacing (1), the position will always be uneven, due to `isLowerSided` always being false. 


### Root Cause

Due to the [isLowerSided](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L236) check not checking for equality every position with tick spacing 1 will be uneven.

### Internal Pre-conditions

1. Tick spacing is 1

### External Pre-conditions

None

### Attack Path

None

### Impact

The Strategy contract will always create un-even position despite being able to create one.

### PoC

       - halfWidth = 2
       - tick  = 50
       - modulo =  50 % 1 = 0`(it will always be zero)
       - isLowerSided = 0 < 0 = false
       - tickBorder = 50 - 0 = 50
       -  since isLowerSided = false -> tickBorder = 50 + 1 = 51
       - lowerTick = 51 - 2 = 49
       - upperTick = 51 + 2 = 53

        This will cause the position to always be uneven, despite it being able to be 48/52.

### Mitigation

Consider checking for equallity on `isLowerSided`

```diff
-      bool isLowerSided = modulo < (tickSpacing / 2);
+      bool isLowerSided = modulo <= (tickSpacing / 2);
```
