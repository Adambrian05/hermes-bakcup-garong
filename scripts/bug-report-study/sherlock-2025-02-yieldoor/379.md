# Incorrect calculation of cached variable in `Leverager::withdraw` function

## Impact
### Summary 
The `Leverager::withdraw` function allows users to withdraw a certain percentage of their leveraged position. However, the cached variable `repayFromWithdraw` is wrongly computed when `borrowed == up.token1` leading to a miscalculation in the amount of asset to be repayed by the user.

### Vulnerability Details

The vulnerability lies on line `232` of `Leverager.sol` where the protocol assigns `amountOut0` as the value of `repayFromWithdraw` instead of `amountOut1` (see [here](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L227-L235)). 
Notice what the function is doing `uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut0 : owedAmount;`. This leads to further miscalculations that depend on the value of `repayFromWithdraw` on subsequent lines that follow.

This vulnerability can also be seen by taking a look at the code snippet below. 


### Impact
Because of the logic error on line `232`, if `amountOut1 < owedAmount` holds true, `repayFromWithdraw` is miscalculated and if `amountOut0 < amountOut1`, the execution proceeds with a miscalculated value. 

If on the other hand `amountOut1 < owedAmount` holds true, but `amountOut0 > amountOut1`, the function will revert on line `234` due to arithmetic overflow or underflow.

## Recommended Mitigation Steps

Consider modifying the `Leverager::withdraw` function so that the `repayFromWithdraw` is calculated correctly as depicted below:

```diff
    function withdraw(WithdrawParams calldata wp) external nonReentrant {
        .
        .
        .

        // In case either of the tokens is denomination token, we directly take from it.
        if (borrowed == up.token0) {
            uint256 repayFromWithdraw = amountOut0 < owedAmount ? amountOut0 : owedAmount;
            owedAmount -= repayFromWithdraw;
            amountOut0 -= repayFromWithdraw;
        } else if (borrowed == up.token1) {
-            uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut0 : owedAmount;
+            uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut1 : owedAmount;
            owedAmount -= repayFromWithdraw;
            amountOut1 -= repayFromWithdraw;
        }
        .
        .
        .
```
