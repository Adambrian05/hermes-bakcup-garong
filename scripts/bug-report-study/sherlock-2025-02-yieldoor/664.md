# Missing update interest timely when we set the borrow rate config

### Summary

In [LendingPool.sol:348](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/LendingPool.sol#L348), the owner can update the borrow rate model via function `setBorrowingRateConfig`.

The problem here is that this borrow config will change this lending pool's borrow rate directly. But we don't accrue the previous borrow interest. This will cause that we will calculate the borrow interest via the updated borrow rate even if this period is before we update the borrow rate config.

For example:
1. Alice deposits 2000 tokenA in the lending pool in timestamp X.
2. Bob opens one leverage position and borrows 1000 TokenA in timestamp X + 100. Assume current borrow rate is 3%.
3. The owner set the borrow rate config in timestamp X + 200. Because we update the borrow rate, the current borrow rate becomes 5%.
4. Cathy deposit 2000 tokenA in the lending pool in timestamp X + 300, we will calculate the accrued interest via the updated borrow rate 5% between timestamp X + 100  and timestamp X + 300. This is incorrect, because we should calculate the borrow interest via borrow rate 3% between timestamp X + 100 and timestamp X + 200.

```solidity
    function setBorrowingRateConfig(
        address asset,
        uint16 utilizationA,
        uint16 borrowingRateA,
        uint16 utilizationB,
        uint16 borrowingRateB,
        uint16 maxBorrowingRate
    ) public onlyOwner notPaused {
        DataTypes.ReserveData storage reserve = reserves[asset];
        setBorrowingRateConfig(reserve, utilizationA, borrowingRateA, utilizationB, borrowingRateB, maxBorrowingRate);
    }

```
