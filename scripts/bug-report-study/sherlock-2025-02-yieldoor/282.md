# Users can liquidate a certain leveraged position without paying the protocol fee.

### Summary

Users can liquidate a certain leveraged position without paying the protocol fee. Looking at the liquidatePosition() function in Leverager.sol, users are required to pay the protocol fee when liquidating a certain leveraged position.
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L320
```solidity
if (totalValueUSD > borrowedValue) {
    // What % of the amountsOut are profit is calculated by `(totalValueUSD - borrowedUSD) / totalValueUSD`
    // Then, on top of that, we calculate the protocol fee and scale it in 1e18.

    uint256 protocolFeePct = 1e18 * liquidationFee * (totalValueUSD - borrowedValue) / (totalValueUSD * 10_000);
    uint256 pf0 = protocolFeePct * amount0 / 1e18;
    uint256 pf1 = protocolFeePct * amount1 / 1e18;

    if (pf0 > 0) IERC20(up.token0).safeTransfer(feeRecipient, pf0);
    if (pf1 > 0) IERC20(up.token1).safeTransfer(feeRecipient, pf1);
    amount0 -= pf0;
    amount1 -= pf1;
}
```
Users can liquidate a certain leveraged position without calling the liquidatePosition() function. By setting the parameter wp.pctWithdraw to 1e18 in the withdraw() function, the withdraw() function will perform the functionality of the liquidatePosition() function. 
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L299
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L209
Therefore, users can set the pctWithdraw of the WithdrawParams wp to 1e18 and call the withdraw() function to liquidate a certain leveraged position. However, the withdraw() function does not require the payment of the protocol fee. 
As a result, users can liquidate a certain leveraged position without paying the protocol fee.

### Attack Path

1. Set pctWithdraw of WithdrawParams wp to 1e18.
2. When attempting to liquidate a certain leveraged position, call withdraw() instead of liquidatePosition().
Users have liquidated a certain leveraged position without paying the protocol fee.


### Impact

### Mitigation

The withdraw() function needs to be modified to pay of the protocol fee.
