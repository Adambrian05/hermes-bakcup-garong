# Integer Overflow in collectFees()

### Summary

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L159

The function collectFees() lacks proper input validation, leading to potential integer overflow when handling fee accumulation.



### Root Cause

1. A large amount of fees is accumulated.
2. collectFees() is called, and without safe math operations, an integer wraps around, causing unexpected behavior.


### Internal Pre-conditions

collectFees() 

### External Pre-conditions

integer wraps around

2. Can lead to arbitrary value manipulation.

### Mitigation

Use SafeMath for calculations.
```solidity
using SafeMath for uint256;

function collectFees(uint256 amount) external {
    require(amount <= type(uint256).max, "Amount too large");
    collectedFees = collectedFees.add(amount);
}

```
