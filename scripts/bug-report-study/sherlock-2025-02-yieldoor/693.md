# Attacker will manipulate price feed for leveraged positions

### Summary

Reliance on a single price feed in Leverager will cause undercollateralized positions for users as an attacker can manipulate the price to borrow at favorable rates.

### Root Cause

In [Leverager.sol: openLeveragedPosition function](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol?plain=1#L130-L131), the contract relies on `IPriceFeed(pricefeed).getPrice` for token valuations, which can be manipulated if the oracle is compromised.

### Internal Pre-conditions

The price feed must be manipulable, allowing the attacker to alter reported prices

### External Pre-conditions

ETH oracle needs to go from 4000 to 5000 within 2 minutes to enable rapid price manipulation.

### Attack Path

1. Attacker manipulates the price feed to inflate collateral value.
2. Calls `openLeveragedPosition `to borrow at favorable rates based on manipulated price.
3. Dumps assets to create underwater positions, profiting from the difference.

### Impact

Users suffer an approximate loss of funds due to undercollateralized positions, with the attacker gaining the difference.

### PoC

it requires oracle manipulation setup.

### Mitigation

Use decentralized oracle like [Chainlink](https://chain.link/) or multiple sources for price verification.
