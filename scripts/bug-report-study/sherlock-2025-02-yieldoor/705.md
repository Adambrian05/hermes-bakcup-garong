# Incorrect Condition Implementation at `_calcDeposit` function

There is a incorrect implementation of condition at `_calcDeposit` function in contract `Vault.sol` . 

Vulnerability Details :

We have implemented the condition that `if (totalSupply == 0)` then take input `amount0` and `amount1` as `depositAmount0` and `depositAmount1` then after that we implemented the next condition  `else if (bal0 == 0)` and `else if (bal1 == 0)`  . But if someone deposite only `amount1` with having non zero value and deposite `amount0` with zero . Then after first transaction he always have to deposit only `amount1`  becouse in every transction first condition will be implemented .
