# min/max answer hasn't been checked in PriceFeed contract

### Root Cause

there is a minAnswer/maxAnswer check for some data feed like [Aave/USD](https://arbiscan.io/address/0x3c6AbdA21358c15601A3175D8dd66D0c572cc904#readContract) in chainlink, that if the oracle price feed falls out of range, it will simply return the minAnswer/maxAnswer. For example, if the price falls below minAnswer, the oracle will simply return minAnswer. See https://docs.chain.link/data-feeds#check-the-latest-answer-against-reasonable-limits for more details.
