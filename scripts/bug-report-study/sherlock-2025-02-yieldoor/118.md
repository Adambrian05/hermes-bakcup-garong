# Unable to rebalance due to phantom overflow

### Summary

Not handling phantom overflow in the function `Strategy::_setSecondaryPositionsTicks` will cause the contract unable to rebalance

### Root Cause

- The function [`Strategy::price()`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L126-L129) returns pool price with precision of 1e30
- The calculation `uint256 bal0in1 = bal0 * _price / PRECISION` in the [function `Strategy::_setSecondaryPositionsTicks`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L371) which calculates token0 value in term of token1. The calculation can be failed due to arithmetic overflow, which happen at `bal0 * _price` part. Indeed, with Univ3 pool's square root price of range [4295128739; 1461446703485210103287273052203988822378723970342], it is possible that `bal0 * _price` can be overflow. For example, with max sqrt ratio = `1461446703485210103287273052203988822378723970342`, `price()` returns value `340256786836388094070642339899681165074510158256154455635779019256721` and it only needs `bal0 > 340307948` so that the operation overflows

N/A

### External Pre-conditions

N/A

### Impact

- Unable to rebalance positions in the pool with very high sqrt price

### PoC

Add the test to file `test/BaseTest.sol`
```solidity
    function test_pool_max_price() public {
      // @audit POC overflow
      (
            ,
            int24 tick,
            uint16 observationIndex,
            uint16 observationCardinality,
            uint16 observationCardinalityNext,
            uint32 feeProtocol,
            bool unlocked
        ) = pool.slot0();
      
      // assume that pool sqrt price reaches (TickMath.MAX_SQRT_RATIO - 1)
      vm.mockCall(address(pool), abi.encodeWithSignature("slot0()"), abi.encode(
        TickMath.MAX_SQRT_RATIO - 1, tick, observationIndex, observationCardinality, observationCardinalityNext, feeProtocol, unlocked
      ));

      deal(address(wbtc), address(this), 340307948 + 1);
      wbtc.transfer(address(strategy), 340307948 + 1);

      vm.startPrank(rebalancer);
      skip(10 minutes);
      IStrategy(strategy).rebalance();
    }
```

### Mitigation

```diff
- uint256 bal0in1 = bal0 * _price / PRECISION;
+ uint256 bal0in1 = FullMath.mulDiv(bal0, _price, PRECISION);
```
