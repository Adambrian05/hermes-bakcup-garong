# Multihop swaps are impossible to use in the `Leverager`, leading to losses for users

### Summary

The `Leverager` supports swaps using multi-hops, which often give better prices to users with less slippage. However, this functionality will never work and lead to OOG revert because it gets stuck in an infinite loop.

### Root Cause

In `Leverager:568`, path is not [updated](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L567-L569) to the new path after skipping a pool.

### Internal Pre-conditions

None.

### External Pre-conditions

None.

### Attack Path

1. User calls `Leverager::openLeveragedPosition()` with multi-hop swaps to repay for the flashloan funds from the lending pool.

### Impact

Multi hop swaps lead to DoS, which means:
1. Users will never be able to use multi-hop swaps, taking losses.
2. Users that try to do multi-hop swaps will revert and not open a position, also taking losses.

### PoC

```solidity
function test_POC_multiplePathFails() public {
    vm.startPrank(depositor);
    ILeverager.LeverageParams memory lp;
    lp.amount0In = 0.5e8;
    lp.amount1In = 50_000e6;
    lp.vault0In = 1e8;
    lp.vault1In = 100_000e6;
    lp.vault = vault;
    lp.maxBorrowAmount = 200_000e6;
    lp.denomination = address(usdc);
    IMainnetRouter.ExactOutputParams memory ep;

    bytes memory _path = abi.encodePacked(address(wbtc), uint24(3000), address(weth), uint24(3000), address(usdc));
    ep.path = _path;
    ep.deadline = block.timestamp;
    ep.amountInMaximum = type(uint256).max;
    ep.recipient = leverager;
    lp.swapParams1 = abi.encode(ep);

    deal(address(wbtc), depositor, 0.5e8);
    deal(address(usdc), depositor, 50_000e6);
    wbtc.approve(leverager, type(uint256).max);
    usdc.approve(leverager, type(uint256).max);

    ILeverager(leverager).openLeveragedPosition(lp);
}
```

### Mitigation

```solidity
function _getTokenIn(bytes memory path) internal pure returns (address) {
    while (path.hasMultiplePools()) {
        path = path.skipToken();
    }

    (, address tokenIn,) = path.decodeFirstPool();
    return tokenIn;
}
```
