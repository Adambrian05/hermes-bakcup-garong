# Borrowing rates can be arbitrarily changed affecting existing loans

## Description:
`LendingPool` contract allows the owner to modify the interest rate configuration that affects all existing loans. While the changes don't apply immediately (only after the next reserve operation), there is no maximum cap on rates, no gradual transition period, and changes eventually apply to all outstanding debt.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/LendingPool.sol#L348
```solidity 
// LendingPool.sol
function setBorrowingRateConfig(
    address asset,
    uint16 utilizationA,
    uint16 borrowingRateA,
    uint16 utilizationB,
    uint16 borrowingRateB,
    uint16 maxBorrowingRate
) public onlyOwner {
    DataTypes.ReserveData storage reserve = reserves[asset];
    setBorrowingRateConfig(reserve, utilizationA, borrowingRateA, utilizationB, borrowingRateB, maxBorrowingRate);
}
```

When the next reserve operation occurs (deposit, withdrawal, borrow, repay), the interest rates are updated:
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/libraries/ReserveLogic.sol#L140
```solidity
// ReserveLogic.sol
function updateInterestRates(DataTypes.ReserveData storage reserve) internal {
    reserve.currentBorrowingRate =
        InterestRateUtils.calculateBorrowingRate(reserve.borrowingRateConfig, utilizationRate(reserve));
}
```

This updated borrowing rate affects the calculation of the borrowing index for all existing loans:
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/libraries/ReserveLogic.sol#L109
```solidity
// ReserveLogic.sol
function latestBorrowingIndex(DataTypes.ReserveData storage reserve) internal view returns (uint256) {
    if (reserve.lastUpdateTimestamp == uint128(block.timestamp)) {
        return reserve.borrowingIndex;
    }

    return reserve.borrowingIndex
        * (InterestRateUtils.calculateCompoundedInterest(reserve.currentBorrowingRate, reserve.lastUpdateTimestamp))
        / (PRECISION);
}
```

This borrowing index is used to calculate the current debt of borrowers:
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L385
```solidity
// Leverager.sol
function isLiquidateable(uint256 _id) public view returns (bool liquidateable) {
    // ...
    uint256 bIndex = ILendingPool(lendingPool).getCurrentBorrowingIndex(pos.denomination);
    uint256 owedAmount = pos.borrowedAmount * bIndex / pos.borrowedIndex;
    // ...
}
```

No maximum limit on interest rates
Changes affect all existing loans immediately (for future interest accrual)
Borrowers cannot predict their future debt

## Impact:
Unexpected increase in borrower debt
Users cannot properly plan debt servicing

## Recommended Mitigation:
Add maximum rate limits
Maintain the initial rate configuration for each loan
