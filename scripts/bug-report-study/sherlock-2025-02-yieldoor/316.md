# Liquidation failes due to blacklisted tokens

### Summary

In the function `liquidatePosition` in Leverager.sol.  

There is no check against blacklisted tokens.

### Root Cause

When user does malicious things and gets blacklisted, he cannot send or receive USDC tokens. Meaning he cannout get liquidated.

### Internal Pre-conditions

.

### External Pre-conditions

.

### Attack Path

1. User deposits into the lending pool
2. Gets blacklisted
3. Liquidation fails

### Impact

User cannot get liquidated

### Mitigation

Implement a try/catch block or check if user is blacklisted.
