# Public function setBorrowingRateConfig does not update lastUpdateTimestamp casuing incorrect borrowing index calculation

## Summary
A  vulnerability exists in the interest rate calculation mechanism where the lastUpdateTimestamp is not properly updated when borrowing rates are modified, leading to inflated interest calculations and potentially incorrect liquidations.

## Vulnerability Detail
The vulnerability occurs because the setBorrowingRateConfig function in LendingPool.sol does not update the lastUpdateTimestamp when called by the owner to modify interest rate parameters. This creates a situation where:
The lastUpdateTimestamp becomes stale
When calculateCompoundedInterest is called, it calculates interest over a much longer period than intended
This results in inflated borrowing indices and owed amounts
Positions that should be healthy may be incorrectly flagged for liquidation
The issue is particularly severe because:
It affects all positions borrowing the affected asset
It can be triggered by a legitimate admin action (updating interest rate parameters)
It can lead to irreversible liquidations and financial loss
## Impact

## Code Snippet
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/LendingPool.sol#L348
```Solidity
    function setBorrowingRateConfig(
        address asset,
        uint16 utilizationA,
        uint16 borrowingRateA,
        uint16 utilizationB,
        uint16 borrowingRateB,
        uint16 maxBorrowingRate
    ) public onlyOwner notPaused {
        DataTypes.ReserveData storage reserve = reserves[asset];
        setBorrowingRateConfig(reserve, utilizationA, borrowingRateA, utilizationB, borrowingRateB, maxBorrowingRate);
    }
```

## Recommendation

add `reserve.lastUpdateTimestamp = uint128(block.timestamp);`

```Solidity
    function setBorrowingRateConfig(
        address asset,
        uint16 utilizationA,
        uint16 borrowingRateA,
        uint16 utilizationB,
        uint16 borrowingRateB,
        uint16 maxBorrowingRate
    ) public onlyOwner notPaused {
        DataTypes.ReserveData storage reserve = reserves[asset];
        setBorrowingRateConfig(reserve, utilizationA, borrowingRateA, utilizationB, borrowingRateB, maxBorrowingRate);
        reserve.lastUpdateTimestamp = uint128(block.timestamp);
    }

```
