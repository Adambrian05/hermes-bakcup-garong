# [H] feeRecipient is never initialized.

### Summary

The address public feeRecipient in the Leverager.sol is never initialized.

### Root Cause

In liquidatePosition::Leverager.sol:L330-331 feeRecipient is used but not initialized anywhere in the protocol. 

if (pf0 > 0) IERC20(up.token0).safeTransfer(feeRecipient, pf0);
if (pf1 > 0) IERC20(up.token1).safeTransfer(feeRecipient, pf1);

### Internal Pre-conditions

No pre-conditions needed, just to use the liquidatePosition function.\


### External Pre-conditions

Nothing.

### Attack Path

No attack path.

### Impact

When calling the function liquidatePosition, the following line of code is excuted: 
if (pf0 > 0) IERC20(up.token0).safeTransfer(feeRecipient, pf0);
if (pf1 > 0) IERC20(up.token1).safeTransfer(feeRecipient, pf1);
Since feeRecipient is not initialized token transfer will go to a 0x0~ address.
