# `Leverager.openLeveragedPosition()` Reverts Due to Modification of `swapParams.path` in the `_getTokenIn()` Function

### Summary

In the `Leverager.openLeveragedPosition()` function, the input token for the swap is obtained by calling `_getTokenIn(swapParams.path)`. However, the `_getTokenIn()` function modifies its parameter, which is a memory variable. As a result, `swapParams.path` is altered, leading to the actual swap reverting due to an incorrect swap path.

### Root Cause

The [openLeveragedPosition()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L146) function calls `_getTokenIn(swapParams.path)` to retrieve the input token for the swap. However, the `_getTokenIn()` function modifies its function parameter `path`. Consequently, `swapParams.path` is altered within the `_getTokenIn()` function, resulting in the actual swap reverting due to an incorrect swap path.
