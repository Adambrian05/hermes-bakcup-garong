# Uninitialized Fee Recipient Will Cause Loss of Protocol Fees

### Summary

Uninitialized fee recipient address will cause protocol fee loss for the project as liquidators will accidentally send fees to the zero address (0x0) during liquidations.
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L47C20-L47C32


### Root Cause

In `Leverager.sol` the `feeRecipient` state variable is declared but never initialized in the constructor or through a setter function, causing it to remain at the default zero address.

### Internal Pre-conditions

1. The `feeRecipient` variable remains at its default value of address(0) when liquidations occur
2. The liquidationFee is set to a non-zero value through the setLiquidationFee` function
3. A position becomes `liquidatable` and someone calls `liquidatePosition`

### External Pre-conditions

No external pre-conditions are required.

### Attack Path

1. The `Leverager` contract is deployed with a non-zero `liquidationFee`
2. A leveraged position becomes `liquidatable` due to market conditions
3. A liquidator calls the `liquidatePosition` function to liquidate the position
4. The function calculates a non-zero protocol fee (pf0 or pf1) based on the profit and the `liquidationFee` value
5. The function attempts to transfer these fees to `feeRecipient` which is still the zero address
6. Tokens are transferred to the zero address and permanently lost:
```solidity
if (pf0 > 0) IERC20(up.token0).safeTransfer(feeRecipient, pf0);
if (pf1 > 0) IERC20(up.token1).safeTransfer(feeRecipient, pf1);

```
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L328-329

### Impact

The protocol suffers a loss of all liquidation fees, which are permanently sent to the zero address. These fees cannot be recovered and represent a direct financial loss for the protocol.

### PoC

_No response_

### Mitigation

Add a setter function for the feeRecipient address:
```solidity
/// @notice Sets the fee recipient address
/// @param _feeRecipient The new fee recipient address
function setFeeRecipient(address _feeRecipient) external onlyOwner {
    require(_feeRecipient != address(0), "Fee recipient cannot be zero address");
    feeRecipient = _feeRecipient;
}
```
Additionally, initialize feeRecipient in the constructor:
```solidity
constructor(
    string memory name_, 
    string memory symbol_, 
    address _lendingPool,
    address _feeRecipient
) Ownable(msg.sender) ERC721(name_, symbol_) {
    require(_feeRecipient != address(0), "Fee recipient cannot be zero address");
    lendingPool = _lendingPool;
    feeRecipient = _feeRecipient;
}
```
