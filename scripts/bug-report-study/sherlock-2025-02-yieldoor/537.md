# Withdaw function missing onlyOwner restriction

### Summary

`Withdaw` function missing `onlyOwner` restriction. The issue can lead to stolen funds.

### Root Cause

In `Vault.sol` in function `withdraw` is missing a a modifier for `onlyOwner`. 
[click this](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Vault.sol#L80)

### Internal Pre-conditions

User need to have deposited funds.

### External Pre-conditions

Attacker must know the address of User's vault.

### Attack Path

The attacker simply calls `withdraw` from `Vault.sol` with the amount of `shares` and the `minAmount` of both tokens he wants to steal.

### Impact

Either a partial or the full amount of User's deposit can be stolen.

### PoC

_No response_

### Mitigation

Add a modifier to `withdraw`.

```diff
- function withdraw(uint256 shares, uint256 minAmount0, uint256 minAmount1) public
+ function withdraw(uint256 shares, uint256 minAmount0, uint256 minAmount1) public onlyOwner
```
