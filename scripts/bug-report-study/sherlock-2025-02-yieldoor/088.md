# Significant precision loss in compounded interest calculation due to dividing before multiplying

### Summary

`InterestRateUtils:calculateCompoundedInterest()` calculates the interest rate as follows:
```solidity
function calculateCompoundedInterest(uint256 rate, uint128 lastUpdateTimestamp, uint256 currentTimestamp)
    internal
    pure
    returns (uint256)
{
    //solium-disable-next-line
    uint256 exp = currentTimestamp - (uint256(lastUpdateTimestamp));

    if (exp == 0) {
        return PRECISION;
    }

    uint256 expMinusOne = exp - 1;

    uint256 expMinusTwo = exp > 2 ? exp - 2 : 0;

    uint256 ratePerSecond = rate / SECONDS_PER_YEAR;

    uint256 basePowerTwo = ratePerSecond * ratePerSecond / PRECISION;

    uint256 basePowerThree = basePowerTwo * ratePerSecond / PRECISION;

    uint256 secondTerm = exp * expMinusOne * basePowerTwo / 2;
    uint256 thirdTerm = exp * expMinusOne * expMinusTwo * basePowerThree / 6;

    return (PRECISION) + (ratePerSecond * exp) + (secondTerm) + (thirdTerm);
}
```
As can be seen, it divides the `rate` by `SECONDS_PER_YEAR`, which is around `3e7`. Although a precision of `1e27` is used, the precision loss is still significant and will keep compounding because of the third term being cubed, which scales the loss. Preliminary tests show that with regular utilization the loss will exceed 10 USD in 3 years and 30 million USD in 20 years, if there are `1e9` usd in the LendingPool, which keeps on scaling. The loss grows actually much bigger in case the pool is not interacted with for long periods, however, this is not as likely and the calculations in the poc assume users interact with the pool in the span of 3 days on average.

### Root Cause

In `InterestRateUtils:89`, it [divides](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/libraries/InterestRateUtils.sol#L89) the rate by `SECONDS_PER_YEAR` and then calculates the interest, which introduces significant precision loss.

### Impact

Borrowers are undercharged, 10 USD in 3 years and 30 million USD in 20 years.

### PoC

`calculateCompoundedInterestV2()` is simply the same function but divides by `SECONDS_PER_YEAR` in the end of the calculations.
```solidity
function test_POC_precision_loss() public {
    uint256 maxDiff;
    for (uint j = 0; j < 10; j++) {
        uint256 borrowingIndex = PRECISION;
        uint256 roundedBorrowingIndex = PRECISION;
        uint256 time = 0;
        for (uint i = 0; i < 100000; i++) {
            uint256 rate = vm.randomUint(0, 1.5e27);
            uint256 exp = vm.randomUint(0, 6*24*3600);
            time += exp;
            if (time > 20*SECONDS_PER_YEAR) { //@audit change years to see how error grows
                break;
            }

            uint256 rounded = calculateCompoundedInterest(rate, 0, exp);
            uint256 roundedV2 = calculateCompoundedInterestV2(rate, 0, exp);

            roundedBorrowingIndex = roundedBorrowingIndex * rounded / PRECISION;
            borrowingIndex = borrowingIndex * roundedV2 / PRECISION;

            uint256 diff = borrowingIndex - roundedBorrowingIndex;
            if (diff > maxDiff) {
                maxDiff = diff;
            }
        }
    }
    console.log("max borrowing index diff in USD", 1e9 * maxDiff / 1e27);
}
```

### Mitigation

Sample implementation with much less precision loss:
```solidity
function calculateCompoundedInterestV2(uint256 rate, uint128 lastUpdateTimestamp, uint256 currentTimestamp)
    internal
    pure
    returns (uint256)
{
    //solium-disable-next-line
    uint256 exp = currentTimestamp - (uint256(lastUpdateTimestamp));

    if (exp == 0) {
        return PRECISION;
    }

    uint256 expMinusOne = exp - 1;

    uint256 expMinusTwo = exp > 2 ? exp - 2 : 0;

    uint256 ratePerSecond = rate;

    uint256 basePowerTwo = ratePerSecond * ratePerSecond / PRECISION;

    uint256 basePowerThree = basePowerTwo * ratePerSecond / (PRECISION);

    uint256 secondTerm = exp * expMinusOne * basePowerTwo / 2 / SECONDS_PER_YEAR ** 2;
    uint256 thirdTerm = exp * expMinusOne * expMinusTwo * basePowerThree / 6 / SECONDS_PER_YEAR ** 3;

    return (PRECISION) + (ratePerSecond * exp / SECONDS_PER_YEAR) + (secondTerm) + (thirdTerm);
}
```
