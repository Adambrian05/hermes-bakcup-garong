# Liquidation fee can be changed to 100% for existing positions, potentially blocking liquidations

## Description:
The Leverager contract allows the owner to change the liquidation fee up to 100% of the liquidation profit. This change affects all existing positions and can make liquidations economically unfeasible, potentially leading to bad debt accumulation.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L512

```solidity
// Leverager.sol
uint256 liquidationFee; // in basis points (10000 = 100%)

function setLiquidationFee(uint256 newFee) external onlyOwner {
    require(newFee <= 10_000, "new fee too high");
    liquidationFee = newFee;
}
```

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L299

```solidity
function liquidatePosition(LiquidateParams calldata liqParams) external {
    // ...
    if (totalValueUSD > borrowedValue) {
        uint256 protocolFeePct = 1e18 * liquidationFee * (totalValueUSD - borrowedValue) /
            (totalValueUSD * 10_000);

        uint256 pf0 = protocolFeePct * amount0 / 1e18;
        uint256 pf1 = protocolFeePct * amount1 / 1e18;

        if (pf0 > 0) IERC20(token0).safeTransfer(feeRecipient, pf0);
        if (pf1 > 0) IERC20(token1).safeTransfer(feeRecipient, pf1);
    }
    // ...
}
```

Fee can be changed to 100% instantly
Affects all existing positions
No minimum liquidator profit guaranteed

## Impact:
Liquidators may stop performing liquidations if there's no profit incentive
Underwater positions may remain unliquidated
Protocol can accumulate bad debt
Users cannot predict liquidation conditions

## Recommended Mitigation:
Add maximum liquidation fee and minimum liquidator profit
Store liquidation fee in position struct to maintain consistent conditions
