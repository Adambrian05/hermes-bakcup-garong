# Exchange Rate Manipulation via Dust Amounts

### Summary

The improper placement of the dust check in _deposit(...) will cause incorrect exchange rate calculations for depositors as an attacker can send dust amounts to the yToken contract, artificially skewing the ratio between yTokens and underlying assets.

### Root Cause

In _deposit(...), the yTokenAmount is calculated before the dust check is applied:

require(yTokenAmount > MINIMUM_YTOKEN_AMOUNT, "deposit is dust amount");
if (IyToken(reserve.yTokenAddress).totalSupply() == 0) {
    IyToken(reserve.yTokenAddress).mint(DEAD_ADDRESS, MINIMUM_YTOKEN_AMOUNT);
    yTokenAmount -= MINIMUM_YTOKEN_AMOUNT;
}

Since the yTokenAmount calculation depends on the current exchange rate, an attacker can manipulate this rate by sending small amounts of tokens directly to the yToken contract. This causes the protocol to miscalculate yTokenAmount for legitimate deposits, potentially allowing the attacker to extract a disproportionate amount of yTokens.

### Internal Pre-conditions

The attacker sends small amounts of the underlying asset to the yToken contract outside of normal deposit functions.

The _deposit(...) function does not verify that the exchange rate remains consistent before allowing deposits.

The dust check is performed only after the yTokenAmount calculation, making it ineffective against manipulated exchange rates.

### External Pre-conditions

The protocol does not enforce restrictions on external token transfers to the yToken contract.

No mechanism ensures that the exchange rate remains stable in the presence of small external deposits

### Attack Path

The attacker sends a dust amount of the underlying token to the yToken contract.

This increases the perceived reserves of the contract without updating the internal accounting.

When a legitimate user deposits, the manipulated exchange rate results in incorrect yTokenAmount calculations.

The attacker may later exploit this by withdrawing an inflated amount of yTokens for a disproportionately higher share of the underlying asset.

### Impact

This vulnerability allows an attacker to manipulate the protocol’s exchange rate, potentially leading to unfair token distribution and financial losses for depositors. The incorrect dust check could also lead to skewed reward allocations and instability in the lending pool.
