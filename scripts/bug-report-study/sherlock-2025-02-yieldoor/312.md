# `feeRecipient`is not initialized in `Leverager` contract

### Summary

The `feeRecipient`is not initialized in the `Leverager` contract. Solidity by default initializes it to zero address. This may result in significant loss of protocol fees

### Root Cause

In [`Leverager.sol:41` ](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L47) the `feeRecipient` is not initialized


### Impact

High as this can lead to significant loss of protocol fees.

### PoC

_No response_

### Mitigation

Initialize the feeRecipient in constructor or create a new function to setFeeRecipient

```diff
- constructor(string memory name_, string memory symbol_, address _lendingPool)
+ constructor(string memory name_, string memory symbol_, address _lendingPool,address _feeRecipient)
        Ownable(msg.sender)
        ERC721(name_, symbol_)
    {
        lendingPool = _lendingPool;
+        feeRecipient = _feeRecipient
    }
```
