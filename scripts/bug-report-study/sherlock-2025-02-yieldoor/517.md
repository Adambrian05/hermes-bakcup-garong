# Incorrect `initCollateralUsd` in `Leverager.openLeveragedPosition()`

### Summary

In the `Leverager.openLeveragedPosition()` function, `initCollateralUsd` represents the total USD value of tokens deposited into the vault. However, this is incorrect. `initCollateralUsd` should only represent the total USD value of tokens that the user paid.

### Root Cause

The [openLeveragedPosition()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L129) function determines `initCollateralUsd` as the total USD value of `token0` and `token1` amounts of `a0` and `a1`. Here, `a0` and `a1` represent the token amounts deposited into the vault, not just the amounts the user paid. As a result, `initCollateralUsd` includes the borrowed USD value.

    function openLeveragedPosition(LeverageParams calldata lp) external nonReentrant returns (uint256 _id) {

Since `initCollateralUsd` includes the borrowed USD value, the value of `positionLeverage` cannot exceed 2, meaning the `_checkWithinlimits()` check will always pass. This allows an attacker to open a position with `1 wei of token0` and `1 wei of token1` by borrowing as much as possible.
