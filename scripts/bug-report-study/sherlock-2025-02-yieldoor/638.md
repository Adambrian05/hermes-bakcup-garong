# Handling the Case Where Both Tokens Lack Price Feeds

### Summary

The function _calculateTokenValues is designed to calculate the USD value of two tokens (token0 and token1) by fetching their respective prices from a price feed. If either token lacks a price feed, the logic attempts to resolve the issue by converting one token into the other, and then converting it into USD based on the available price data. However, the current implementation does not account for the scenario where both tokens lack price feeds. When both tokens have no price feeds, the function will fail to calculate their USD value and, in its current state, will not raise any error or handle this edge case, leading to unpredictable behavior or incorrect results.

### Root Cause

The root cause of the issue lies in the way the _calculateTokenValues function handles missing price feeds for the tokens involved in the calculation. The function assumes that at least one of the two tokens (token0 or token1) will always have a valid price feed. If one of the tokens does not have a price feed, the function attempts to resolve this by converting the value of the token with no price feed into the value of the other token (which has a price feed) and then into USD.

However, the current implementation does not account for the scenario where both tokens lack price feeds. When both tokens have no price feeds, the function will fail to calculate their USD value and, in its current state, will not raise any error or handle this edge case, leading to unpredictable behavior or incorrect results.

    {
        uint256 chPrice0;
        uint256 chPrice1;
        uint256 decimals0 = 10 ** ERC20(token0).decimals();
        uint256 decimals1 = 10 ** ERC20(token1).decimals();

            chPrice0 = IPriceFeed(pricefeed).getPrice(token0);
            usdValue += amount0 * chPrice0 / decimals0;
        }
        if (IPriceFeed(pricefeed).hasPriceFeed(token1)) {
            chPrice1 = IPriceFeed(pricefeed).getPrice(token1);
            usdValue += amount1 * chPrice1 / decimals1;
        }

            usdValue += amount1 * PRECISION / price * chPrice0 / decimals0;
        }
