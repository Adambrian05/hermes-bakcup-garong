# `initCollateralUsd` is incorrectly set when opening a leveraged position.

### Summary
`up.initCollateralUsd` is the USD amount of the collateral of a leveraged position. However, it is incorrectly set to the USD value of the total position. 

### Root Cause
The amounts for token0 and token1 which are transferred from a user are `lp.amount0In` and `lp.amount1In`.(L116-L117) So, the `up.initCollateralUsd` should be set as the USD value of `lp.amount0In` and `lp.amount1In`. However, it is set as the USD value of `a0` and `a1` which are the amounts actually deposited into the vault.(L127) Therefore, `up.initCollateralValue` is also incorrectly calculated.(L131)

http://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L116-L129
```solidity
116:    IERC20(up.token0).safeTransferFrom(msg.sender, address(this), lp.amount0In);
117:    IERC20(up.token1).safeTransferFrom(msg.sender, address(this), lp.amount1In);

        uint256 delta0 = lp.vault0In - lp.amount0In;
        uint256 delta1 = lp.vault1In - lp.amount1In;
        if (delta0 > 0) ILendingPool(lendingPool).pullFunds(up.token0, delta0); // we flashloan the difference between amounts desired to be deposited in Vault
        if (delta1 > 0) ILendingPool(lendingPool).pullFunds(up.token1, delta1); // and the amount pulled from the user

        // a0 and a1 represent the actual amounts deposited within the vault.
        // We keep track of them as we later make exactOutput swaps based on them
126:    (uint256 shares, uint256 a0, uint256 a1) =
            IVault(lp.vault).deposit(lp.vault0In, lp.vault1In, lp.min0in, lp.min1in);

129:    up.initCollateralUsd = _calculateTokenValues(up.token0, up.token1, a0, a1, price);
        uint256 bPrice = IPriceFeed(pricefeed).getPrice(lp.denomination);
131:    up.initCollateralValue = up.initCollateralUsd * (10 ** ERC20(lp.denomination).decimals()) / bPrice;
```

As a result, in the `_checkWithinlimits()` function, `positionLeverage` is calculated much smaller than expected.(L464, L467)
http://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L459-L474
```solidity
    function _checkWithinlimits(Position memory up) internal {
        VaultParams memory vp = vaultParams[up.vault];
        (uint256 maxIndividualBorrow, uint256 maxLevTimes) =
            ILendingPool(lendingPool).getLeverageParams(up.denomination);

464:    uint256 positionLeverage = (up.initCollateralValue + up.borrowedAmount) * 1e18 / up.initCollateralValue;

        require(up.initBorrowedUsd >= minBorrow, "position must be at least minBorrow amount");
467:    require(positionLeverage <= vp.maxTimesLeverage && positionLeverage <= maxLevTimes, "too high x leverage");
        require(up.initBorrowedUsd <= vp.maxUsdLeverage, "too high borrow usd amount");
        require(up.borrowedAmount <= maxIndividualBorrow, "too high borrow for the vault");
        require(
            vaultParams[up.vault].currBorrowedUSD <= vaultParams[up.vault].maxCumulativeBorrowedUSD,
            "vault exceeded borrow limit"
        );
    }
```

In addition, the `isLiquidateable` function cannot work correctly, too. So, `base` will be set to an incorrect value(greater than expected), when `base >= pos.initCollateralValue`. As a result, a position can be liquidated incorrectly.

http://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L408-L411
```solidity
        uint256 base = owedAmount * 1e18 / (vp.maxTimesLeverage - 1e18);
409:    base = base < pos.initCollateralValue ? base : pos.initCollateralValue;

        if (owedAmount > totalDenom || totalDenom - owedAmount < vp.minCollateralPct * base / 1e18) return true;
```

### Impact
1. A position can be opened with very less collateral due to incorrect calculation of `positionLeverage` in the  `_checkWithinlimits()` function. 
2. A position can be liquidated incorrectly in some cases.

### PoC
none

### Mitigation

```diff
-       up.initCollateralUsd = _calculateTokenValues(up.token0, up.token1, a0, a1, price); // returns the USD price in 1e18
+       up.initCollateralUsd = _calculateTokenValues(up.token0, up.token1, lp.amount0In, lp.amount1In, price); // returns the USD price in 1e18
```
