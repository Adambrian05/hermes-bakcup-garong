# Strategy balance reporting omits vesting position funds and uncollected fees


## Summary
The `balances()` function in `Strategy.sol` fails to account for both funds locked in vesting positions and uncollected fees from Uniswap V3 pools, leading to inaccurate balance reporting that affects user decisions and protocol interactions.

## Root Cause
In [`Strategy.sol#L502-L521`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L502-L521), the `balances()` function only considers idle balances and funds in main/secondary positions:

```solidity
    function balances() public view returns (uint256 amount0, uint256 amount1) {
        (uint160 sqrtPriceX96,,,,,,) = IUniswapV3Pool(pool).slot0();

        (uint256 idle0, uint256 idle1) = idleBalances();
        (uint256 m0, uint256 m1) = LiquidityAmounts.getAmountsForLiquidity(
            sqrtPriceX96,
            TickMath.getSqrtRatioAtTick(mainPosition.tickLower),
            TickMath.getSqrtRatioAtTick(mainPosition.tickUpper),
            mainPosition.liquidity
        );
        (uint256 s0, uint256 s1) = LiquidityAmounts.getAmountsForLiquidity(
            sqrtPriceX96,
            TickMath.getSqrtRatioAtTick(secondaryPosition.tickLower),
            TickMath.getSqrtRatioAtTick(secondaryPosition.tickUpper),
            secondaryPosition.liquidity
        );

        amount0 = idle0 + m0 + s0;
        amount1 = idle1 + m1 + s1;
    }
```

The function omits two critical components:
1. Funds locked in vesting positions
2. Uncollected fees from Uniswap V3 pool positions

## Internal pre-conditions
1. Active vesting position exists with locked funds
2. Strategy has positions in Uniswap V3 pools generating fees

## External pre-conditions
1. Time has passed since last fee collection
2. Positions have accumulated uncollected fees

## Attack Path
1. User queries `balances()` to make investment decisions
2. Function returns only partial balances:
   - Includes: idle funds, main position, secondary position
   - Excludes: vesting position funds, uncollected fees
3. User makes decisions based on incomplete information
4. Actual strategy value is higher than reported
5. This discrepancy affects:
   - Share price calculations
   - Investment decisions
   - Withdrawal planning

## Impact
The incomplete balance reporting leads to:
1. Users making decisions based on incorrect strategy valuations
2. Potential mispricing of share values
3. Suboptimal investment and withdrawal timing
4. Reduced trust in protocol accounting

## Mitigation
Modify `balances()` to include all strategy assets:
1. Add vesting position funds calculation
2. Include uncollected fees from pool positions
3. Return comprehensive total of all strategy assets
