# Incorrect Price Calculation in `Leverager::_calculateTokenValues`  will lead to Inaccurate Token Valuation for Users

### Summary

Improper price conversion in the `Leverager::_calculateTokenValues` function will cause an inaccurate token valuation for users as the protocol will incorrectly calculate token values when one token lacks a price feed.

https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L447

### Root Cause

In `Leverager::_calculateTokenValues` function, the calculation `amount1 * PRECISION / price * chPrice0 / decimals0` is incorrectly implemented.  The formula for calculating the missing price feed must be the same for both token , even if not using  division before multiplication can lead to significant precision loss and incorrect valuation, particularly when dealing with tokens of different decimal places.

### Internal Pre-conditions

1. The protocol must use a token pair where one token does not have a price feed set in the IPriceFeed contract
2. The token without a price feed must be token1 in the function parameters
3. The decimals of token0 and token1 must be different
4. The TWAP price must be non-zero

### External Pre-conditions

None

### Attack Path

1. User interacts with a function that utilizes `Leverager::_calculateTokenValues` where token1 has no price feed
2. The function incorrectly calculates the value using `amount1 * PRECISION / price * chPrice0 / decimals0`
3. Due to division before multiplication and potential decimal differences or the wrong formula , the calculation returns an incorrect USD value

### Impact

The users suffer an unpredictable valuation error that could be significant depending on token decimals and price. This could lead to incorrect liquidations, improper collateralization ratios, or inaccurate borrowing capacity calculations.

### PoC

create a file in `/test` and put this code on it

```solidity 
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.13;

import "./Leverager.t.sol";
import "forge-std/Test.sol";
import {LendingPool} from "../src/LendingPool.sol";
import {Leverager} from "../src/Leverager.sol";
import {LiquidityAmounts} from "../src/libraries/LiquidityAmounts.sol";
import {MockERC20} from "../lib/forge-std/src/mocks/MockERC20.sol";
import {PriceFeed} from "../src/PriceFeed.sol";

contract TokenValueTest is LeveragerTest {

    function test_WrongValuedToken1() public {
        MockERC20 mockToken = new MockERC20();
        mockToken.initialize("Mock", "MOCK", 18);
        TokenValueContract testContract = new TokenValueContract("test", "$T", lendingPool);

        testContract.setPriceFeed(address(priceFeed));

        uint256 usdcPrice = IPriceFeed(priceFeed).getPrice(address(usdc));

        uint256 twapPrice = 2e18;

        uint256 amount0 = 10e18;
        uint256 amount1 = 10e18;

        uint256 decimals0 = 1000000;

        uint256 expectedTokenValue = testContract.calculateTokenValues(address(mockToken), address(usdc), amount1, amount0, twapPrice);

        // swapping the token values to test the Wrong valued token
        uint256 actualTokenValue = testContract.calculateTokenValues(address(usdc), address(mockToken), amount0, amount1, twapPrice);

        assertNotEq(expectedTokenValue, actualTokenValue, "Token value is wrong due to incorrect price conversion");
    }
}

contract TokenValueContract is Leverager {

    constructor(string memory _name, string memory _symbol, address _lendingPool) Leverager(_name, _symbol, _lendingPool) {}


    function calculateTokenValues(address token0, address token1, uint256 amount0, uint256 amount1, uint256 price) public returns (uint256) {
        return _calculateTokenValues(token0, token1, amount0, amount1, price);
    }
}
```

### Mitigation

Correct the price conversion formula in the else-if block to use proper order of operations and appropriate decimal scaling:

```diff
- usdValue += amount1 * PRECISION / price * chPrice0 / decimals0;

+ usdValue += amount1 * chPrice0 * PRECISION / (price * decimals0);
```
Or change the formula to be like the first one :

```diff 
-  usdValue += amount1 * PRECISION / price * chPrice0 / decimals0;
+  usdValue += (amount1* price / PRECISION) * chPrice0 / decimals0;
```
