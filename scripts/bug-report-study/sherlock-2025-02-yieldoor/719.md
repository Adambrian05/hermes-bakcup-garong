# Wrong vest position boundaries setting in during Strategy::collectFees function

### Summary

Wrong vest position limits passed  when collectPositionFees is called

### Root Cause

collectPositionFees is passing as arguments (vestPosition.tickLower, mainPosition.tickUpper) and it should be  (vestPosition.tickLower, vestPosition.tickUpper) 
[https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L166-L167](url)

### Internal Pre-conditions

n/a

### External Pre-conditions

n/a

### Attack Path

n/a

### Impact

The Strategy contract will attempt to collect fees from the wrong position. This means that any fees accrued from the vesting position will not be collected properly.

Pass correct vest positions limits
