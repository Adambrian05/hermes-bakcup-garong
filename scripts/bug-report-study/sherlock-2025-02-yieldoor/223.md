# Lack of Upgradeability

### Summary
The contract is not upgradeable, meaning once deployed, it cannot be modified or improved later.

### Issue

- The contract uses a constructor instead of an initializer function.
- No proxy pattern (UUPS or Transparent Proxy) is implemented.
- Storage layout cannot be updated after deployment.

### Impact
If any bug is found later, the contract cannot be fixed without redeploying a new version.

### Recommandation
Make the contract upgradeable by using UUPSUpgradeable and an initialize() function.
