# The `PriceFeed` contract doesn't check stale price, causing protocol get a inaccurate price

### Summary

The `PriceFeed.sol::_getChainlinkPrice` does not check for a stale price, which may cause the user to receive an bad price, negatively impacting the user experience.

### Root Cause

[PriceFeed.sol::_getChainlinkPrice](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/PriceFeed.sol#L57-L62)
```Solidity
    function _getChainlinkPrice(Data memory data) internal view returns (uint256) {
        (, int256 answer,, /* uint256 updatedAt */ ,) = AggregatorV3Interface(data.feed1).latestRoundData();
        require(answer > 0);
        // require(block.timestamp - updatedAt <= heartbeat);
        return uint256(answer);
    }
```

### Internal Pre-conditions

None.

### External Pre-conditions

None.

### Attack Path

None.

### Impact

Both the user and the protocol may receive a bad price, affecting the entire protocol.
