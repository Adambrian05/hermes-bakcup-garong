# Stale prices may lead to incorrect calculations for values

### Title
Stale price may lead to incorrect calculations for values

### Severity
Medium

### Difficulty
Medium



### Target
src/Leverager.sol

## Description
In `leverager.sol` contracts chPrice0, chPrice1 and  bprice are retrieved from PriceFeed contract using `getPrice` function. These prices are used in further calculations such as estimating values:
`usdValue` in `_calculateTokenValues`,
`totalDenom` in `isLiquidatable`,
`up.initCollateralValue` in `openLeveragedPosition`,
`borrowedValue` in liquidatePosition` functions. 

However result price returned from `getPrice` function not check for being stale neither in `getPrice` nor in other places. We can see line 
`// require(block.timestamp - updatedAt <= heartbeat);` commented out in function `_getChainlinkPrice`.



## Recommendations
it is better to add check in PriceFeed contract, rather then in each places in code where this function is used.
