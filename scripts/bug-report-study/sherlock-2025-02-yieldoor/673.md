# Possible incorrect fees for the vesting position

### Summary
Possible incorrect fees for the vesting position

### Root Cause
In `Strategy.sol:167`, where the wrong variable `mainPosition.tickUpper` is being used instead of `vestPosition.tickUpper` when calling `collectPositionFees` for vesting position.

### Internal Pre-conditions

None

### External Pre-conditions

None

### Code snippet
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Strategy.sol#L167


### Attack Path

1. User calls the `collectFees` function

### Impact

The strategy contract may receive incorrect values of fees.

### PoC

_No response_

### Mitigation

```diff

        if (ongoingVestingPosition) {
-            collectPositionFees(vestPosition.tickLower, mainPosition.tickUpper);
+            collectPositionFees(vestPosition.tickLower, vestPosition.tickUpper);
        }

```
