# Insufficient Observation Cardinality Check in Uniswap V3 Pool

### Summary

Insufficient observation cardinality will cause a failure to execute for users as the checkPoolActivity() function will always return false when observationCardinality * timeOfBlock is less than 300

### Root Cause

In the Strategy.sol the checkPoolActivity() function returns false when there aren't enough observations.

### Internal Pre-conditions

Uniswap V3 Pool needs to have observationCardinality set to be more than 300/timeOfBlock

### External Pre-conditions

none

### Attack Path

1. There is a check [_requirePriceWithInRange ](https://github.com/sherlock-audit/2025-02-yieldoor/blob/b5a0f779dce4236b02665606adb610099451a51a/yieldoor/src/Strategy.sol#L407)in rebalance(), compund() and addVesting() positions in the strategy.sol contract. This checks calls  [checkPoolActivity()](https://github.com/sherlock-audit/2025-02-yieldoor/blob/b5a0f779dce4236b02665606adb610099451a51a/yieldoor/src/Strategy.sol#L310) to check for manipulations in the pool.
2. It iterates through available observations
3. Function returns false due to insufficient observations before reaching TWAP period
4. rebalance(), compund() and addVesting() fails to execute due to the false return value



### Impact

This would result in a user depositing assets to the strategy contract, but the funds will remain idle it would be impossible to deposit those funds in the main and secondary position because rebalance() function won't work. Therefore there will be no fees collected for the user. Core functionalities of the protocol cannot be executed like rebalance(), compound(), or addVestingPosition() functions.

_No response_

### Mitigation

Add a check and increase observation cardinality if needed:


```solidity
function checkPoolActivity() public view returns (bool) {
    (
        ,
        int24 tick,
        uint16 currentIndex,
        uint16 observationCardinality,
        ,
        ,

    ) = IUniswapV3Pool(pool).slot0();

    // Add minimum required cardinality check
    uint16 minCardinality = uint16(300 / timeOfBlock) + 1;
    if (observationCardinality < minCardinality) {
        IUniswapV3Pool(pool).increaseObservationCardinalityNext(minCardinality);
    }

    // Rest of the function...
}
```
