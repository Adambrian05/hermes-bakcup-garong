# While `deploying`  strategy there is no check if `vault` has the same `token0` and `token1`.

### Summary

While constructing the statergy, `token0`, `token1`. are derived from the `unipool` address. however, the `vault` may have `different`. token address, and there is no check while deploying. due to the lack of the check to revert(). this can led to issues while trying to deposit and withdrawing

### Root Cause

```javascript
  constructor(
        address uniPool,
        address _vault,
        address _rebalancer,
        address _feeRecipient
    ) Ownable(msg.sender) {
        token0 = IUniswapV3Pool(uniPool).token0();
        token1 = IUniswapV3Pool(uniPool).token1();
        pool = uniPool;
        vault = _vault;
```
while setting `vault` there is no check if `token0 == vault.token0 && token1 == vault.token1`

### Mitigation

```javascript
  constructor(
        address uniPool,
        address _vault,
        address _rebalancer,
        address _feeRecipient
    ) Ownable(msg.sender) {
        token0 = IUniswapV3Pool(uniPool).token0();
        token1 = IUniswapV3Pool(uniPool).token1();
        pool = uniPool;

        vault = _vault;
        require(token0 == vault.token0 && token1 == vault.token1, "tokens must match")
```
