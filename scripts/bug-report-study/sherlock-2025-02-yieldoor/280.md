# In the withdraw() function of Leverager.sol, the calculation for repayFromWithdraw is incorrect.

### Summary

In the withdraw() function of Leverager.sol, the calculation for repayFromWithdraw is incorrect. In case either of the tokens is the denomination token, we directly take from it. On line 232 of Leverager.sol, when borrowed == up.token1, the value of repayFromWithdraw is incorrectly set.
https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/Leverager.sol#L232
```solidity
        if (borrowed == up.token0) {
            uint256 repayFromWithdraw = amountOut0 < owedAmount ? amountOut0 : owedAmount;
            owedAmount -= repayFromWithdraw;
            amountOut0 -= repayFromWithdraw;
        } else if (borrowed == up.token1) {
            uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut0 : owedAmount;
            owedAmount -= repayFromWithdraw;
            amountOut1 -= repayFromWithdraw;
        }
```
In the code above, when borrowed == up.token1, the value of repayFromWithdraw should be set as follows:
```solidity
uint256 repayFromWithdraw = amountOut1 < owedAmount ? amountOut1 : owedAmount;
```
