# Interest Approximation Error will Cause Protocol Insolvency for Lenders

### Summary

 **Interest Accrual Approximation Error** : Incorrect interest calculation leads to undercollateralization.
The use of linear interest approximation in InterestRateUtils.sol will cause protocol insolvency for lenders as the system undercounts borrower debt by 12%+ annually, leading to undercollateralization.

### Root Cause

The code uses a binomial approximation for compounded interest that can be less accurate over longer periods. If the actual interest is higher than calculated, the protocol might not collect enough interest, leading to undercollateralization. By borrowing a large amount when rates are low and holding until the actual interest owed exceeds what the protocol accounts for. Over time, the LendingPool might not have enough funds to cover withdrawals because the interest wasn't properly accrued.

In InterestRateUtils.sol#calculateCompoundedInterest() function:
```solidity
 function calculateCompoundedInterest(uint256 rate, uint128 lastUpdateTimestamp, uint256 currentTimestamp)
        internal
        pure
        returns (uint256)
    {
        //solium-disable-next-line
        uint256 exp = currentTimestamp - (uint256(lastUpdateTimestamp));

        if (exp == 0) {
            return PRECISION;
        }

        uint256 expMinusOne = exp - 1;

        uint256 expMinusTwo = exp > 2 ? exp - 2 : 0;

        uint256 ratePerSecond = rate / SECONDS_PER_YEAR;

        uint256 basePowerTwo = ratePerSecond * ratePerSecond / PRECISION;

        uint256 basePowerThree = basePowerTwo * ratePerSecond / PRECISION;

        // Third-order binomial approximation
@>        uint256 secondTerm = exp * expMinusOne * basePowerTwo / 2;
@>        uint256 thirdTerm = exp * expMinusOne * expMinusTwo * basePowerThree / 6;

@>        return (PRECISION) + (ratePerSecond * exp) + (secondTerm) + (thirdTerm);
    }
```
The protocol uses a truncated Taylor series instead of exponential compounding, creating growing errors at high rates/durations.

1. Borrower takes $1M loan at 200% APR
2. Protocol calculates debt using approximation: Debt = 1M * (1 + 2 + 2 + 1.333) = $6.333M after 1 year

4. Protocol becomes undercollateralized by $1.056M (14.3%)
