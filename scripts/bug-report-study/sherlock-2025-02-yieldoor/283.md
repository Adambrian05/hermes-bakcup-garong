# Multisig accounts can block the access to price feeds

### Summary

`latestRoundData()` call should be wrapped by a try-catch block because multisig accounts can block the access to price feeds, leading the execution to revert.

### Root Cause

In [`PriceFeed.sol`](https://github.com/sherlock-audit/2025-02-yieldoor/blob/main/yieldoor/src/PriceFeed.sol?plain=1#L58) `latestRoundData()` call should be wrapped by a try-catch block because `multisigs can immediately block access to price feeds at will`. More info at https://blog.openzeppelin.com/secure-smart-contract-guidelines-the-dangers-of-price-oracles/
