# Missing Deployment Validation

### Summary

The `StakerFactory.sol` contract contains a medium-severity vulnerability where the `newStrategy` function directly overwrites existing deployments without validation. When a new strategy is deployed for an asset that already has a deployed strategy, the function overwrites the `deployments[_asset]` mapping entry, causing the reference to the previous strategy to be permanently lost while the old strategy contract remains deployed on-chain.


### Root Cause

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StakerFactory.sol#L32-L48

The function directly overwrites `deployments[_asset]` without checking if a deployment already exists for the given asset and the function is not access-controlled.

 When a new strategy is deployed for an existing asset, the mapping is updated to point to the new strategy, effectively "losing" the reference to the previous deployment.

### Internal Pre-conditions

none

### External Pre-conditions

none

### Attack Path

1. Management deploys Strategy A for Asset X:
   ```solidity
   address strategyA = factory.newStrategy(assetX, "Strategy A", ...);
   // deployments[assetX] = strategyA
   ```

2. Later, Management deploys Strategy B for the same Asset X:
   ```solidity
   address strategyB = factory.newStrategy(assetX, "Strategy B", ...);
   // deployments[assetX] = strategyB (overwrites strategyA reference)
   ```

3. **Result**: 
   - Strategy A still exists on-chain but is no longer accessible via the factory
   - `deployments[assetX]` now points to Strategy B
   - Any system depending on the factory to find the strategy for Asset X will get Strategy B instead of Strategy A

### Impact

Previously deployed strategies become unreachable through the factory contract, potentially causing integration issues with systems that rely on the factory to locate strategies.

### Mitigation

Add a validation check to prevent duplicate deployments:

```solidity
function newStrategy(
    address _asset,
    string memory _name,
    address _management,
    address _performanceFeeRecipient,
    address _keeper
) external onlyManagement returns (address) {
    // Check that no deployment exists for this asset
    require(deployments[_asset] == address(0), "StakerFactory: strategy already deployed for asset");
    
    // Deploy a new Staker strategy
    address newStaker = Clones.clone(ORIGINAL);
    
    IStrategyInterface(newStaker).initialize(
        _asset,
        _name,
        _management,
        _performanceFeeRecipient,
        _keeper
    );

    // Store the deployment
    deployments[_asset] = newStaker;

    emit NewStaker(newStaker, _asset);

    return newStaker;
}
```
