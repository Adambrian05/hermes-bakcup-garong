# Lake of access control in `StakerFactory::newStrategy` function allows anyone to create strategy with desired asset

### Summary

Lake of access control in `StakerFactory::newStrategy` function
Description: In `StakerFactory::newStrategy` function there is lack of access control to create new strategy (st-yBold). there is no parameter checked weather who can access the function lead to open the gate to all. allows anyone to create their strategy for any of the `asset`.

### Root Cause

In `StakerFactory.sol:32` function there is lack of access control to create new strategy (st-yBold). there is no parameter checked weather who can access the function lead to open the gate to all users. allows anyone to create their strategy for any of the `asset`.

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StakerFactory.sol?plain=1#L32
