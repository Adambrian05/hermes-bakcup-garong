# Strategy Overwrite Vulnerability in StrategyFactory.sol

### Summary

Missing check in the StrategyFactory.so's newStrategy allowed to overwrite the old Strategy deployed.

### Root Cause

The vulnerable code in the `newStrategy` function unconditionally overwrites the deployments mapping:

```solidity
function newStrategy(
    address _addressesRegistry,
    address _asset,
    string calldata _name
) external virtual onlyManagement returns (address) {
    IStrategyInterface _newStrategy = IStrategyInterface(address(new Strategy(_addressesRegistry, _asset, _name)));


    emit NewStrategy(address(_newStrategy), _asset);

    // VULNERABILITY: Unconditional overwrite without existence check
    deployments[_asset][_newStrategy.SP()] = address(_newStrategy);
    return address(_newStrategy);
}
```
https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StrategyFactory.sol#L38-L59

### Internal Pre-conditions

none

### External Pre-conditions

none

### Attack Path

1. create one strategy with one asset 
2. create another stratergy using the same asset the old one is gone

### Impact

- Previously deployed strategies become inaccessible through the factory's lookup mechanism
- The factory's internal state no longer reflects all actual deployments
- If strategies contain funds, they may become harder to manage without proper registry tracking

### Mitigation

```solidity
function newStrategy(
    address _addressesRegistry,
    address _asset,
    string calldata _name
) external virtual onlyManagement returns (address) {
    IStrategyInterface _newStrategy = IStrategyInterface(address(new Strategy(_addressesRegistry, _asset, _name)));
    
    // Get the stability pool address
    address stabilityPool = _newStrategy.SP();
    
    // Check if strategy already exists for this asset-SP combination
    require(
        deployments[_asset][stabilityPool] == address(0), 
        "Strategy already exists for this asset and stability pool"
    );

    _newStrategy.setPerformanceFeeRecipient(performanceFeeRecipient);
    _newStrategy.setKeeper(keeper);
    _newStrategy.setPendingManagement(management);
    _newStrategy.setEmergencyAdmin(emergencyAdmin);

    emit NewStrategy(address(_newStrategy), _asset);

    deployments[_asset][stabilityPool] = address(_newStrategy);
    return address(_newStrategy);
}
```
