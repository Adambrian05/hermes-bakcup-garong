# The strategy will face reversion issues during time-sensitive tend calls

### Summary

The governance-only modifier in the `setStartingPrice` function will cause a failure to execute the [`_tend()`](https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/88a3b89c05fd6e59ec130c79659195cd05d872af/yv3-liquityv2-sp-strategy/src/Strategy.sol#L225) function for the strategies as the auction contract will revert when called by non-governance actors.

### Root Cause

In Auction.sol, the `setStartingPrice` function has a governance-only modifier that prevents non-governance actors from setting the starting price.

- The `setStartingPrice` function is restricted to governance calls only, which leads to reversion when the `_tend` function attempts to call it.

### Internal Pre-conditions

1. The keeper must call `_tend` to initiate the auction process.
2. The auction must be enabled for the collateral being auctioned.
3. The strategy must have governance set to allow the call to `setStartingPrice`.

### External Pre-conditions

1. The auction contract must be active and not already in the process of an auction.
2. The collateral must be available for the strategy to claim.

### Attack Path

1. **Keeper calls `_tend` to initiate the auction process.**
2. The function checks if there is collateral gain to claim and calls `claim()`.
3. The function checks if the auction is active and if the available collateral is zero, calling `settle()` if necessary.
4. The function attempts to set the starting price using `setStartingPrice`, which is restricted to governance-only calls.
5. If the caller is not governance, the transaction reverts, preventing the auction from being initiated.

### Impact

The strategy suffers from a failure to execute the tend function, which is critical for maintaining the stability of the collateral-to-BOLD exchange rate. This will cause the time-sensitive `_tend()` function to fail and the 1:1 peg cannot happen.
