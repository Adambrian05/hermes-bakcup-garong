# Collateral rewards can become irrecoverably locked

### Summary

When the strategy earns collateral rewards, `_tend()` must transfer that collateral into an auction and kick it off. However, if `setStartingPrice()` ever reverts because the oracle returns zero/unreliable or there’s already an active auction, the entire `_tend()` call aborts, leaving the collateral permanently stuck in the strategy contract with no escape hatch.

### Root Cause

- `_tend()` is the only code path that moves COLL out of the strategy.
- `setStartingPrice(...)` will revert if the oracle reports `price == 0` or `isOracleDown == true`, or if there’s already an active auction on COLL.
- `sweep()` explicitly forbids rescuing COLL, and neither emergency nor shutdown paths withdraw on-contract collateral.

### Internal Pre-conditions

- `COLL.balanceOf(address(this)) > dustThreshold` (so `_tend()` even attempts to auction).
- `AUCTION.available(address(COLL)) == 0` (no collateral already sitting in the auction contract).
- `block.basefee <= maxGasPriceToTend` (so `_tendTrigger()` permits calling `_tend()`).

### External Pre-conditions

- `COLL_PRICE_ORACLE.fetchPrice()` returns `(0, true)` or non-primary source.
- An attacker or condition keeps `AUCTION.isActive(COLL) == true` (e.g. front-runs settlement with a 1-token “dust” auction).

### Attack Path

- Strategy accumulates collateral rewards via the Stability Pool.
- Keeper calls `tend()` when `isCollateralGainToClaim() == true`.
- In `_tend()`, `setStartingPrice(...)` reverts because the price is zero or an auction remains active.
- The revert aborts the rest of `_tend()`, so `COLL.safeTransfer(...)` and `kick(...)` never execute.
- `sweep(COLL)` is disallowed, and emergency/shutdown functions ignore on-chain COLL. Collateral remains stranded forever.

### Impact

**Invariant break**: yBOLD share-price remains pegged at 1 BOLD despite extra collateral value stranded on-chain.
**Under-reported TVL:** `estimatedTotalAssets()` omits locked collateral.
**Lost yield**: Users (and st-yBOLD holders) lose access to potentially significant collateral rewards (well over $10 in value which can never be recovered under normal operation)

Medium severity under Sherlock’s criteria: 

> locks real funds indefinitely (DOS >1 week), causing a relevant loss (>0.01% and >$10) of user yield.

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.18;

import "forge-std/console2.sol";
import {Setup, ERC20, IStabilityPool} from "./utils/Setup.sol";
import {IAuction} from "../interfaces/IAuction.sol";
import {IPriceFeed} from "../interfaces/IPriceFeed.sol";

/**
 * @title Collateral Stranding POC
 * @notice Demonstrates the critical vulnerability where collateral gets permanently stuck
 * in the strategy when setStartingPrice() reverts during _tend() execution.
 *
 */
contract CollateralStrandingPOC is Setup {

    function setUp() public virtual override {
        super.setUp();
        vm.prank(management);
        strategy.allowDeposits();
    }


    function test_CollateralPermanentlyStrandedDueToOracleFailure() public {
        uint256 collateralAmount = 5 ether; // 5 ETH worth ~$15,000
        uint256 depositAmount = 1000 ether; // Need some assets for tendTrigger to work

        console2.log("=== DEMONSTRATING CRITICAL COLLATERAL STRANDING BUG ===");
        console2.log("");

        // STEP 0: Setup strategy with some assets (required for tendTrigger)
        console2.log("STEP 0: Setup strategy with assets");
        mintAndDepositIntoStrategy(strategy, user, depositAmount);
        console2.log("Strategy total assets:", strategy.totalAssets());
        console2.log("");

        // STEP 1: Strategy accumulates collateral (normal operation)
        console2.log("STEP 1: Strategy receives collateral rewards");
        airdrop(ERC20(strategy.COLL()), address(strategy), collateralAmount);
        assertEq(ERC20(strategy.COLL()).balanceOf(address(strategy)), collateralAmount);
        console2.log("Collateral in strategy:", collateralAmount);
        console2.log("USD value:", collateralAmount * ethPrice() / 1e18);
        console2.log("");

        // STEP 2: Verify _tend() should be triggered (normal flow)
        console2.log("STEP 2: Verify tend trigger is active");
        (bool trigger,) = strategy.tendTrigger();
        assertTrue(trigger, "Tend should be triggered with collateral to auction");
        console2.log("Tend trigger active:", trigger);
        console2.log("");

        // STEP 3: Oracle fails/manipulated (returns zero price)
        console2.log("STEP 3: Oracle failure - returns zero price");
        vm.mockCall(
            strategy.COLL_PRICE_ORACLE(),
            abi.encodeWithSelector(IPriceFeed.fetchPrice.selector),
            abi.encode(0, false) // CRITICAL: price = 0
        );
        console2.log("Oracle mocked to return price = 0");
        console2.log("");

        // STEP 4: _tend() reverts, collateral gets stuck
        console2.log("STEP 4: _tend() reverts due to setStartingPrice(0)");
        vm.prank(keeper);
        vm.expectRevert(); // setStartingPrice(0) reverts with "starting price"
        strategy.tend();
        console2.log("_tend() reverted as expected");
        console2.log("");

        // STEP 5: Verify collateral is stranded
        console2.log("STEP 5: Collateral is now PERMANENTLY STRANDED");
        assertEq(ERC20(strategy.COLL()).balanceOf(address(strategy)), collateralAmount);
        assertEq(ERC20(strategy.COLL()).balanceOf(strategy.AUCTION()), 0);
        console2.log("Collateral stuck in strategy:", ERC20(strategy.COLL()).balanceOf(address(strategy)));
        console2.log("Collateral in auction:", ERC20(strategy.COLL()).balanceOf(strategy.AUCTION()));
        console2.log("");

        // STEP 6: Prove NO recovery mechanism exists
        console2.log("STEP 6: Proving NO recovery mechanism exists");
        vm.clearMockedCalls(); // Fix oracle

        // 6. Emergency shutdown doesn't help
        console2.log("6. Testing emergency shutdown");
        vm.prank(management);
        strategy.shutdownStrategy();
        assertEq(ERC20(strategy.COLL()).balanceOf(address(strategy)), collateralAmount);
        console2.log("Emergency shutdown complete - collateral still stranded");


        // FINAL RESULT
        console2.log("=== FINAL RESULT: PERMANENT COLLATERAL LOSS ===");
        console2.log("Stranded collateral:", collateralAmount);
        console2.log("USD value lost:", collateralAmount * ethPrice() / 1e18);
        console2.log("Recovery mechanism: NONE");
        console2.log("");
        console2.log("BUG CONFIRMED: Collateral permanently stranded due to");
        console2.log("setStartingPrice() revert in _tend() with no escape hatch");
    }
}
```
