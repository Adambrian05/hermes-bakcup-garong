# Incorrect Accountant implementation breaks yBOLD-BOLD expected ratio

### Summary

The Accountant sets 100% of the gains as fees, which are minted as vault shares. However the logic is flawed, as this doesn't maintain a 1:1 ratio between BOLD and yBOLD, as specified in the requirements.

### Root Cause

The yBOLD system sets up an accountant that reports its fees as the total of the vault gains. The intention here is to keep a balance between BOLD and yBOLD, while the actual yield is sent to and distributed between stakers.

In Yearn V3 vaults, the accountant's fees are minted as shares (see https://github.com/yearn/yearn-vaults-v3/blob/104a2b233bc6d43ba40720d68355b04d2dc31795/contracts/VaultV3.vy#L1115):

```vyper
    if loss + total_fees > 0:
        # The amount of shares we will want to burn to offset losses and fees.
        shares_to_burn = self._convert_to_shares(loss + total_fees, Rounding.ROUND_UP)

        # If we have fees then get the proportional amount of shares to issue.
        if total_fees > 0:
            # Get the total amount shares to issue for the fees.
            total_fees_shares = shares_to_burn * total_fees / (loss + total_fees)
```

```vyper
    # Issue shares for fees that were calculated above if applicable.
    if total_fees_shares > 0:
        # Accountant fees are (total_fees - protocol_fees).
        self._issue_shares(total_fees_shares - protocol_fees_shares, accountant)

        # If we also have protocol fees.
        if protocol_fees_shares > 0:
            self._issue_shares(protocol_fees_shares, protocol_fee_recipient)
```

The value reported by the accountant is converted to shares, and then those are minted to the accountant.

However, this doesn't ensure a 1:1 ratio between assets and shares. For example:

1. Suppose we have 10 assets and 10 shares.
2. The vault gains 5 assets, we now have 15 assets and 10 shares.
3. Accountant returns `fees = 5`.
4. Accountant is minted `5 * 10 / 15 = 3.33` shares.
5. We now have 15 assets and 13.33 shares.


### Internal Pre-conditions

1. Vault has gains.
2. Manager calls `process_report()` in the vault.
3. Vault calls accountant to obtain fees.

### External Pre-conditions

N/A.

### Attack Path

N/A, the incorrect logic is always executed.

### Impact

The ratio between yBOLD and BOLD is not balanced, as required. This means not all yield goes to stakers, as some of the gains are leaked to people who don't stake.

_No response_

### Mitigation

The implementation should mint an amount of shares so that total assets and total supply are equal.
