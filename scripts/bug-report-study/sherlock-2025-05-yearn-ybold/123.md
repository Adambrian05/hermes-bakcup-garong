# _harvestAndReport() doesn't report all the profits

### Summary

The _harverstAndReport call the _estimatedTotalAssets which doesn't include the current collateralGain and the curent yieldGain from Stability pool.
As the report is false, users will have a false report about profits and losses from the strategy.


### Root Cause

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L214

The _harverstAndReport must report all the assets as specified here :

https://docs.yearn.fi/developers/v3/strategy_writing_guide#_harvestandreport

_totalAssets: A trusted and accurate account for the total amount of 'asset' the strategy currently holds including loose funds.

Best Practice:

The returned value is used to account for all strategy profits, losses and fees so care should be taken when relying on oracle values, LP prices etc. that have the potential to be manipulated.

And here :
https://docs.yearn.fi/developers/smart-contracts/V3/BaseStrategy#_harvestandreport
 A trusted and accurate account for the total amount of 'asset' the strategy currently holds including idle funds.


### Internal Pre-conditions

None

### External Pre-conditions

Existing yield gains or collateral gains for the strategy in the stability pool.

### Attack Path

None

### Impact


Medium :
Breaks core contract functionality, rendering the contract useless or leading to loss of funds that's relevant to the affected party.

The integration of the strategy is not respected and it could lead to loss of funds to the users :

1. **Irredeemable Assets**:

   * Creates a discrepancy between reported and actually available assets

2. **Incorrect Fee Distribution**:

   * Performance and protocol fees are calculated on deflated profits

   * Fee recipients receive shares backed by diluted assets
