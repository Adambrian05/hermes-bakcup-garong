# _harvestAndReport() function doesn't include claims

### Summary

As _harvestAndReport current implementation only deploy avalaible assets, this function doesn't respect the specification of a _harvestAndReport  function of a yearn v3 strategy : 

https://docs.yearn.fi/developers/v3/strategy_writing_guide#_harvestandreport
Purpose:  Called during every report. This should harvest and sell any rewards, reinvest any proceeds, perform any position maintenance and return a full accounting of a trusted amount denominated in the underlying asset the strategy holds.

Some rewards must be lost


### Root Cause

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L208

The function doesn't call claimAllCollGains  or other weep functions before the deploy call.

### Internal Pre-conditions

None

### External Pre-conditions

Existence of claimable collateral gains.

### Attack Path

None

### Impact

1. **Irredeemable Assets**:

   * Creates a discrepancy between reported and actually available assets

### PoC

None.

### Mitigation

Add  a claimAllCollGains before the deploy.
