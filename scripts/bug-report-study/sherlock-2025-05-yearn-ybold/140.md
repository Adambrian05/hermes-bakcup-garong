# _tend is DOSed when there is an Auction active as the AUCTION.settle doesn't sweep dust amounts

### Summary

When the keeper wants to call `tend` when an auction is already running, he cant even if the intended amounts to sell are sold.

This is because of a front running attack where minute amounts can be deposited and the auction that is still active. The auction hence continues but `tend` call reverts as both `kick` and `settle` can't be done.

### Root Cause

we see that the `setStartingPrice` will revert if there are active auctions

```solidity
    function setStartingPrice(
        uint256 _startingPrice
    ) external virtual onlyGovernance {
        require(_startingPrice != 0, "starting price");
    
        // Don't change the price when an auction is active.
        address[] memory _enabledAuctions = enabledAuctions;
        for (uint256 i = 0; i < _enabledAuctions.length; ++i) {
            require(!isActive(_enabledAuctions[i]), "active auction"); ///@audit reverts here
        }

        startingPrice = _startingPrice;

        emit UpdatedStartingPrice(_startingPrice);
    }
```

Auction.settle can be effectively DOSed using minute deposits as well frontrunning `tend` calls

```solidity
    function settle(address _from) external virtual {
        require(isActive(_from), "!active");
        require(ERC20(_from).balanceOf(address(this)) == 0, "!empty"); //@audit can deposit tokens to prevent settling

        auctions[_from].kicked = uint64(0);
    }
```

### Attack Path

1. Auction is active but sold all intended amounts
2. Keeper tries to call tend
3. Attacker frontrunds tend with minute deposit to disrupt `settle`
4. Keeper tend call fails as the Auction hasn't settled

### Impact

The protocol cannot call time sensitive `tend` function

### Mitigation

if the `AUCTION.available(address(COLL))` is lesser than dust, simply call `AUCTION.sweep(address(COLL))`

then proceed to call `settle`

```diff
    /// @inheritdoc BaseStrategy
    function _tend(
        uint256 /*_totalIdle*/
    ) internal override {
        if (isCollateralGainToClaim()) claim();
-        if (AUCTION.isActive(address(COLL)) && AUCTION.available(address(COLL)) == 0) AUCTION.settle(address(COLL));
+       if (AUCTION.isActive(address(COLL)) && AUCTION.available(address(COLL)) <= dustThreshold) {
+       AUCTION.sweep(address(COLL));
+       AUCTION.settle(address(COLL));
+       }
```
