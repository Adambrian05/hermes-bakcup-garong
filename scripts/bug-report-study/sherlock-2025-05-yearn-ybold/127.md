# Missing Deposit Pause Function

### Summary

Once deposits are enabled using `Strategy::allowDeposits`, there’s no way to turn them off. This means the team can't pause deposits during emergencies like a bug, exploit, or external issue. It removes an important tool for controlling risk.

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L129-L131

### Root Cause

The contract sets `openDeposits = true` using the `Strategy::allowDeposits`, but there's no function to set `openDeposits = false`. This one way switch makes it impossible to pause deposits after they're turned on.

### Internal Pre-conditions

- The contract has `openDeposits` set to true.
- There is no admin function to set `openDeposits = false`.

### External Pre-conditions

- A serious bug, vulnerability, or market issue arises that requires stopping user deposits temporarily.
- Users are still allowed to interact with the contract and send deposits.

### Attack Path

- Team calls `allowDeposits` during normal operation.
- A vulnerability or market issue occurs.
- Team wants to stop new deposits to limit further exposure.
- No function exists to disable deposits.
- Users keep depositing into a potentially unsafe or compromised system.

### Impact

This is not an exploit in itself, but it exposes the protocol to serious operational risk:
- In a crisis, the team can’t stop inflows of new funds.
- More deposits could worsen the impact of a bug or exploit.
- Critical incident response is limited.
- This weakens the protocol’s safety controls even though `Strategy::_emergencyWithdraw` suggests the team planned for emergencies.

### PoC

- Team calls `allowDeposits` during normal operation.
- A vulnerability or market issue occurs.
- Team wants to stop new deposits to limit further exposure.
- No function exists to disable deposits.
- Users keep depositing into a potentially unsafe or compromised system.
- Users lose funds.

### Mitigation

- Implement bidirectional deposit control:
```solidity
function allowDeposits() external onlyManagement {
        openDeposits = !openDeposits;
    }
```
