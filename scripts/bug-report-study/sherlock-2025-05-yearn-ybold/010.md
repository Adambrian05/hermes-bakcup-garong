# Lack of access control in StakerFactory.sol::newStrategy()

### Summary

The `StakerFactory.newStrategy()` function lacks access control, allowing anyone to deploy new `LV2SPStakerStrategy` contracts and overwrite the factory's deployment tracking system.

### Root Cause

The `newStrategy()` function in `StakerFactory.sol` is marked as external without any access control modifiers, unlike the equivalent function in `StrategyFactory.sol` which properly implements `onlyManagement` restriction.

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StakerFactory.sol#L32-L48

```solidity
    function newStrategy(address _asset, string calldata _name) external virtual returns (address) {
        // tokenized strategies available setters.
        IStrategyInterface _newStrategy = IStrategyInterface(address(new Strategy(_asset, _name)));

        _newStrategy.setPerformanceFeeRecipient(performanceFeeRecipient);

        _newStrategy.setKeeper(keeper);

        _newStrategy.setPendingManagement(management);

        _newStrategy.setEmergencyAdmin(emergencyAdmin);

        emit NewStrategy(address(_newStrategy), _asset);

        deployments[_asset] = address(_newStrategy);
        return address(_newStrategy);
    }
```

This allows many function calls, which in turn will overwrite `deployments[_asset]` and the protocol operators will lose ability to reliably track which strategies were officially deployed.

### Attack Path

The attacker calls `newStrategy()` function with the same `_asset` parameter and changes the `deployments[_asset]` mapping.

### Impact

Multiple calls with the same `_asset` parameter overwrite `deployments[_asset]`, causing the factory to "forget" previously deployed strategies. So `isDeployedStrategy()` will return `false` for legitimate strategies that were overwritten. This means that external systems relying on `isDeployedStrategy()` for verification will incorrectly identify legitimate strategies as invalid.

### Mitigation

Add the `onlyManagement` modifier to restrict strategy deployment.
