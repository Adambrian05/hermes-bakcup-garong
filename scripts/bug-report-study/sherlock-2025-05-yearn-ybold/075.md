# newStrategy() Lacks Access Control, Allowing Unauthorized Strategy Deployment

### Summary

The missing access control on newStrategy will cause unauthorized deployment of arbitrary strategies for assets as any external actor will call newStrategy with any asset and name.

### Root Cause

In StakerFactory.sol:26, the newStrategy() function is marked as external and lacks any role-based access control. This allows any external caller to invoke it:

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StakerFactory.sol#L32-L48

### Internal Pre-conditions

There is no access control check within newStrategy().

The contract is deployed with public visibility for newStrategy().

### External Pre-conditions

An external user (or malicious actor) needs network access and a valid transaction to call newStrategy().

The user does not need any privileged role or permission.

### Attack Path

The attacker calls newStrategy(_asset, _name) with arbitrary _asset and _name.

The contract deploys a new strategy for _asset.

The attacker can repeat this to spam or flood the deployments mapping, causing confusion, mismanagement, or even high gas costs for management functions.

### Impact

The protocol suffers from unauthorized and potentially malicious strategy deployments.
The attacker gains the ability to flood the system with arbitrary strategies or deploy malicious contracts under the guise of legitimate strategies. This can lead to:

Loss of trust in deployment records.

Management confusion over active strategies.

Potential loss of funds if a malicious strategy is able to interact with the system.

### PoC

// Attacker's script (for demonstration)
factory.newStrategy(attackerAsset, "Attacker Strategy");

### Mitigation

Implement role-based access control (e.g., using Ownable or AccessControl, onlyManagement) for newStrategy(). Example:


require(msg.sender == management, "!management");
Or implement a more sophisticated role structure where only authorized deployers can call newStrategy().
