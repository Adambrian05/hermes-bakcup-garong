# Potential Reentrancy in Accountant.sol

### Summary

The `removeVault` function in Accountant.sol is vulnerable to reentrancy attacks due to making external calls before state changes. A malicious vault contract could reenter the function during the `IVault(vault).report()` call, potentially causing unauthorized vault removals or state inconsistencies.


### Root Cause

The `removeVault` function in Accountant.sol makes an external call to `IVault(vault).report()` before updating the state variables `vaults` and `vaultIndexes`. This violates the checks-effects-interactions pattern and allows for reentrancy attacks.

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/periphery/Accountant.sol#L221


### Internal Pre-conditions

1. Vault must be previously added.
2. Vault must have an asset with non-zero allowance.
3. Caller must have vault manager or fee manager role.

### External Pre-conditions

1. Attacker must have control of a malicious vault
2. Attacker must have a vault manager or a fee manager role
3. Attacker must be able to execute the attack before state changes

### Attack Path

1. Attacker deploys malicious vault that reenters on `safeApprove.`
2. Attacker calls removeVault with a malicious vault.
3. During `safeApprove`, malicious vault reenters `removeVault`..
4. State changes are manipulated before completion.


### Impact

- Unauthorized vault removals
- State inconsistencies in the Accountant contract
- Potential loss of funds or protocol disruption

### Mitigation

1. Implement the checks-effects-interactions pattern:

```solidity
function removeVault(address vault) external onlyOwner {
    require(vault != address(0), "Invalid vault");
    require(vaultIndexes[vault] != 0, "Vault not found");
    
    // 1. Update state first
    uint256 index = vaultIndexes[vault] - 1;
    uint256 lastIndex = vaults.length - 1;
    
    if (index != lastIndex) {
        address lastVault = vaults[lastIndex];
        vaults[index] = lastVault;
        vaultIndexes[lastVault] = index + 1;
    }
    
    vaults.pop();
    delete vaultIndexes[vault];
    
    // 2. Make external call last
    IVault(vault).report();
    
    emit VaultRemoved(vault);
}
```

2. Add a reentrancy guard:
```solidity
modifier nonReentrant() {
    require(!_reentrancyGuard, "ReentrancyGuard: reentrant call");
    _reentrancyGuard = true;
    _;
    _reentrancyGuard = false;
}
```
