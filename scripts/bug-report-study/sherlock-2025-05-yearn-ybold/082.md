# Unrestricted Strategy Deployment in `StakerFactory`

### Summary

The `StakerFactory` contract exposes a public `newStrategy` function that lacks access controls, enabling **any address to deploy arbitrary strategies** tied to the protocol’s infrastructure.

### Root Cause

The `newStrategy` function is declared as `external` with no access modifiers, allowing unrestricted deployment:  

```solidity  
    // @audit Anyone can call this function  
    function newStrategy(address _asset, string calldata _name) external virtual returns (address) {
        // tokenized strategies available setters.
        IStrategyInterface _newStrategy = IStrategyInterface(address(new Strategy(_asset, _name)));

       //...
     }
```  

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/StakerFactory.sol#L32

### Internal Pre-conditions

N/A

### External Pre-conditions

Don't have any external pre-condition

### Attack Path

Simple Access Control Issue

### Impact

Malicious strategies intercept protocol fees or rewards intended for legitimate strategies.

### PoC

_No response_

### Mitigation

Restrict `newStrategy` to authorized addresses using the `onlyManagement` modifier.
