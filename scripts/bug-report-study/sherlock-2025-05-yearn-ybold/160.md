# wrong check for auction upness leads to wrong bool returned for tendTrigger

### Summary

_tendTrigger returns false if the AUCTION contract has any sort of amounts left.

However this is false as the Auction can be inactive and it still have some amount left. a simple example is when the Auction ended with not selling completely.

### Root Cause

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L256-L257

wrong check here. uses balance instead of AUCTION.isActive

1.

### External Pre-conditions

1.

### Attack Path

1. Auction starts and ends
2. Auction has residual amount left
3. tend trigger is checked by keeper
4. tend trigger returns false
5. keeper doesn't call tend in cases where it should be called

### Impact

the tend trigger returns false in cases where it should return true leading to the keeper not calling the tend function
