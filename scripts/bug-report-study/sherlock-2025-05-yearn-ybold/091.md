# No minimum on `maxGasPriceToTend` allows management to lock user funds

### Summary

maxGasPriceToTend is used to ensure keepers don't go through a costly tend while the network is going through extreme stress. It has no restrictions what value it can be set to. If this variable is set to 0, auctions can never occur. This means that users will lose backing funds and never be able to withdraw owed funds from auctions.

### Root Cause

https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L138

This adjustment to maxGasPriceToTend has no restrictions on what the variable can be set to.

### Internal Pre-conditions

1. Management sets `maxGasPriceToTend` to 0

### External Pre-conditions

1. Liquidation occurs

### Attack Path

1. Management sees large liquidations incoming
2. They set `maxGasPriceToTend` to 0
3. Users lose backing BOLD and cannot be paid back with auctions so their owed funds are permanently locked

### Impact

The attacker doesn't inherently gain anything from the attacker but users suffer from locking of their funds. If done directly before a large amount of liquidations, this could affect a significant amount of user funds that can never then be withdrawn, resulting in permanent user loss.

### PoC

_No response_

### Mitigation

Add a minimum amount to `maxGasPriceToTend` to ensure management cannot permanently lock user funds.
