# The strategy will suffer significant price truncation for auction participants

### Summary

The incorrect decimal handling in the `_tend` function will cause a significant loss of precision for auction participants as the strategy will set the starting price incorrectly due to improper calculations.

### Root Cause

In [[src/Strategy.sol](https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/88a3b89c05fd6e59ec130c79659195cd05d872af/yv3-liquityv2-sp-strategy/src/Strategy.sol#L241), the starting price calculation in the `_tend` function has incorrect decimal handling.

- In `src/Strategy.sol:line_number`, the starting price is calculated using values that are all in 18 decimals, leading to a final result with 0 decimals precision.

### Internal Pre-conditions

1. The auction must be active for the collateral to be auctioned.
2. The `COLL` balance of the strategy must be greater than the `dustThreshold`.

### External Pre-conditions

1. The price fetched from the oracle must be valid and not return an error.
2. The auction must not already be active when `setStartingPrice` is called.

### Attack Path

1. **Keeper calls `_tend` to initiate the auction process.**
2. The function checks if there is collateral gain to claim and calls `claim()`.
3. The function checks if the auction is active and if the available collateral is zero, calling `settle()` if necessary.
4. The function calculates the total available collateral and the price from the oracle.
5. The function attempts to set the starting price using the formula which results in a value with 0 decimals precision due to incorrect handling of the decimal places.

```solidity
AUCTION.setStartingPrice(_available * _price / WAD * _bufferPercentage / WAD / WAD)
/// 18 decimals * 18 decimals / 18 decimals * 18 decimals / 18 decimals / 18 decimals = 0 decimals
```

6. The function transfers the collateral to the auction and calls `kick()` to start the auction.

### Impact

The auction’s price will be significantly truncated, which will lead to significant financial losses during the auction process. The strategy cannot accurately represent the value of the collateral being auctioned. Thus, the Auction's price of the collateral will be significantly reduced, making the gain a lot less.

### Mitigation

To mitigate this issue, the calculation for the starting price should ensure that the final result maintains the correct decimal precision.
