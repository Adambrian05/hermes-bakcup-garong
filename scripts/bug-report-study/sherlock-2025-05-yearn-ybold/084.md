# Incorrect `estimatedTotalAssets` function can lead to revert of `harvestAndReport` function

### Summary

The incorrect return value of `Strategy.estimatedTotalAssets` function will lead to incorrect handling in `BaseHealthCheck._executeHealthCheck()` function. This can lead to revert of 

### Root Cause

In [`estimatedTotalAssets`](https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L106) function, returns the total assets as follows:
```solidity
    function estimatedTotalAssets() public view returns (uint256) {
        return asset.balanceOf(address(this)) + SP.getCompoundedBoldDeposit(address(this));
    }
```

Looking into [liquidity](https://github.com/liquity/bold/) protocol, there is  [`getDepositorYieldGain`](https://github.com/liquity/bold/blob/main/contracts/src/StabilityPool.sol#L470) function in `StabilityPool.sol`.\
`getDepositorYieldGain` function returns the depositor's gained yield amount and the yield token is bold token, so the the total available asset of depositor is the sum of `getCompoundedBoldDeposit` and  `getDepositorYieldGain` function.\
You can easily check in `provideToSP` or `withdrawFromSP` function:
```solidity
    function provideToSP(uint256 _topUp, bool _doClaim) external override {
        _requireNonZeroAmount(_topUp);

        activePool.mintAggInterest();

        uint256 initialDeposit = deposits[msg.sender].initialValue;

        uint256 currentCollGain = getDepositorCollGain(msg.sender);
@>      uint256 currentYieldGain = getDepositorYieldGain(msg.sender);
@>      uint256 compoundedBoldDeposit = getCompoundedBoldDeposit(msg.sender);
@>      (uint256 keptYieldGain, uint256 yieldGainToSend) = _getYieldToKeepOrSend(currentYieldGain, _doClaim);
        uint256 newDeposit = compoundedBoldDeposit + _topUp + keptYieldGain;
        (uint256 newStashedColl, uint256 collToSend) =
            _getNewStashedCollAndCollToSend(msg.sender, currentCollGain, _doClaim);

        ...

        _updateDepositAndSnapshots(msg.sender, newDeposit, newStashedColl);
        boldToken.sendToPool(msg.sender, address(this), _topUp);
        _updateTotalBoldDeposits(_topUp + keptYieldGain, 0);
        _decreaseYieldGainsOwed(currentYieldGain);
@>      _sendBoldtoDepositor(msg.sender, yieldGainToSend);
        ...
    }
```
Explain about `provideToSP` function:\
The real deposit amount in while user provides bold token to SP, is `compoundedBoldDeposit + _topUp + keptYieldGain`.\
`keptYieldGain` is calculated from `_getYieldToKeepOrSend` function which returns the yield token amount to send to user with `_doClaim` flag.\
The logic of `provideToSP` function shows that the real bold token amount for deposit is the `compoundedBoldDeposit + currentYieldGain`.


`estimatedTotalAssets` function is called in [`_harvestAndReport`](https://github.com/sherlock-audit/2025-05-yearn-ybold/blob/main/yv3-liquityv2-sp-strategy/src/Strategy.sol#L214) function in `Strategy.sol`, and `_harvestAndReport` function is call in `harvestAndReport` function in [`BaseHealthCheck.sol`](https://github.com/yearn/tokenized-strategy-periphery/blob/master/src/Bases/HealthCheck/BaseHealthCheck.sol#L117-L160).

```solidity
    function harvestAndReport()
        external
        override
        onlySelf
        returns (uint256 _totalAssets)
    {
        // Let the strategy report.
        _totalAssets = _harvestAndReport();

        // Run the healthcheck on the amount returned.
        _executeHealthCheck(_totalAssets);
    }

    function _executeHealthCheck(uint256 _newTotalAssets) internal virtual {
        if (!doHealthCheck) {
            doHealthCheck = true;
            return;
        }

        // Get the current total assets from the implementation.
        uint256 currentTotalAssets = TokenizedStrategy.totalAssets();

        if (_newTotalAssets > currentTotalAssets) {
            require(
                ((_newTotalAssets - currentTotalAssets) <=
                    (currentTotalAssets * uint256(_profitLimitRatio)) /
                        MAX_BPS),
                "healthCheck"
            );
        } else if (currentTotalAssets > _newTotalAssets) {
            require(
                (currentTotalAssets - _newTotalAssets <=
                    ((currentTotalAssets * uint256(_lossLimitRatio)) /
                        MAX_BPS)),
                "healthCheck"
            );
        }
    }
```

Looking into `BaseHealthCheck.sol`, you can notice that the incorrect return value of `estimatedTotalAssets` function leads to in correct handling in `_executeHealthCheck` function of `BaseHealthCheck.sol`.\

### Mitigation

Update the `estimatedTotalAssets` function:
```diff
    function estimatedTotalAssets() public view returns (uint256) {
--      return asset.balanceOf(address(this)) + SP.getCompoundedBoldDeposit(address(this));
++      return asset.balanceOf(address(this)) + SP.getCompoundedBoldDeposit(address(this)) + SP.getDepositorYieldGain(address(this));
    }
```
