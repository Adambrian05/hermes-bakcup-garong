# Swap Calculation Between `UniswapV2Library` and `UniswapV2Router01` That Can Cause Fund Loss

## Description
The `GatewayCrossChain` contract has a critical issue in the Uniswap V2 swap implementation. The contract uses two different components for swap operations that should be consistent:
1. `UniswapV2Library` - For swap estimation calculations (CORRECT implementation)
2. `IUniswapV2Router01` - For actual swap execution (BUGGY implementation)

This issue occurs because `UniswapV2Router01` has a known bug in its `getAmountIn()` function that mistakenly calls `getAmountOut()` instead of `getAmountIn()`. This bug has been acknowledged by the Uniswap team and fixed in `UniswapV2Router02`.

https://docs.uniswap.org/contracts/v2/reference/smart-contracts/router-01

Note: this issue also occurs in the `GatewayTransferNative` contract on the same function, because it uses `IUniswapV2Router01`.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L323-L330

## Code Snippet
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L319-L326

## Root Cause
`_swapAndSendERC20Tokens()` function:
```solidity
// CALCULATION using Library (CORRECT)
uint[] memory amountsQuote = UniswapV2Library.getAmountsIn(
    UniswapFactory,
    gasFee,                                           
    getPathForTokens(targetZRC20, gasZRC20)          
);

// EXECUTION using Router01 (BUGGY)
uint[] memory amounts = IUniswapV2Router01(UniswapRouter)
    .swapTokensForExactTokens(
        gasFee,                                      
        amountInMax,                                 
        getPathForTokens(targetZRC20, gasZRC20),    
        address(this),                               
        block.timestamp + MAX_DEADLINE              
);
```
Bug in `UniswapV2Router01`:
```solidity
function getAmountIn(uint amountOut, uint reserveIn, uint reserveOut) 
    public pure override returns (uint amountIn) {
    // BUG: Calling getAmountOut instead of getAmountIn
    return UniswapV2Library.getAmountOut(amountOut, reserveIn, reserveOut);
    
    // SHOULD:
    // return UniswapV2Library.getAmountIn(amountOut, reserveIn, reserveOut);
}
```

## Impact
Users may lose more tokens than initially estimated.

## Scenario
1. User Initiates Cross-Chain Swap
- User wants to swap 1000 USDC to ETH on the destination chain
- Contract receives 1000 USDC on ZetaChain
2. Estimation Calculation (Using Library - TRUE)
```diff
// The contract calculates: "To earn 0.1 ETH gas fee, it takes 200 USDC"
uint[] memory amountsQuote = UniswapV2Library.getAmountsIn(
    UniswapFactory,
    0.1 ether, // gasFee
    [USDC, WETH] // path
);
// Result: amountsQuote[0] = 200 USDC (CORRECT)
```
3. Addition of Slippage Tolerance
```diff
// amountInMax = 200 + (1% slippage) = 202 USDC
uint amountInMax = 202 USDC;
```
4. Swap Execution (Using Router01 - BUGGY)
```diff
// Router01 internally uses the buggy getAmountIn()
// Router internal calculations went WRONG
uint[] memory amounts = router.swapTokensForExactTokens(
    0.1 ether,  // amountOut
    202,        // amountInMax  
    [USDC, WETH],
    address(this),
    deadline
);
```
5. Inconsistent Results
- Library estimates: 200 USDC needed
- Router01 executes with incorrect internal calculations
6. Impact on Users
- Users lose more tokens than estimated

## Recommendation
Use `IUniswapV2Router02`.
```solidity
// Change router constants
address public constant UniswapRouter = 0x7a250d5630B4cF539739dF2C5dAcb4c659F2488D; // Router02

// Update swap function
function _swapAndSendERC20Tokens(
    address targetZRC20,
    address gasZRC20,
    uint256 gasFee,
    uint256 targetAmount
) internal returns(uint256 amountsOut) {
    // Calculation still uses Library (correct)
    uint[] memory amountsQuote = UniswapV2Library.getAmountsIn(
        UniswapFactory,
        gasFee,
        getPathForTokens(targetZRC20, gasZRC20)
    );

    uint amountInMax = (amountsQuote[0]) + (slippage * amountsQuote[0]) / 1000;
    
    IZRC20(targetZRC20).approve(UniswapRouter, amountInMax);

    // Use the repaired Router02
    uint[] memory amounts = IUniswapV2Router02(UniswapRouter)
        .swapTokensForExactTokens(
            gasFee,
            amountInMax,
            getPathForTokens(targetZRC20, gasZRC20),
            address(this),
            block.timestamp + MAX_DEADLINE
        );

    // Consistency validation
    require(amounts[0] <= amountsQuote[0] + (slippage * amountsQuote[0]) / 1000, 
            "SWAP_AMOUNT_INCONSISTENT");
    
    require(IZRC20(gasZRC20).balanceOf(address(this)) >= gasFee, 
            "INSUFFICIENT_GAS_FOR_WITHDRAW");
    require(targetAmount - amounts[0] > 0, 
            "INSUFFICIENT_AMOUNT_FOR_WITHDRAW");

    IZRC20(gasZRC20).approve(address(gateway), gasFee);
    IZRC20(targetZRC20).approve(address(gateway), targetAmount - amounts[0]);

    amountsOut = targetAmount - amounts[0];
}
```
