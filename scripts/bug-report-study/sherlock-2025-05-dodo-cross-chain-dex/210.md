# Incorrect Boolean Conversion in Assembly Leading to Solana Account Permission Corruption

### Description
A critical issue was discovered in the `AccountEncoder` library in the `decompressAccounts()` function that uses assembly to parse Solana account data. The issue occurred in the `isWritable` boolean conversion process where the `mload(ptr)` assembly instruction read 32 bytes of data when it only needed 1 byte for the boolean value.

This caused the next 31 bytes of data (which are part of the next account's publicKey) to be read and affect the boolean conversion result, resulting in incorrect account permissions for Solana transactions.

## Code Snippet
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/libraries/AccountEncoder.sol#L35-L49

### Root Cause
The way `mload()` works in assembly is that `mload(ptr)` always reads 32 bytes from memory/calldata, even though we only need 1 byte for the Boolean and the remaining 31 bytes are unrelated data.

In `decompressAccounts()` function:
```solidity
assembly {
    for { let i := 0 } lt(i, len) { i := add(i, 1) } {
        // Load publicKey (32 bytes) - CORRECT
        mstore(acc, mload(ptr))
        ptr := add(ptr, 32)
        
        // ❌ PROBLEM: Load isWritable (boolean)
        mstore(add(acc, 32), iszero(iszero(mload(ptr))))
        //                              ^-- Reading 32 bytes when only 1 byte is needed
        ptr := add(ptr, 1) // Only advance 1 byte
    }
}
```
The `mload(ptr)` instruction always reads 32 bytes from memory/calldata, it cannot read partial bytes. The compressed account data format is:
```solidity
[32 bytes publicKey][1 byte isWritable][32 bytes next publicKey][1 byte next isWritable]...
```
When reading `isWritable`, what happens is:
```solidity
ptr pointing to: [1 byte isWritable][31 bytes from the next publicKey]
mload(ptr) read: 0x[isWritable][31 bytes publicKey next account]
```
Boolean Conversion Logic:
```solidity
iszero(iszero(mload(ptr)))
```
If the next 31 bytes of `publicKey` are not zero, then the boolean result will always be `true` even if the first byte (the original `isWritable`) is 0x00 (`false`).

## Impact
The majority of transactions to Solana will fail and users will lose platform fees.

## Scenario
Cross-Chain Swap Ethereum → Solana

1.	User Initiation:
```diff
// User sends swap from Ethereum to Solana with 3 accounts
Account[] memory accounts = [
    Account(userTokenAccount, false),    // Read-only

    Account(systemProgram, false)        // Read-only
];
```
2.	Data Encoding on Frontend:
```diff
Compressed data:

[userTokenAccount_32bytes][0x00]            // Account 1: read-only
[poolAccount_32bytes][0x01]                 // Account 2: writable
[systemProgram_32bytes][0x00]               // Account 3: read-only
```
3.	Cross-Chain Message to ZetaChain:
```diff
// Messages are sent via ZetaChain gateway
gateway.depositAndCall(targetContract, amount, asset, dstChainId, payload);
```
4.	Processing on `GatewayCrossChain.onCall()`:
```diff

```
5.	Problem Occurred in `Account Encoder.decompress Accounts()`:
```diff
Parsing Account 1:
ptr -> [0x00][poolAccount_first_31_bytes]
mload(ptr) = 0x00[poolAccount_first_31_bytes] ≠ 0
iszero(iszero(0x00[poolAccount...])) = true

Parsing Account 2:

iszero(iszero(0x01[systemProgram...])) = true
Result: Account 2 isWritable = true (CORRECT)

Parsing Account 3:

// Results depend on subsequent data
```

```diff

```

## Recommendation
Fix Boolean Extraction in Assembly in `decompressAccounts()` function.
```solidity
function decompressAccounts(bytes memory input) internal pure returns (Account[] memory accounts) {
    assembly {
        let ptr := add(input, 32)
        let len := add(shl(8, byte(0, mload(ptr))), byte(1, mload(ptr)))
        ptr := add(ptr, 2)

        accounts := mload(0x40)
        mstore(accounts, len)
        let arrData := add(accounts, 32)
        let freePtr := add(arrData, mul(len, 32))

        for { let i := 0 } lt(i, len) { i := add(i, 1) } {
            let acc := freePtr
            freePtr := add(freePtr, 64)

            // Load publicKey (32 bytes) - DO NOT CHANGE
            mstore(acc, mload(ptr))
            ptr := add(ptr, 32)

            // ✅ FIX: Extract only the first byte for a boolean
            let isWritableByte := byte(0, mload(ptr))
            mstore(add(acc, 32), iszero(iszero(isWritableByte)))
            ptr := add(ptr, 1)

            mstore(add(arrData, mul(i, 32)), acc)
        }

        mstore(0x40, freePtr)
    }
}
```
