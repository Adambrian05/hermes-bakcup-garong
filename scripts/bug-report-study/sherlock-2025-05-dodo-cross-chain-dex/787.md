# USDT missing return value, causing many function revert in `GatewaySend` contract.

### Summary

USDT missing return value, causing many function revert in `GatewaySend` contract.


### Root Cause

In Gatewaysend Contract, there are many functions using IERC20 Interface to interact with the tokens. But in the tokens that protocol uses, the USDT token contract on Ethereum mainnet does not comply with ERC20 standards, it does not return Bool value when called `approve`, `transfer` and `transferFrom`.

This leads to these following code:

1. [GatewaySend.sol#L184](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L184) and [GatewaySend.sol#L199:](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L199)

```solidity
        IERC20(asset).approve(address(gateway), amount);
```

2. [GatewaySend.sol#L239](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L239), [GatewaySend.sol#L317](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L317) and [GatewaySend.sol#L359](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L359)

```solidity
        IERC20(fromToken).transferFrom(msg.sender, address(this), amount),
```

3. [GatewaySend.sol#L372](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L372)

```solidity
        IERC20(toToken).transfer(evmWalletAddress, outputAmount);
```

will always be reverted.

### PoC

Create a new test file UsdtTest.t.sol in test folder.
Code:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import {Test} from "forge-std/Test.sol";
import {IERC20} from "@openzeppelin/contracts/token/ERC20/IERC20.sol";

contract UsdtTest is Test {
    // USDT address on ETH mainnet
    address usdtAddress = 0xdAC17F958D2ee523a2206206994597C13D831ec7;
    // A wallet with many USDT
    address holder = 0x559432E18b281731c054cD703D4B49872BE4ed53;
    address alice = makeAddr("alice");

    function setUp() external {}

    function test_usdt_revert() public {
        vm.prank(holder);
        IERC20(usdtAddress).transfer(alice, 100);
    }

    function test_usdt_revert_approve() public {
        vm.prank(holder);
        IERC20(usdtAddress).approve(alice, 100);
    }
}
```

### Mitigation


-   Use `forceApprove`, `safeTransfer` and `safeTransferFrom` from OpenZeppelin’s SafeERC20 library.

```diff
+    using SafeERC20 for IERC20;
```
