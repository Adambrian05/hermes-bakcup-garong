# Mismatched gas limits for EVM and Solana calls can cause cross-chain execution failures

### Summary

Using a single gasLimit value for both EVM‐style and Solana‐style calls—without adapting to each chain’s compute-unit model—will cause cross-chain withdrawals to fail when the provided limit is too low or too high for the destination chain’s requirements.

```solidity 
            onRevertGasLimit: gasLimit
```

### Root Cause

In withdrawAndCall, the same gasLimit variable is passed into both CallOptions.gasLimit and RevertOptions.onRevertGasLimit for every destination chain. There is no differentiation between EVM gas (measured in wei) and Solana compute-unit limits (measured in “compute units,” max ~1.4 M). As a result:

For Solana destinations, an EVM‐appropriate gasLimit (e.g. 200 k) is far below the 1.4 M compute-unit minimum, causing the call to run out of budget.

For EVM destinations, a Solana‐style compute-unit limit (e.g. 1 400 000) may exceed block gas limits or consume excessive fees, leading to reverts or unexpectedly high costs.

### Internal Pre-conditions

The contract’s gasLimit variable is setto an EVThe same gasLimit is reused for all chains, including Solana and EVMM-sized value, without chain-specific adjustment.

### External Pre-conditions

Solana: Transactions require up to 1.4 M compute units; anything less aborts.

EVM: Blocks impose a maximum gas per transaction (e.g. ~30 M gas on Ethereum), and typical calls budget far less.

### Attack Path

User initiates a cross-chain withdrawal to Solana.

withdrawAndCall packages CallOptions({ gasLimit }) and RevertOptions({ onRevertGasLimit: gasLimit }) using the EVM-sized gasLimit (e.g. 200 000).

The Solana side attempts to use 200 000 compute units—below the 1 400 000 minimum—so the transaction is dropped or aborted by the Solana runtime.

The user’s withdrawal never executes on Solana, and no fallback or retry occurs.

### Impact

cross-chain transfers to Solana (or other non-EVM chains) consistently fail due to under-budgeting compute units.
