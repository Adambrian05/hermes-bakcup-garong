# `onCall` method from GatewayTransferNative contract process fees incorrectly leading to fail transactions.

### Summary

In `GatewayTransferNative` contract's `onCall` method process fees incorrectly (when platformFee is enabled) especially `targetERC20` is different from `zrc20` parameter leading to failure of transaction.

### Root Cause

[GatewayTransferNative:370](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370)

```solidity
uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); // platformFee = 5 <> 0.5%
```

[GatewayTransfernative:393-395](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayTransferNative.sol#L393C11-L395C81)

```solidity
} else {
            // Swap on DODO Router
            uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
```

In `onCall` method from `GatewayTransferNative` contract, it calculate and transfer fees with given `amount` parameter first.
And it checks `targetZRC20` is same as `zrc20` and split the logic to transfer `targetZRC20` into external chain.
However, when `targetZRC20` is different from `zrc20` parameter (else statement in the code), it swaps entire amount (not substracting platformFeesForTx calculated in the above), and this will leading to transaction revert because of insufficient balance. (In case of platform fee is enabled).

### Internal Pre-conditions

Platform fee should be enabled by owner with `setFeePercent` method.


### External Pre-conditions

No external condition is needed.

### Attack Path

When `onCall` method is called (`depositAndCall` method from GatewaySend contract will call `onCall`) and `zrc20` paremeter is different from `targetZRC20` from decoded message it will cause failure.

### Impact

Impact: High
Protocol won't work because transaction will always revert.
Likelihood: Medium
Need to platformFee is enabled.
Impact: High

### Mitigation

```solidity
uint256 outputAmount = _doMixSwap(decoded.swapData, amount - platformFeesForTx, params);
```

Please swap only amount excluded with platformFees. (`amount - platformFeesForTx`)
