# Malicious user can drain tokens(BTC) from `GatewayTransferNative` using `withdraw`

### Summary

Malicious user can drain tokens from `GatewayTransferNative` because [`withdraw`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286-L304) lacks access control and [`_handleBitcoinWithdraw`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L458) approves incorrect amount.

### Root Cause

When user calls `GatewayTransferNative`.`withdrawToNativeChain` and `dstChainId == BITCOIN_EDDY`,  `_handleBitcoinWithdraw` is called.
For bitcoin, `GasToken` is  `BTC`,  so `decoded.targetZRC20` and  `GasToken` are same as `BTC`.
Here, it approves `outputAmount + gasFee` for `gateway`. But withdraw amount is `outputAmount - gasFee`
```solidity
@>  IZRC20(decoded.targetZRC20).approve(address(gateway), outputAmount + gasFee);
	withdraw(
		externalId, 
		decoded.receiver, 
		decoded.targetZRC20, 
@>		outputAmount - gasFee
	);
```
`GasFee` is deducted from `outputAmount`, so withdrawal amount is `outputAmount - gasFee` and gas fee is `gasFee`.
This means total amount of tokens that transferred to `gateway` is `outputAmount`.
It remains `gasFee`.
`withdraw` is public function and it lacks access control.
So malicious user can call this function with `gasFee` and he can steal `gasFee` from `contract`.
Approval to `gateway` remains `gasFee`, so user can steal `gasFee`.
The whole tokens that user transferred can be transferred to `gateway` but failed transactions are stored in contract and also failed tokens are returned to contract for `claimRefund`.
Attacker can steal this tokens. It can causes reversion about `claimRefund`.
`withdraw` calls `gateway.withdraw` and it transfers tokens from `GatewayTransferNative`.

### Attack Path

1. Attacker checks `gasToken` for BTC exists that stored for `claimRefund`.
2. Attacker calls `withdraw` with `outputToken == gasToken` and `amount == gasFee`.
3. Attacker steals BTC and the amount of `stolen` token is `gasFee`.

### Impact

Attacker can steal BTC from system. And `claimRefund` can fail because contract doesn't have enough token.

### Mitigation

```diff
function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
-    ) public {
+    ) internal {
        gateway.withdraw(
            sender,
            amount,
            outputToken,
            RevertOptions({
                revertAddress: address(this),
                callOnRevert: true,
                abortAddress: address(0),
                revertMessage: bytes.concat(externalId, bytes20(sender)),
                onRevertGasLimit: gasLimit
            })
        );
    }
```
