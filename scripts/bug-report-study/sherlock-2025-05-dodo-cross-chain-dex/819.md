# Less tokens than expected will be received from ZetaChain in connected chain when withdrawing

### Summary

Less tokens than expected will be received from ZetaChain in connected chain when withdrawing

### Root Cause

According to docs, users can `depositAndCall()` in connected chains to receive that amount in ZetaChain, paying a gasFee that is fixed for each token being transferred. However, the received amount will be lower than expected.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L363-L440

This happens because in both `_handleEvmOrSolanaWithdraw()` and `_handleBitcoinWithdraw()`, the approved amount for GatewayZEVM is correct (amount to withdraw + gasFee) but when `withdrawAndCall()` is called to interact with GatewayZEVM and make this transfer effective, the amount used to send is `outputAmount - gasFee`. This means that the received amount is lower than expected because the gasFee transfer is made appart in GatewayZEVM contract through `_withdrawZRC20WithGasLimit()` internal function.

### Attack Path

1. Alice withdraws 100 USDC from ZetaChain to Ethereum via withdrawAndCall() in GatewayCrossChain contract.
2. Gas fee is 5 USDC, so the total approved amount for GatewayZEVM is 105 USDC.
3. Withdrawn amount in the function is `outputAmount - gasFee` => 100 - 5 = 95 USDC.
4. Alice sends 105 USDC to GatewayZEVM, pays 5 as fee but only withdraws 95 USDC to its address in Ethereum, resulting in a net loss for her as 5 USDC stayed in GatewayZEVM instead of receiving them.

### Impact

Users receive less tokens than expected when withdrawing from ZetaChain to a connected chain. This happens in every withdraw (the loss amount is always equal to gasFee), which will make users eventually get disappointed with the protocol and look for other alternatives more fair.

### Mitigation

Update the withdrawn amount in both mentioned functions as the gas fee is paid appart in GatewayZEVM:

```solidity
function _handleBitcoinWithdraw(
        bytes32 externalId, 
        DecodedMessage memory decoded, 
        uint256 outputAmount,
        uint256 gasFee
    ) internal {
        if(gasFee >= outputAmount) revert NotEnoughToPayGasFee();
        IZRC20(decoded.targetZRC20).approve(address(gateway), outputAmount + gasFee);
        withdraw(
            externalId, 
            decoded.receiver, 
            decoded.targetZRC20, 
            outputAmount - gasFee
        );
    }

    function _handleEvmOrSolanaWithdraw(
        bytes32 externalId,
        DecodedMessage memory decoded,
        uint256 outputAmount,
        bytes memory receiver
    ) internal returns (uint256 amountsOutTarget) {
        (address gasZRC20, uint256 gasFee) = IZRC20(decoded.targetZRC20).withdrawGasFeeWithGasLimit(gasLimit);

        if (decoded.targetZRC20 == gasZRC20) {
            if (gasFee >= outputAmount) revert NotEnoughToPayGasFee();
            IZRC20(decoded.targetZRC20).approve(address(gateway), outputAmount + gasFee);

            bytes memory data = SwapDataHelperLib.buildOutputMessage(
                externalId, 
 -              outputAmount - gasFee, 
 +             outputAmount,
                decoded.receiver, 
                decoded.swapDataB
            );
            
            bytes memory encoded = (decoded.dstChainId == SOLANA_EDDY)
                ? AccountEncoder.encodeInput(AccountEncoder.decompressAccounts(decoded.accounts), data)
                : data;

            withdrawAndCall(
                externalId, 
                decoded.contractAddress, 
                decoded.targetZRC20, 
-               outputAmount - gasFee, 
+              outputAmount,
                receiver, 
                encoded
            );

            amountsOutTarget = outputAmount - gasFee;
        } else {
            amountsOutTarget = _swapAndSendERC20Tokens(
                decoded.targetZRC20, 
                gasZRC20, 
                gasFee, 
                outputAmount
            );

            bytes memory data = SwapDataHelperLib.buildOutputMessage(
                externalId, 
                amountsOutTarget, 
                decoded.receiver, 
                decoded.swapDataB
            );
            
            bytes memory encoded = (decoded.dstChainId == SOLANA_EDDY)
                ? AccountEncoder.encodeInput(AccountEncoder.decompressAccounts(decoded.accounts), data)
                : data;

            withdrawAndCall(
                externalId, 
                decoded.contractAddress, 
                decoded.targetZRC20, 
                amountsOutTarget, 
                receiver, 
                encoded
            );
        }
    }
```
