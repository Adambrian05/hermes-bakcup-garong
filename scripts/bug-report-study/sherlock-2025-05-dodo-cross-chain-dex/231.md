# The USDT Token Cannot Be Approved or Transferred Using the `TransferHelper` Library

## Vulnerability Details
- USDT is regarded as a supported token on ZetaChain ([see documentation](https://www.zetachain.com/docs/developers/tokens/zrc20/#:~:text=0x95aD61b0a150d79219dCF64E1E6Cc01f0B64C4cE-)). 

- According to the contest's Q&A, the Ethereum mainnet is one of the chains where the protocol will be deployed:
> Q: On which chains will the smart contracts be deployed?  
> A: ZetaChain, Ethereum, Polygon, Arbitrum, Base, BNB Chain.

- Transferring and approving USDT on the Ethereum mainnet does not return a boolean value ([see Etherscan](https://etherscan.io/token/0xdac17f958d2ee523a2206206994597c13d831ec7#code)).

- However, the `TransferHelper` library's functions `safeApprove`, `safeTransfer`, and `safeTransferFrom` expect a boolean output and require it to be true. This means attempting to approve or transfer USDT via this library will typically revert. An example is the `safeTransfer` function ([see source](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/libraries/TransferHelper.sol#L12)):

```solidity
function safeTransfer(address token, address to, uint value) internal {
    // bytes4(keccak256(bytes('transfer(address,uint256)')));
    (bool success, bytes memory data) = token.call(abi.encodeWithSelector(0xa9059cbb, to, value));
    require(success && (data.length == 0 || abi.decode(data, (bool))), 'TransferHelper: TRANSFER_FAILED');
}
```
- The `TransferHelper` library is used in the `GatewaySend` contract [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L396), which is deployed on the Ethereum mainnet as one of the target chains.

## POC
The issue with USDT's unusual behavior has been reported multiple times before, such as [here](https://solodit.cyfrin.io/issues/usdt-cannot-be-withdrawn-from-aavev3yieldmanager-cantina-none-level-money-pdf).

## Impact
Users who attempt to send or swap USDT from Ethereum mainnet to other chains may lose their initial USDT funds if their transaction reverts. This is because the `onRevert` function called by the gateway will fail, preventing users from retrieving their funds.

## Mitigation
In the `safeTransfer` and `safeTransferFrom` functions, record the token balance before and after the transfer, and verify that the balance has increased accordingly to confirm that the transfer was successful.
