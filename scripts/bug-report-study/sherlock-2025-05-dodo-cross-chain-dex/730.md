# `approve` method will brick usage of USDT tokens on `GatewaySend.sol`

### Summary

`GatewaySend.sol` uses EIP20 approve method directly on all tokens. However, the protocol supports USDT on mainnet, which is incompatible with the EIP20 approve method for some reasons

* It does not return a boolean in approval, while the interface expects a bool
* When there are pending approvals, it will require an approval to 0 first

### Root Cause

use of EIP20 standard interface on on all tokens

```solidity
    function _handleERC20Deposit(
        address targetContract,
        uint256 amount,
        address asset,
        bytes memory message,
        RevertOptions memory revertOptions
    ) internal {
        IERC20(asset).approve(address(gateway), amount);
        //@audit Deposits ERC20 tokens to the custody or connector contract and calls an omnichain smart contract.
        gateway.depositAndCall(
            targetContract,
            amount,
            asset,
            message,
            revertOptions
        );
    }
```
