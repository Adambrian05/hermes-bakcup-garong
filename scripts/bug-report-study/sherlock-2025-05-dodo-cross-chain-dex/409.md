# Incorrect accounting of positive slippage in gas swaps causes protocol fund loss

### Summary

An incorrect calculation of the final output amount will cause a loss of funds for the protocol as any user will receive extra tokens when they perform a cross-chain swap and the internal gas swap executes with positive slippage.

### Root Cause

In `_swapAndSendERC20Tokens` function ([GatewayCrossChain.sol:302-335](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayCrossChain.sol#L302-L335)) the final output amount for the user is calculated based on the actual amount of tokens spent on gas (`amounts[0]`), not the quoted amount (`amountsQuote[0]`). Any profit from positive slippage is incorrectly sent to the user instead of being kept by the protocol.

### Internal Pre-conditions

None

### External Pre-conditions

- The market price for the `gasZRC20` token improves relative to the `targetZRC20` token between the time the quote is fetched and the swap is executed.

### Attack Path

1. User starts a cross-chain swap that requires an internal swap for gas tokens.
2. The contract gets a quote (`amountsQuote[0]`) for the cost of the gas tokens.
3. The swap executes at a better price, so the actual cost (`amounts[0]`) is less than the quoted cost.
4. The contract calculates the user's final amount to withdraw using the lower `amounts[0]`. This results in the user receiving more tokens than they should have.

### Impact

The protocol suffers a loss of funds on every transaction with positive slippage. The loss is equal to the difference between the quoted gas cost and the actual gas cost. Users gain these funds.

### PoC

_No response_

### Mitigation

The final amount for the user should be calculated using the quoted gas cost (`amountsQuote[0]`), not the actual cost. Any profit from positive slippage should be kept by the protocol.

```diff
function _swapAndSendERC20Tokens(
    // [...]
    IZRC20(gasZRC20).approve(address(gateway), gasFee);
-   IZRC20(targetZRC20).approve(address(gateway), targetAmount - amounts[0]);
+   IZRC20(targetZRC20).approve(address(gateway), targetAmount - amountsQuote[0]);
    
-   amountsOut = targetAmount - amounts[0];
+   amountsOut = targetAmount - amountsQuote[0];
}
```
