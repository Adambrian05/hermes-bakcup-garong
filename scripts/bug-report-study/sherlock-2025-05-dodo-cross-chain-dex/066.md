# Unnecessary transferFrom in onCall() causes always revert.

### Summary

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L359

```solidity
function onCall(
        MessageContext calldata /*context*/,
        bytes calldata message
    ) external payable onlyGateway returns (bytes4) {
        (
            bytes32 externalId, 
            uint256 amount, 
            bytes calldata recipient, 
            address fromToken, 
            address toToken, 
            bytes calldata swapData
        ) = decodePackedMessage(message);

       //...

        if(!fromIsETH) {
            IERC20(fromToken).transferFrom(msg.sender, address(this), amount);
        }

       //...

}
```

The onCall() function in the GatewaySend contract attempts to call transferFrom() to receive tokens from the Gateway, despite the fact that tokens have already been transferred by ZetaChain’s Gateway. 

This incorrect behavior leads to a likely revert during onCall(), which triggers the fallback to onRevert()—forcing a refund operation that should not have occurred.



### Root Cause

In GatewaySend.sol:359 there is unnecessary  code.

 if(!fromIsETH) {
      IERC20(fromToken).transferFrom(msg.sender, address(this), amount);
  }
