# Absent Verification of DODO Swap Results



## Finding description and impact

The `depositAndCall` function invokes `_doMixSwap`, which produces a swap `outputAmount`. However, this returned value lacks proper validation.

If the swap encounters a silent failure or yields an unexpectedly minimal amount, the function continues execution, forwarding the questionable `outputAmount` to subsequent processing logic.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L245

## Potential impacts:

* Cross-chain transactions or operations proceeding with negligible or zero token amounts
* Abnormal behavior in downstream contracts anticipating legitimate token quantities
* User fund loss when swaps fail or encounter excessive slippage

## Mitigation

Verify that the resulting `outputAmount` meets acceptable thresholds before continuing:

```solidity
require(outputAmount > 0, "SWAP FAILED: ZERO OUTPUT");
```

Additionally, consider validating against the minimum return specified in `params.minReturnAmount` to strengthen slippage protection, based on how `_doMixSwap` processes it internally.
