# Unrestricted withdraw() Allows Any User to Drain Funds from GatewayTransferNative.sol contract

### Summary

The `GatewayTransferNative.withdraw()` function lacks proper access controls and validation checks. This leads to a critical vulnerability: an attacker can steal tokens being held in GatewayTransferNative.sol contract.

```solidity
   function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
    ) public {  //@audit - Should be internal not public
```

### Root Cause

The withdraw() function is public which can be called by anyone by passing any amount and any address as parameters

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286

### Attack Path

1. **User1** bridges ZRC20 tokens (e.g., BTC-ZRC20) using `withdrawToNativeChain()`.

   * `btcZ.mint(user1, amount)`
   * User approves and calls `gatewayTransferNative.withdrawToNativeChain()`.

2. The bridged tokens are now held in the `GatewayTransferNative` contract.

3. **Attacker (any EOA)** calls `withdraw()` with:

   * Arbitrary `externalId` (`"dummy"`),
   * Their own address as `receiver`,
   * Valid ZRC20 asset address (e.g., `btcZ`),
   * And the entire balance held in the contract.

4. The `withdraw()` function blindly transfers the full token amount to the attacker, bypassing any authentication or verification.

5. **Result**: Attacker drains the ZRC20 balance intended for the user, causing loss of funds.

### Impact

High severity: Complete loss of tokens being holded in GatewayTransferNative.sol
Malicious actor can repeatedly drain bridge balances as long as any token is held in this contract

### Mitigation

Mark `GatewayTransferNative.withdraw()` as internal (similar to how it's done in the `GatewayCrossChain.sol` contract) to prevent unauthorized external calls. This ensures it can only be invoked through trusted gateway called functions like `onCall()`

```diff
    function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
-    ) public {
+   ) internal {
```
