# Cross-Chain Transaction Failures due to wrong chainid of solana

### Summary

The contracts GatewayTransferNative.sol and GatewayCrossChain.sol use a hardcoded value for the Solana chain ID that does not align with the official value defined by ZetaChain.

According to ZetaChain's official documentation, the correct chain ID for Solana is 900. This discrepancy causes logic that depends on the dstChainId to fail, leading to rejected or misrouted Solana-related transactions, effectively breaking Solana interoperability.

### Root Cause

The contract sets SOLANA_EDDY = 1399811149

This value is incorrect. The correct chain ID for Solana per ZetaChain’s specification is 900.

### Impact

As a direct result, the _handleEvmOrSolanaWithdraw() function is never invoked for Solana chains, since its internal check compares against the incorrect SOLANA_EDDY value. Without proper execution, Solana-bound transactions will either revert or behave unexpectedly, rendering cross-chain functionality for Solana unusable — a serious concern for systems depending on full multi-chain support.
