# Transfer not compatible with usdc / usdt

## Summary
When user calls `depositAndCall` it would transfer assets from the user to the the protocol, However the protocol integrates with various chains and assets,  But transfer is not compatible with usdt/usdc
## Description
```solidty
            require(
                IERC20(asset).transferFrom(msg.sender, address(this), amount),
                "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
            );
            _handleERC20Deposit(
                targetContract, 
                amount,
                asset, 
                message, 
                revertOptions
            );
```
As we can see it uses unsafe `tranferFrom` which does not return a boolean (bool) from the transfer.
## Impact
Dos for second execution of call
## Recommended Mitigation
Uses safe transfer
