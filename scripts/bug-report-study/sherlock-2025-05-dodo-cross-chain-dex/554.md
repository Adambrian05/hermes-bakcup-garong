# `GatewayTransferNative::_doMixSwap` reverts when swapping from native gas token in `GatewayTransferNative::withdrawToNativeChain`

### Summary

`GatewayTransferNative::withdrawToNativeChain` allows users to use native zeta to swap for other zrc20 tokens using `DODORouteProxy::mixSwap`. 

They do this by specifying `MixSwapParams::params` where `fromToken == _ETH_ADDRESS__`.

However, `_doMixSwap` will always revert as the code will attempt to call `approve()` on `params.fromToken`

### Root Cause

The `_doMixSwap` function in `GatewayTransferNative.sol` does not check if the `fromToken` is the native asset before attempting to call `approve` as seen [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayTransferNative.sol#L434)


### Internal Pre-conditions

None

### External Pre-conditions

None

### Attack Path

1. Users call `GatewayTransferNative::withdrawToNativeChain` and specify in `MixSwapParams::params` that `fromToken` is `_ETH_ADDRESS`. Do note that developers intentions to allow this is evident by marking the function as `payable` as seen [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayTransferNative.sol#L534).

2. Assuming `_handleFeeTransfer` passes, that is another bug, `_doMixSwap` is called.

3. ` IZRC20(params.fromToken).approve(DODOApprove, amount);` is executed, and a revert occurs.

### Impact

1. Denial of Service for this use case, as there is no work around to swap native ether for other tokens.
2. Users could swap native ZETA for wrappedZeta on another DEX, which might lose earnings for `DODORouterProxy`.
3. This will also fail when `fromToken` is USDT

### PoC

Please refer to Attack Path.

### Mitigation
Change GatewayTransferNative::_doMixSwap as follows:
```diff
 function _doMixSwap(
        bytes memory swapData, 
        uint256 amount, 
        MixSwapParams memory params
    ) internal returns (uint256 outputAmount) {
        if (swapData.length == 0) {
            return amount;
        }
+       if (params.fromToken != _ETH_ADDRESS_){
+       IZRC20(params.fromToken).safeApprove(DODOApprove, amount);
+        }    
-       IZRC20(params.fromToken).approve(DODOApprove, amount);
        return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
            params.fromToken,
            params.toToken,
            params.fromTokenAmount,
            params.expReturnAmount,
            params.minReturnAmount,
            params.mixAdapters,
            params.mixPairs,
            params.assetTo,
            params.directions,
            params.moreInfo,
            params.feeData,
            params.deadline
        );
    }
```
