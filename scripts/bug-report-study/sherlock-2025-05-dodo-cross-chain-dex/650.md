# Cross-Chain Wallet Address Mismatch Leading to Fund Loss

### Summary

The GatewaySend contract has a critical vulnerability where failed cross-chain transactions revert funds to msg.sender address on the destination chain, assuming wallet addresses are identical across chains. This assumption fails with Account Abstraction wallets, Safe multisigs, and deterministic deployment variations, potentially causing permanent fund loss or funds being sent to unintended recipients.

### Root Cause

The contract hardcodes msg.sender as the revert recipient address in the revertMessage:
```solidity
revertMessage: bytes.concat(externalId, bytes20(msg.sender))
```
This address is later extracted in onRevert() function:
```solidity
function onRevert(RevertContext calldata context) external onlyGateway {
    bytes32 externalId = bytes32(context.revertMessage[0:32]);
    address sender = address(uint160(bytes20(context.revertMessage[32:]))); // msg.sender from source chain
    TransferHelper.safeTransfer(context.asset, sender, context.amount); // Sent to potentially wrong address
}
```
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L253

The fundamental flaw is assuming cross-chain address consistency, which is not guaranteed in modern wallet architectures.

### Attack Path

1. Alice uses a Safe multisig wallet: 0xABC...123 on Ethereum
2. Alice calls depositAndCall() to send 1000 USDC from Ethereum to other chain
3. Her Safe address on Polygon is 0xDEF...456 (different due to deployment variations)
4. Cross-chain transaction fails on other chain
5. onRevert() sends 1000 USDC to 0xABC...123 on other chain
6. If 0xABC...123 doesn't exist on other chain→ funds permanently lost
7. If 0xABC...123 belongs to someone else on other chain→ funds stolen

### Impact

Permanent Fund Loss: Users can lose their entire transaction amount if the address doesn't exist on destination chain
Fund Theft: Funds can be sent to unintended recipients who control the same address on destination chain
