# misconfiguration of  inputs in function `withdraw` in contract `GatewayTransferNative.sol`

## Overview : 

In  function `withdraw` in contract `GatewayTransferNative.sol` we set sender address as input , and call the `withdraw` function in `GatewayZEVM.sol` then that function takes the receiver address and do its task . so in place of sender address we should set receiver address.
