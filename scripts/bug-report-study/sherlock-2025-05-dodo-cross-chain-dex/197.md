# Return Value Problematic in `_doMixSwap()` Function - Semantic Mismatch between Input and Output Amount

## Description
The `_doMixSwap()` function has a logic issue in its return value that can lead to incorrect calculations in cross-chain swap systems. The function returns `input amount` when `swapData.length == 0`, but the return variable is named `outputAmount` and the calling function expects the actual swap result.

The issue occurs due to a semantic mismatch between the caller's expectations and the function's implementation, where the function returns the number of tokens to be swapped and the function returns the input amount when there is no swap data, causing the caller to be unable to distinguish between "no swap" vs "1:1 swap".

## Code Snippet
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L425-L449

## Root Cause
`_doMixSwap` function:
```solidity
function _doMixSwap(
    bytes memory swapData,              
    uint256 amount,                     
    MixSwapParams memory params         
) internal returns (uint256 outputAmount) {
    // ❌ ROOT CAUSE: Inconsistent return logic
    if (swapData.length == 0) {
        return amount; // Returns input amount, not output amount
    }

    // Approve and execute swap...
    return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(...);
}
```
The root of the problem is that the return variable `outputAmount` implies the swap result, but in the condition `swapData.length == 0` it returns `amount` (input amount) and there is no validation that the source and target tokens are the same when `swapData` is empty. The function is unclear when to swap vs. not to swap. The calling functions (`onCall()` and `withdrawToNativeChain()`) expect `outputAmount` as a valid swap result.

## Impact
Users may receive tokens in incorrect amounts.

## Scenario
`withdrawToNativeChain()` function:
```solidity

function withdrawToNativeChain(
    address zrc20,              // USDT
    uint256 amount,             // 1000 USDT

    // decoded.targetZRC20 = ETH token address

    // params.toToken = ETH
    // decoded.swapDataZ = "" (empty!)

    // System tries to swap 995 ETH for gas fee
    // Whereas the user should only have ~0.33 ETH
}
```

## Recommendation
Explicit validation dan clear semantics.
```solidity
function _doMixSwap(
    bytes memory swapData,              
    uint256 amount,                     
    MixSwapParams memory params         
) internal returns (uint256 outputAmount) {
    
    // ============== INPUT VALIDATION ==============
    require(amount > 0, "INVALID_AMOUNT");
    require(params.fromToken != address(0), "INVALID_FROM_TOKEN");
    require(params.toToken != address(0), "INVALID_TO_TOKEN");
    
    // ============== TOKEN CONSISTENCY VALIDATION ==============
    
    bool tokensAreSame = params.fromToken == params.toToken;
    bool hasSwapData = swapData.length > 0;
    
    if (tokensAreSame && hasSwapData) {
        // ❌ ERROR: Token is the same but there is a data swap
        revert InvalidSwapParams();
    }
    
    if (!tokensAreSame && !hasSwapData) {
        // ❌ ERROR: Tokens are different but no swap data
        revert SwapDataRequired();
    }
    
    // ============== HANDLING BASED ON CONDITION ==============
    
    if (tokensAreSame) {
        // ✅ VALID: Same token, no need to swap
        emit SwapSkipped(
            params.fromToken,
            params.toToken,
            amount,
            "Same token, no swap needed"
        );
        return amount; // Return input amount because there is no swap
    }
    
    // ============== SWAP EXECUTION FOR DIFFERENT TOKENS ==============
    
    // Validate swap parameters
    require(params.fromTokenAmount == amount, "AMOUNT_MISMATCH");
    require(params.minReturnAmount > 0, "INVALID_MIN_RETURN");
    require(params.deadline >= block.timestamp, "DEADLINE_EXPIRED");
    
    // Approve DODO
    IZRC20(params.fromToken).approve(DODOApprove, amount);
    
    // Swap execution with error handling
    try IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
        params.fromToken,              
        params.toToken,                
        params.fromTokenAmount,        
        params.expReturnAmount,        
        params.minReturnAmount,        
        params.mixAdapters,            
        params.mixPairs,               
        params.assetTo,                
        params.directions,             
        params.moreInfo,               
        params.feeData,                
        params.deadline                
    ) returns (uint256 swapResult) {
        
        // Validation of swab results
        require(swapResult >= params.minReturnAmount, "SWAP_RESULT_TOO_LOW");
        require(swapResult > 0, "ZERO_SWAP_RESULT");
        
        return swapResult;
        
    } catch Error(string memory reason) {
        revert SwapFailed();
    } catch (bytes memory) {
        revert SwapFailed();
    }
}
```
