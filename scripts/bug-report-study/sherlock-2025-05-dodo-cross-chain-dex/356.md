# `GatewayTransferNative.withdraw()` Reverts Due to Missing Token Approval to `gateway` Contract

### **Summary**

The `withdraw()` function in the `GatewayTransferNative` contract is marked `public`, enabling any caller to attempt a withdrawal. However, the function fails because it does not approve the `gateway` contract to spend the specified `outputToken`, which results in a transfer failure during execution.

### **RootCause**

- `GatewayTransferNative` holds the `outputToken` intended for withdrawal.
- Before invoking `gateway.withdraw()`, it does **not** approve the `gateway` contract to spend `outputToken`.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286-L304

- Consequently, the internal `transferFrom()` call in `gateway.withdraw()` reverts due to zero allowance.

https://github.com/zeta-chain/protocol-contracts/blob/2e61e029e89792c1b10ed15d2aa19818a77dd4d8/contracts/zevm/GatewayZEVM.sol#L194-L218

https://github.com/zeta-chain/protocol-contracts/blob/2e61e029e89792c1b10ed15d2aa19818a77dd4d8/contracts/zevm/GatewayZEVM.sol#L150-L172

- The contract lacks any internal mechanism to authorize this transfer.

### **Impact**

- The `withdraw()` function is non-functional and **always reverts** for non-zero `amount` inputs.
- Users are unable to withdraw tokens through the `GatewayTransferNative` contract.
- Causes wasted gas and user confusion due to a seemingly supported but broken operation.

### **Mitigation**
To resolve the issue, the contract should explicitly approve the `gateway` to spend the necessary `outputToken` amount before invoking the withdrawal:

```solidity
function withdraw(
    bytes32 externalId,
    bytes memory sender,
    address outputToken,
    uint256 amount
) public {
    IZRC20(outputToken).approve(address(gateway), amount);

    gateway.withdraw(
        sender,
        amount,
        outputToken,
        RevertOptions({
            revertAddress: address(this),
            callOnRevert: true,
            abortAddress: address(0),
            revertMessage: bytes.concat(externalId, bytes20(sender)),
            onRevertGasLimit: gasLimit
        })
    );
}
```
