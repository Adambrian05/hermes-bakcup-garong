# Missing Fee Deduction in Token Swaps Will Cause Fee Calculation Inconsistencies

### Summary

The missing fee deduction in `GatewayTransferNative.sol` will cause fee calculation inconsistencies for cross-chain swaps as the swap will be calculated on the full amount rather than the post-fee amount.

### Root Cause

In `GatewayTransferNative.onCall` the platform fee is deducted from the user's tokens via the `_handleFeeTransfer` function, but the full amount is still passed to the swap function in the else block when `decoded.targetZRC20 != zrc20`

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370-L395

### Internal Pre-conditions

1. User performs a cross-chain swap where the target token (`decoded.targetZRC20`) is different from the source token (`zrc20`)
2. Platform fee is configured to be greater than zero (`feePercent > 0`)

### External Pre-conditions

None specific.

### Attack Path

1. User initiates a cross-chain swap
2. The `onCall` function calculates and transfers the platform fee using `_handleFeeTransfer(zrc20, amount)`
3. However, when swapping to a different token in the else block (lines 394-408), the original `amount` is passed to the swap function without subtracting the fee: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L395
4. This results in the swap functions attempting to use the full amount, even though some of it has already been sent to the treasury: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L341-L347

### Impact

The protocol will attempt to swap more tokens than are actually available, which may cause transactions to revert or token accounting will be incorrect (less available for refund) as the fee is removed but not accounted for in swap calculations, causing later `claimRefund` calls to fail.

_No response_

### Mitigation

```solidity
    // Subtract fees from the amount before further processing
    uint256 amountAfterFee = amount - platformFeesForTx;

    if (decoded.targetZRC20 == zrc20) {
        // same token
        TransferHelper.safeTransfer(
            decoded.targetZRC20,
            receiver,
            amountAfterFee
        );

        // ...
    } else {
        uint256 outputAmount = _doMixSwap(decoded.swapData, amountAfterFee, params);
        // ...
    }
}
```
