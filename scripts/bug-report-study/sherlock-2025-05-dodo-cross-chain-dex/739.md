# Unrestricted withdraw() Function in GatewayTransferNative.sol, leads to fund being stolen

### Summary

In GatewayTransferNative.sol, there withdraw() is publicly accessible without any access controls, allowing anyone to siphon off all ZRC20 tokens held by the contract. This vulnerability undermines the intended cross-chain bridging process and exposes user funds to direct theft.

   function withdraw(
        bytes32 externalId,

### Attack Path

A legitimate user deposits ZRC20 tokens into the contract by calling withdrawToNativeChain() as part of the intended bridging process.
An attacker exploits the vulnerability by calling the withdraw() function with a random externalId.and also specifies their own address as the recipient.
requests the entire balance of ZRC20 tokens held by the contract.
