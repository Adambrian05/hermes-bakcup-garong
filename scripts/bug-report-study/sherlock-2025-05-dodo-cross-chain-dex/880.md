# Use of "transfer" opcode to send ETH

### Summary

In `GatewaySend.sol` in [onCall](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L370) function the `.transfer` opcode is used to handle ETH transfer. But is not recommended for sending native token due to its 2300 gas unit limit, this is only enough for basic operations.

However this is insufficient, if the recipient address is a contract or a multisig safe, with a `receive`/`fallback` function which requires more than 2300 gas, and execute extra logic in the `receive`/`fallback` function, the transfer function will always fail due to out of gas errors.

### Root Cause

Gas limitation of "transfer" opcode
