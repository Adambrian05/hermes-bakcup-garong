# Unconditional ETH forwarding in `_doMixSwap`

## Finding description and impact

The `_doMixSwap` function unconditionally forwards `msg.value` to the `mixSwap` call, regardless of whether the route uses ETH.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L425-L450

If the swap path doesn’t involve ETH:

* The forwarded ETH may be wasted or locked
* The external call could revert due to unexpected ETH sent

This creates fragility in swap behavior and risks failed transactions.

## Mitigation

Check if the route requires ETH before forwarding it. Only include `msg.value` if necessary:

```solidity
bool fromIsETH = (params.fromToken == _ETH_ADDRESS_);
if (fromIsETH) {
    return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(...);
} else {
    return IDODORouteProxy(DODORouteProxy).mixSwap(...);
}
```

This avoids unnecessary ETH transfers and potential reverts in non-ETH swap paths.
