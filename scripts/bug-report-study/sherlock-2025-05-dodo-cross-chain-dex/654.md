# Critical State Management Vulnerability in Cross-Chain Withdrawals

### Summary

The `_handleEvmOrSolanaWithdraw` function lacks withdrawal state tracking, enabling withdrawal replays and potential fund draining. This is a severe architectural flaw in cross-chain transaction management.

```solidity
function _handleEvmOrSolanaWithdraw(
    bytes32 externalId,
    DecodedMessage memory decoded,
    uint256 outputAmount,
    bytes memory receiver
) internal returns (uint256 amountsOutTarget) {
    // No tracking of processed withdrawals
    withdrawAndCall(...);
}
```

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L379C4-L441C1  


- Missing withdrawal state management mapping
- No uniqueness validation for externalId
- Lack of withdrawal completion tracking
- Absence of cross-chain state synchronization
    

### Internal Pre-conditions

- Contract must have sufficient token balance
- Valid externalId provided
- Withdrawal function accessible
- No existing state checks implemented

### External Pre-conditions

- Cross-chain messaging system operational
- Gateway contract accessible
- Target chain reachable
- Sufficient gas available

### Mitigation

```solidity
contract GatewayCrossChain {
    mapping(bytes32 => bool) public processedWithdrawals;
    mapping(bytes32 => uint256) public withdrawalTimestamps;
    uint256 public constant WITHDRAWAL_TIMEOUT = 1 hours;

    function _handleEvmOrSolanaWithdraw(
        bytes32 externalId,
        DecodedMessage memory decoded,
        uint256 outputAmount,
        bytes memory receiver
    ) internal returns (uint256 amountsOutTarget) {
        require(!processedWithdrawals[externalId], "Withdrawal already processed");
        require(withdrawalTimestamps[externalId] == 0 || 
                block.timestamp >= withdrawalTimestamps[externalId] + WITHDRAWAL_TIMEOUT,
                "Withdrawal in progress");

        withdrawalTimestamps[externalId] = block.timestamp;
        
        // Existing withdrawal logic
        uint256 result = executeWithdrawal(...);
        
        processedWithdrawals[externalId] = true;
        emit WithdrawalProcessed(externalId, block.timestamp);
        
        return result;
    }
    
    // Add recovery mechanism
    function recoverFailedWithdrawal(bytes32 externalId) external {
        require(withdrawalTimestamps[externalId] + WITHDRAWAL_TIMEOUT < block.timestamp,
                "Withdrawal not timed out");
        require(!processedWithdrawals[externalId], "Already processed");
        // Recovery logic
    }
}
```
