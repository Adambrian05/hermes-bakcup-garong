# USDT will not function

### Summary

depositAndCall function uses simple transferFrom with require on transferFrom's output, which will not work with USDT.

### Root Cause

depositAndCall [uses](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewaySend.sol#L238-L241) simple transferFrom instead of safeTransferFrom. 

### Internal Pre-conditions

None

### External Pre-conditions

None

### Attack Path

1. user calls depositAndCall with USDT as `fromToken` 
2. depositAndCall will revert as USDT does not return any value.

### Impact

depositAndCall will not work.

### PoC

_No response_

### Mitigation

use safeTransferFrom instead.
