# Cross-Chain Revert Loop Denial of Service

### Summary

The `withdrawAndCall` function's revert handling mechanism can be exploited to create infinite revert loops, potentially locking funds and exhausting gas.

```solidity
function withdrawAndCall(
    bytes32 externalId,
    bytes memory contractAddress,
    address targetZRC20,
    uint256 outputAmount,
    bytes memory receiver,
    bytes memory message
) internal {
    gateway.withdrawAndCall(
        contractAddress,
        outputAmount,
        targetZRC20,
        message,
        CallOptions({...}),
        RevertOptions({
            revertAddress: address(this),
            callOnRevert: true,
            abortAddress: address(0),
            revertMessage: bytes.concat(externalId, receiver),
            onRevertGasLimit: gasLimit
        })
    );
}
```

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L244C4-L270C1

- No maximum revert attempt limit
- Recursive revert handling
- Missing circuit breaker
- Unlimited gas consumption in revert paths

### Internal Pre-conditions

- RevertOptions enabled
- callOnRevert set to true
- No revert attempt counter
- Gas limit set for revert operations

### External Pre-conditions

- Gateway contract operational
- Cross-chain messaging available
- Sufficient gas for initial transaction
- Valid targetZRC20 token
