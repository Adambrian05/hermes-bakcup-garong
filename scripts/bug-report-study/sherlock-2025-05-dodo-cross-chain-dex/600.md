# Protocol fee can be lost when user user bridges zeta token(native token) from Zetachain to any supported chains

### Summary

For bridging tokens from **Zetachain** to a destination chain, the function [`withdrawToNativeChain`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530) is used.

When a user attempts to bridge the **ZETA token**, which is the native token on Zetachain, the first parameter passed to `withdrawToNativeChain`, `zrc20` ([source](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L531)), is set to `ETH_ADDRESS` (`0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE`).

To collect protocol fees, [`_handleFeeTransfer`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L551) is invoked within `withdrawToNativeChain`:

```solidity
function _handleFeeTransfer(
    address zrc20,
    uint256 amount
) internal returns (uint256 platformFeesForTx) {
    platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
    TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
}

```

However, _handleFeeTransfer does not account for the native token case (passed as the zrc20 address [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L551)). As a result, the safeTransfer call silently fails, and the platformFee is not transferred to the EddyTreasurySafe.


### Root Cause

Native token cases are not handled correctly in `_handleFeeTransfer`, the ETH address `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE `does not represent a real contract, causing safeTransfer to succeed without actually transferring any funds.



### Impact

Protocol fees are silently skipped when bridging the ZETA token (native token) to a supported destination chain via the [withdrawToNativeChain](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530) function.
