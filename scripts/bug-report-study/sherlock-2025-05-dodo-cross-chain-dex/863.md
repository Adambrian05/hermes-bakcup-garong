# The calculation of externalId does not include chainID.

### Summary

The calculation of externalId does not include the chainID. When a user attempts to send two transactions with the exact same global nonce on two different chains at the same time and both transactions revert, only one of them will receive a refund.










### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L539

```solidity
            RefundInfo memory refundInfo = RefundInfo({
                externalId: externalId,
                token: context.asset,
                amount: context.amount,
                walletAddress: walletAddress
            });
            refundInfos[externalId] = refundInfo;
```
