# Unable to take platform fee for swap with native ZETA tokens from Zetachain

### Summary

Mistake in the function `_handleFeeTransfer()` can cause the contract unable to take platform fee in native ZETA token

### Root Cause

The function [`withdrawToNativeChain()`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530) supports user to swap native ZETA tokens from Zetachain to connected chains, by setting `zrc20 = _ETH_ADDRESS_`

However, the function `_handleFeeTransfer()` does not handle case when `zrc20 == _ETH_ADDRESS_`, causing it unable to take platform fee. The function uses `TransferHelper.safeTransfer()` to address `_ETH_ADDRESS_` which will return `success` if calling to a non-contract address because it uses low-level `.call()`. As a result, platform fee is skipped for native ZETA tokens
```solidity
    function _handleFeeTransfer(
        address zrc20,
        uint256 amount
    ) internal returns (uint256 platformFeesForTx) {
        platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
@>        TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx); // <<<<<<<<<<< using `safeTransfer()`
    }
```
```solidity
    function safeTransfer(address token, address to, uint value) internal {
        // bytes4(keccak256(bytes('transfer(address,uint256)')));
@>        (bool success, bytes memory data) = token.call(abi.encodeWithSelector(0xa9059cbb, to, value));
@>        require(success && (data.length == 0 || abi.decode(data, (bool))), 'TransferHelper: TRANSFER_FAILED');
    }
```

### Mitigation

```diff
    function _handleFeeTransfer(
        address zrc20,
        uint256 amount
    ) internal returns (uint256 platformFeesForTx) {
        platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
-        TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
+        zrc20 != _ETH_ADDRESS_ ? TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx) : TransferHelper.safeTransferETH(EddyTreasurySafe, platformFeesForTx);
    }
```
