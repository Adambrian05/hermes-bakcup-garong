# Use of transfer() causes revert when to address consumes more than 2300 gas

### Summary

Using `transfer()` enforces a 2300 gas stipend on `evmWalletAddress`, which will not work for addresses that are smart contracts that consume more than 2300 gas when receiving the native token.

### Root Cause

Use of `transfer` causes revert when address could be a smart contract that consumes more than 2300 gas when receiving ETH.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L370

### Internal Pre-conditions

1. GatewaySend.onCall must be called and `toIsETH` is True

### External Pre-conditions

n/a

### Attack Path

1. GatewaySend.onCall is called to finalize a cross-chain transaction and  `toIsETH` is True.
2. The contract attempts to transfer the native token to and address that is a smart contract that performs some storage updates in its receive function that use up more than 2300 gas. 
3. `onCall` reverts.

### Impact

`onCall` always reverts when `toIsETH` is True and the transfer uses more than 2300 gas breaking intended protocol functionality.
