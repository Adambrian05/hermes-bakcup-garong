# Fee On Transfer Tokens Are Not Supported



## Summary
The GatewaySend contract assumes it receives the exact token amount specified in function parameters, but fee-on-transfer tokens deduct fees during transfer. This causes the contract to have less tokens than expected, leading to failed swaps when it tries to use the assumed amount.

## Root Cause

In [[GatewaySend.sol](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L218)](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L218), the contract uses direct `IERC20.transferFrom` calls and assumes the amount specified equals the actual amount received. This breaks with fee-on-transfer tokens where the received amount is less than the specified amount.

```solidity
function depositAndCall(...) public payable {
    // ...
    if(!fromIsETH) {
        require(
            IERC20(fromToken).transferFrom(msg.sender, address(this), amount), 
            "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
        );
    }
    
    // Uses assumed amount, not actual received amount
    uint256 outputAmount = _doMixSwap(swapData);
}
```

## Impact

Transactions will fail when users attempt to swap fee-on-transfer tokens like PAXG. The contract will try to approve and use more tokens than it actually received, causing insufficient balance errors during the swap process.

## Recommendation

Consider implementing balance checking that records the balance of the contract before and after the transfer and uses the actual received amount for swap calculations:

```solidity
if(!fromIsETH) {
    uint256 balanceBefore = IERC20(fromToken).balanceOf(address(this));
    
    require(
        IERC20(fromToken).transferFrom(msg.sender, address(this), amount), 
        "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
    );
    
    uint256 balanceAfter = IERC20(fromToken).balanceOf(address(this));
    uint256 actualAmount = balanceAfter - balanceBefore;
    
    // Use actualAmount for swap calculations
    uint256 outputAmount = _doMixSwap(swapData, actualAmount);
}
```
