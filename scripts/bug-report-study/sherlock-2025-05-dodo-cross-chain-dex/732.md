# Underflow Vulnerability in onCall: Missing Check Allowing Platform Fee to Exceed Amount

## Description
The issue arises in the function onCall, the line  amount -= platformFeesForTx modifies the amount parameter without checking if platformFeeForTx is less than or equal to amount. If platformFeesForTx > amount, it will cause underflow.

The line:
```solidity
amount -= platformFeesForTx;
```
modifies the amount parameter without checking whether platformFeesForTx <= amount. If platformFeesForTx > amount, this will cause an underflow.
Impact 
Underflow causing Legitimate users  unable to complete swaps or cross-chain transfers if fees exceed the provided amount, causing disruption.

## Recommendation
Add a Pre-Check Before Subtraction
```solidity
require(platformFeesForTx <= amount, "onCall: platform fee exceeds amount");
amount -= platformFeesForTx;
```
