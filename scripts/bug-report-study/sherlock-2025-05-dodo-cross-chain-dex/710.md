# Funds from aborted withdrawals cannot be claimed.

### Summary

when `withdrawAndCall` is called several parameters are passed, including RevertOptions struct which holds different data in case of reverts. RevertOptions contains several variables including `revertAddress` and `abortAddress`.  from the natspec on the RevertOptions struct, `revertAddress` is the `Address to receive revert`, while  `abortAddress` is the `Address to receive funds if aborted`. abortAddress is always set as `address(0)`, this means in cases where the transactions are aborted funds are sent to address(0) which will be irrecoverable.

```solidity
  gateway.withdrawAndCall(
            contractAddress,
            outputAmount,
            targetZRC20,
            message,
            CallOptions({
                isArbitraryCall: false,
                gasLimit: gasLimit
            }),
            RevertOptions({
                revertAddress: address(this),
                callOnRevert: true,
          @>      abortAddress: address(0),
                revertMessage: bytes.concat(externalId, receiver),
                onRevertGasLimit: gasLimit
            })
        );

```

### Root Cause

`AbortAddress` is set as `address(0)`, on every aborted transactions, funds will be sent to the zero address which will be irrecoverable.
