# `GatewayTransferNative::_doMixSwap` does not handle if cross chain swap using ZETA to swap for another token chain

### Summary

function `withdrawToNativeChain` can be used to swap any token to resulting native token for the destination chain using dodo swap.
but this function would fail if the token used is native ZETA token because it is unhandled in `_doMixSwap`

### Root Cause

[GatewayTransferNative.sol#L425-L434](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L425-L434)
```solidity
    function _doMixSwap(
        bytes memory swapData, 
        uint256 amount, 
        MixSwapParams memory params
    ) internal returns (uint256 outputAmount) {
        if (swapData.length == 0) {
            return amount;
        }

@>        IZRC20(params.fromToken).approve(DODOApprove, amount);
```

the root cause because here fromToken is used with ZRC20 interface to call approve function, as we know if we use ZETA then the fromToken would be `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE`, so it would try to call approve on this address where it would fails.

### Attack Path

1. user wants to swap ZETA to ETH.ETH and then withdraw it to ETH mainnet
2. user then calls `withdrawToNativeChain` providing amount via msg.value, and `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE` as zrc20 address
3. the line [GatewayTransferNative.sol#L535-L537](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L535-L537) would check if the original token is native token or not, because it is native token, no need to transfer because the amount already sent via `msg.value`
4. function proceed to `_doMixSwap` using decoded swap data and params
5. function would revert because it would try to approve spending into `0xEeeeeEeeeEeEeeEeEeEeeEEEeeeeEeeeeeeeEEeE` address

### Impact

break core function because of unhandled native zeta token swap

### PoC

_No response_

### Mitigation

change the line inside `_doMixSwap` to handle native zeta token
```diff
-        IZRC20(params.fromToken).approve(DODOApprove, amount);
+        if (params.fromToken != _ETH_ADDRESS_) IZRC20(params.fromToken).approve(DODOApprove, amount);
```

only the following change is needed, because the zeta native token would be handled correctly inside [dodo route proxy](https://etherscan.io/address/0xa2398842F37465f89540430bDC00219fA9E4D28a) contract
