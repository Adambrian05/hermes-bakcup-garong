# No Validation for Slippage Parameter

### Summary

The contract initializes with a slippage parameter but does not validate its value and does not provide a function to update it after initialization.

Link to code:
- [initialize](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L109-L127)

### Root Cause

The `slippage` parameter is used to calculate the maximum amount to input for a swap (`amountInMax = (amountsQuote[0]) + (slippage * amountsQuote[0]) / 1000`). However, there is no validation to ensure this parameter is reasonable, and unlike other parameters like `feePercent` and `gasLimit`, there is no function to update it after contract initialization. This limits the contract's ability to adapt to changing market conditions.

### Attack Path

1. The `slippage` parameter is set during initialization without validation.
2. It is used in `_swapAndSendERC20Tokens` to calculate amountInMax for swaps.
3. An unreasonably high slippage could lead to excessive slippage tolerance, potentially resulting in unfavorable trades.
4. An unreasonably low slippage could cause transactions to fail in volatile market conditions.
5. Unlike other parameters, there is no function to update `slippage` after initialization.

### Impact

Impact: Medium - Inappropriate slippage values could lead to failed transactions or unfavorable trades.

Likelihood: Medium - Market conditions change over time, and the inability to update slippage could cause issues.

### Mitigation

Add validation for the slippage parameter during initialization and provide a function to update it.
```solidity
// Add this event declaration with the other events
event SlippageUpdated(uint256 slippage);

// Define reasonable bounds for slippage
uint256 public constant MAX_SLIPPAGE = 100; // 10%

function initialize(
    address payable _gateway,
    address _EddyTreasurySafe,
    address _dodoRouteProxy,
    address _dodoApprove,
    uint256 _feePercent,
    uint256 _slippage,
    uint256 _gasLimit
) public initializer {
    require(_slippage <= MAX_SLIPPAGE, "Slippage exceeds maximum allowed");
    __Ownable_init(msg.sender);
    __UUPSUpgradeable_init();
    gateway = GatewayZEVM(_gateway);
    EddyTreasurySafe = _EddyTreasurySafe;
    DODORouteProxy = _dodoRouteProxy;
    DODOApprove = _dodoApprove;
    feePercent = _feePercent;
    slippage = _slippage;
    gasLimit = _gasLimit;
}

function setSlippage(uint256 _slippage) external onlyOwner {
    require(_slippage <= MAX_SLIPPAGE, "Slippage exceeds maximum allowed");
    slippage = _slippage;
    emit SlippageUpdated(_slippage);
}
```
