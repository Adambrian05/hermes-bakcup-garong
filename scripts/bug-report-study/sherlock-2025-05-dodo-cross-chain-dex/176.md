# Anyone can claim refund if refundInfo.walletAddress is incorrect

### Summary

[GatewayTransferNative.sol:claimRefund()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L661) and [GatewayCrossChain.sol:claimRefund()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L571) uses `msg.sender` as receiver for refund if `walletAddress` is incorrect. This will allow anyone to claim tokens.

### Root Cause

In `GatewayTransferNative.sol:onRevert()` and `GatewayCrossChain.sol:onRevert()` if `revertMessage` has incorrect length then tokens will be used for refund:
```solidity
function onRevert(RevertContext calldata context) external onlyGateway {
    // 52 bytes = 32 bytes externalId + 20 bytes evmWalletAddress
    bytes32 externalId = bytes32(context.revertMessage[0:32]);
    bytes memory walletAddress = context.revertMessage[32:];
    if(context.revertMessage.length == 52) {
        ...
    } else {
        //@audit set refundInfo if revertMessage is incorrect
        RefundInfo memory refundInfo = RefundInfo({
            externalId: externalId,
            token: context.asset,
            amount: context.amount,
            walletAddress: walletAddress
        });
        refundInfos[externalId] = refundInfo;
        ...
    }
}
```
In `claimRefund()` `receiver` changed from `msg.sender` only if `refundInfo.walletAddress.length == 20`:
```solidity
function claimRefund(bytes32 externalId) external {
    RefundInfo storage refundInfo = refundInfos[externalId];

    address receiver = msg.sender;
    if(refundInfo.walletAddress.length == 20) {
        receiver = address(uint160(bytes20(refundInfo.walletAddress)));
    }
    require(bots[msg.sender] || msg.sender == receiver, "INVALID_CALLER");
    require(refundInfo.externalId != "", "REFUND_NOT_EXIST");
    TransferHelper.safeTransfer(refundInfo.token, receiver, refundInfo.amount);
    delete refundInfos[externalId];
    ...
}
```
The point is that if `revertMessage` originally had the wrong length in `onRevert()`, then `refundInfo.walletAddress.length` will also have the wrong length. This would allow anyone to claim these tokens.
