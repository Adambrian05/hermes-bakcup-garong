# withdrawToNativeChain will revert if zrc20 == _ETH_ADDRESS_

### Summary

If `zrc20` parameter of `GatewayTransferNative::withdrawToNativeChain` is `_ETH_ADDRESS_`, it means received token is native token (i.e. gas token).

The contract tries to collect platform fee in ERC20 manner even if received token is the native token.

Thus, the transaction will revert.

### Root Cause

[File: omni-chain-contracts/contracts/GatewayTransferNative.sol](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530-L552)

If `zrc20 == _ETH_ADDRESS_`, the contract received `amount` in native token (ZETA).

However, in L551, the contract tries to collect platform fee in ERC20 manner, which will cause a revert.
