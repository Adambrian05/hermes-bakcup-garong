# abortAddress is not set correctly

### Summary

Both GatewayTransferNative and GatewayCrossChain have an onAbort function that allows handling aborted transactions. However, currently only transactions sent from GatewaySend are processed through onAbort, while those sent from ZetaChain are not. This can lead to user funds being lost in certain scenarios.

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L277C1-L295C6

```solidity
    function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
    ) internal {
        gateway.withdraw(
            sender,
            amount,
            outputToken,
            RevertOptions({
                revertAddress: address(this),
                callOnRevert: true,
                abortAddress: address(0),
                revertMessage: bytes.concat(externalId, bytes20(sender)),
                onRevertGasLimit: gasLimit
            })
        );
    }
```
