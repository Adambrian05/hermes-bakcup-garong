# The protocol does not support USDT

### Summary

`GatewaySend.depositAndCall()` requires transferFrom to return true, which does not apply to USDT

### Root Cause

According to the documentation, the protocol supports cross-chain transfers of USDT.ETH, however in [GatewaySend.sol](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L238-L241), `GatewaySend.depositAndCall()` requires `transferFrom()` to return true, which does not apply to USDT. This results in users being unable to cross-chain USDT from the mainnet to Zeta and other chains.
```solidity
    function transferFrom(address _from, address _to, uint _value) public onlyPayloadSize(3 * 32) {
        var _allowance = allowed[_from][msg.sender];

        // Check is not needed because sub(_allowance, _value) will already throw if this condition is not met
        // if (_value > _allowance) throw;

        uint fee = (_value.mul(basisPointsRate)).div(10000);
        if (fee > maximumFee) {
            fee = maximumFee;
        }
        if (_allowance < MAX_UINT) {
            allowed[_from][msg.sender] = _allowance.sub(_value);
        }
        uint sendAmount = _value.sub(fee);
        balances[_from] = balances[_from].sub(_value);
        balances[_to] = balances[_to].add(sendAmount);
        if (fee > 0) {
            balances[owner] = balances[owner].add(fee);
            Transfer(_from, owner, fee);
        }
        Transfer(_from, _to, sendAmount);
    }
```
