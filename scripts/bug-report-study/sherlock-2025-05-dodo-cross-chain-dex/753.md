# Unsafe Address Decoding in onRevert: Potential Fund Loss via Improper Byte Slice

## Description
The issue lies in the function onRevert, context.revertMessage[0:32] gives everything from bytes 32 to the end of the bytes array, not just the next 20 bytes for the address. If revertMessage.length > 52, this will still decode the address, but will silently include extra trailing bytes, which could lead to funds transferred to wrong address.

Problem Summary:
```solidity
address sender = address(uint160(bytes20(context.revertMessage[32:])));
```
This line is not extracting exactly the 20 bytes needed for the address. Instead, context.revertMessage[32:] returns all bytes starting from index 32 to the end, which could be more than 20 bytes if revertMessage.length > 52. This will silently cast the first 20 bytes of a larger slice, and could lead to:

Incorrect address decoding.

Transfer of funds to an unintended address

## Recommendation
Apply both of the following fixes to fully mitigate the risk:

.1. Exact Slicing of 20 Bytes
Ensure you only decode bytes 32 to 51 (inclusive), which are exactly 20 bytes:
```solidity
address sender = address(uint160(bytes20(context.revertMessage[32:52])));
```
2. Length Check for Safety
Require the revertMessage to be long enough:
```solidity
require(context.revertMessage.length >= 52, "Invalid revertMessage length");
```
Final Safe Code:
```solidity
function onRevert(RevertContext calldata context) external onlyGateway {
    require(context.revertMessage.length >= 52, "Invalid revertMessage length");

    bytes32 externalId = bytes32(context.revertMessage[0:32]);
    address sender = address(uint160(bytes20(context.revertMessage[32:52])));
    TransferHelper.safeTransfer(context.asset, sender, context.amount);

    emit EddyCrossChainRevert(
        externalId,
        context.asset,
        context.amount,
        sender
    );
}
```
This solution:

Enforces correct memory boundaries.

Avoids unsafe casts and silent bugs.

Prevents attacks where malicious revertMessage tricks the contract into sending funds to an attacker
