# onRevert doesn't handle native tokens leading to stuck funds

### Summary

If a user calls `GatewaySend:depositAndCall` using GatewayCrossChain as the targetContract and a revert occurs on the destination chain where the token is Zeta, then `GatewayZEVM:depositAndRevert` is called, which transfers native Zeta and then calls `GatewayGatewayCrossChain::onRevert`:
```solidity
function depositAndRevert(
        uint256 amount,
        address target,
        RevertContext calldata revertContext
    )
        external
        nonReentrant
        onlyProtocol
        whenNotPaused
    {
        GatewayZEVMValidations.validateZetaDepositAndCallParams(amount, target, PROTOCOL_ADDRESS, address(this));

        _transferZETA(amount, target);
        Revertable(target).onRevert(revertContext);
    }
```

The problem is that `GatewayGatewayCrossChain::onRevert` doesn't handle native Zeta, so it will revert. There's no `onAbort` address set so the funds will then get stuck on Zetachain.

### Root Cause

`GatewayGatewayCrossChain::onRevert` doesn't handle native Zeta and no onAbort address is set.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L264

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L517-L548

It should also be noted that onRevert doesn't handle the native token in GatewaySend or GatewayTransferNative either.


### Internal Pre-conditions

1. The `targetZRC20` is Zeta when GatewayCrossChain::onCall calls gateway.withdrawAndCall
2. onCall reverts on the destination chain

### External Pre-conditions

n/a

### Attack Path

1. User initiates depositAndCall using GatewayCrossChain as the target.
2. Destination chain reverts the transaction where Zeta is the token, triggering GatewayZEVM:depositAndRevert.
3. GatewayZEVM transfers native Zeta to GatewayCrossChain and calls onRevert.
4. GatewayCrossChain:onRevert reverts due to missing native Zeta handling.
5. Without a configured onAbort address, the native Zeta tokens become permanently stuck on Zetachain.

### Impact

Stuck funds. 

### PoC

_No response_

### Mitigation

Handle native tokens in all the onRevert function calls.
