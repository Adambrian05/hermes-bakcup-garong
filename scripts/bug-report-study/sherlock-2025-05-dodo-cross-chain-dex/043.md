# GatewayTransferNative:_doMixSwap() reverts when native token is used

### Summary

`GatewayTransferNative.sol:_doMixSwap()` function always use `approve` function for ZRC20, even though native token can be used.

### Root Cause

[GatewayTransferNative.sol:_doMixSwap()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L425) always use `IZRC20.approve()` function before calling `IDODORouteProxy.mixSwap()`:
```solidity
function _doMixSwap(
    bytes memory swapData, 
    uint256 amount, 
    MixSwapParams memory params
) internal returns (uint256 outputAmount) {
    if (swapData.length == 0) {
        return amount;
    }
    IZRC20(params.fromToken).approve(DODOApprove, amount);
    //@audit native token can be used
    return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
    ...
}
```
But [withdrawToNativeChain()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530) may use native tokens:
```solidity
function withdrawToNativeChain(
    address zrc20,
    uint256 amount,
    bytes calldata message
) external payable {
    if(zrc20 != _ETH_ADDRESS_) {
        require(IZRC20(zrc20).transferFrom(msg.sender, address(this), amount), "INSUFFICIENT ALLOWANCE: TRANSFER FROM FAILED");
    } 
    ...
    // Swap on DODO Router
    uint256 outputAmount = _doMixSwap(decoded.swapDataZ, amount, params);
    ...
}
```
`_doMixSwap` function will revert because it calls to non-existent contract.

### Mitigation

Change `_mixSwap()` function like in [GatewaySend.sol](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L195) contract:
```solidity
if(params.fromToken != _ETH_ADDRESS_) {
    IERC20(params.fromToken).approve(DODOApprove, params.fromTokenAmount);
}
```
