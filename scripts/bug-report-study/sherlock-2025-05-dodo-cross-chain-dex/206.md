# # Hard-coded `UniswapRouter` and `UniswapFactory` address in `GatewayCrossChain.sol` and `GatewayTransferNative.sol`.

## Root Cause
The team has mentioned about which chains the contracts are to be deployed in the readme
""
On what chains are the smart contracts going to be deployed?

ZetaChain, Ethereum, Polygon, Arbitrum, Base, BNB Chain. 
"".
but `GatewayCrossChain.sol` contract and `GatewayTransferNative.sol` uses hard-coded `UniswapRouter` and `UniswapFactory` addresses.

https://github.com/Skyewwww/omni-chain-contracts/blob/2fe44d3da76b721e4d32addfecb04ca97a39cb0d/contracts/GatewayCrossChain.sol#L22

https://github.com/Skyewwww/omni-chain-contracts/blob/2fe44d3da76b721e4d32addfecb04ca97a39cb0d/contracts/GatewayCrossChain.sol#L23

https://github.com/Skyewwww/omni-chain-contracts/blob/2fe44d3da76b721e4d32addfecb04ca97a39cb0d/contracts/GatewayTransferNative.sol#L23

https://github.com/Skyewwww/omni-chain-contracts/blob/2fe44d3da76b721e4d32addfecb04ca97a39cb0d/contracts/GatewayTransferNative.sol#L24

```solidity
    address public constant UniswapRouter = 0x2ca7d64A7EFE2D62A725E2B35Cf7230D6677FfEe;
    address public constant UniswapFactory = 0x9fd96203f7b22bCF72d9DCb40ff98302376cE09c;
```
these are the address of the uniswap router and uniswap factory in the zeta chain.

https://explorer.zetachain.com/address/0x9fd96203f7b22bcf72d9dcb40ff98302376ce09c

https://explorer.zetachain.com/address/0x2ca7d64A7EFE2D62A725E2B35Cf7230D6677FfEe

the address of the UniswapV2Factory in ethereum is `0x5C69bEe701ef814a2B6a3EDD4B1652CB9cc5aA6f`

https://etherscan.io/address/0x5C69bEe701ef814a2B6a3EDD4B1652CB9cc5aA6f

 Router address in ethereum is `0xf164fC0Ec4E93095b804a4795bBe1e041497b92a`

 https://etherscan.io/address/0xf164fC0Ec4E93095b804a4795bBe1e041497b92a

 As you can see the addresses are different and this is the same case on all the above mentioned chains.

## Impact 
All the interaction with the factory contract and router contract will revert as the addresses are different across all the chains

## Reccomended mitigation
Use the `initialize()` function to set the router and factory addresses by passing in the appropriate values for the target chain.
