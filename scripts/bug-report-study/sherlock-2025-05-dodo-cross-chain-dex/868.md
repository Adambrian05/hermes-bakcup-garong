### Root Cause

The protocol uses Solidity’s transfer() when transferring ETH to the recipients. This has some notable shortcomings when the recipient is a smart contract, which can render ETH impossible to transfer. Specifically, this wouldnt happen before the pectra but with eip7702 the transfer will inevitably fail when the address have some logic as :

does not implement a payable fallback function, or
implements a payable fallback function which would incur more than 2300 gas units, or
implements a payable fallback function incurring less than 2300 gas units but is called through a proxy that raises the call’s gas usage above 2300.
