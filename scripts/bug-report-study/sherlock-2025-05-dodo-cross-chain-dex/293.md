### Attack Path

1. Alice approves Bob for 100 tokens
2. Alice wants to reduce it to 50 tokens
3. Before she submits the new approve(), Bob front-runs and spends the original 100
4. Then Alice’s transaction executes and sets it to 50 → Bob stole funds

### Impact

attacker can steal user's token using fronend running

### Mitigation
