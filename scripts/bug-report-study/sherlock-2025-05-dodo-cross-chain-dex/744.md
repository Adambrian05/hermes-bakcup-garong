# Theft of funds due to missing access control in `GatewayNativeTransfer` contract

### Summary

Theft of funds due to missing access control in function `GatewayNativeTransfer::withdraw()`

### Root Cause

The function [`GatewayNativeTransfer::withdraw()`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286) is expected to be called within the process of withdrawing bitcoin. However, the function is made `public` without access control, which can allow arbitrary caller to withdraw funds in the contract
```solidity
    function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
    ) public {
        gateway.withdraw(
            sender,
            amount,
            outputToken,
            RevertOptions({
                revertAddress: address(this),
                callOnRevert: true,
                abortAddress: address(0),
                revertMessage: bytes.concat(externalId, bytes20(sender)),
                onRevertGasLimit: gasLimit
            })
        );
    }
```

### Attack Path

1. An attacker calls `GatewayNativeTransfer::withdraw()` with `sender` is his controlled address, `outputToken` is the wanted token to steal with appropriate `amount` ==> the funds held by the contract is withdrawn to connected chain ==> stealing of funds

### Impact

- Theft of funds holding by the contract
- Stealing pending claim funds
