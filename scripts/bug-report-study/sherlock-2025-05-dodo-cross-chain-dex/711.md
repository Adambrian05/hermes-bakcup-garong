# onRevert will send BTC to wrong address.

At the core, Bitcoin uses hashes like RIPEMD-160, which are 160-bit (i.e., 20-byte) hashes. That’s the same binary length as Ethereum addresses. In Bitcoin, P2PKH (Pay to Public Key Hash) and P2SH (Pay to Script Hash) addresses are both derived from RIPEMD-160(SHA256(pubkey)). The resulting address hash portion is 160 bits (20 bytes) in length.
