# Fees not taken into account in `GatewayTransferNative::onCall` if `targetZRC20 != zrc20`

### Summary
`GatewayTransferNative::onCall` deducts and transfers fees to `EddyTreasurySafe` but doesn't take this fee into account when `targetZRC20 != zrc20`.

### Root Cause
`platformFeesForTx` is calculated and transferred to `EddyTreasurySafe`:
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370-L371
```solidity
        // Fee for platform
        uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); // platformFee = 5 <> 0.5%
        address receiver = address(uint160(bytes20(decoded.receiver)));
```
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L341-L347
```solidity
    function _handleFeeTransfer(
        address zrc20,
        uint256 amount
    ) internal returns (uint256 platformFeesForTx) {
        platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
        TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx); //@audit transfer to EddyTreasurySafe
    }
```
but the full amount is still used when `targetZRC20 != gasZRC20`:
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L395
```solidity
        // Fee for platform
        uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); // @audit fees charged here
        address receiver = address(uint160(bytes20(decoded.receiver)));
        if (decoded.targetZRC20 == zrc20) {
            // same token
            TransferHelper.safeTransfer(
                decoded.targetZRC20,
                receiver,
                amount - platformFeesForTx //@audit fees taken into account here
            );
        } else {
            // Swap on DODO Router
            //@audit but full amount is used here, we have not deducted platformFeesForTx
            uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
            if (decoded.targetZRC20 == WZETA) {
                // withdraw WZETA to get Zeta in 1:1 ratio
                IWETH9(WZETA).withdraw(outputAmount);
                // transfer wzeta
                TransferHelper.safeTransferETH(receiver, outputAmount);
            } else {
                TransferHelper.safeTransfer(
                    decoded.targetZRC20,
                    receiver,
                    outputAmount
                );
            }
```

### Internal Pre-conditions
- `decoded.targetZRC20 != zrc20`
- `feePercent > 0`

### External Pre-conditions
---

### Attack Path
1. Alice deposits 100 USDT into zeta chain to swap it to USDC_ZRC20
2. 0.5% fee is deducted as `platformFeesForTx` from 100 USDT and transferred to `EddyTreasurySafe`
3. Since `targetZRC20 != zrc20`, a mixSwap is performed with `amount`
4. At this step there are two scenarios:
    - Contract holds enough assets (other user refunds) hence the swap goes through but the `platformFeesForTx` is paid from other users' funds
    - Contract doesn't hold enough assets (`USDT_zrc20.balanceOf(GatewayTransferNative) < amount`) and swap fails due to insufficient funds

### Impact
- The asset might be used from other users' refunds which might cause some users to not be able to claim their refunds
- If the contract does not have enough assets, the CCTX fails resulting in user loss of funds as they have paid gas

### Mitigation
```diff 
       } else {
            // Swap on DODO Router
-           uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
+           uint256 outputAmount = _doMixSwap(decoded.swapData, amount - platformFeesForTx, params);
```
