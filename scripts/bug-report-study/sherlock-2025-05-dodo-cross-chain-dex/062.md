# `GatewayTransferNative::_doMixSwap` would fail because it using msg.value that already deducted by fee

### Summary

as we know that doing `withdrawToNativeChain` using zeta native token, the msg.value would be forwarded into dodo router contract.
but this is problematic because the msg.value is actually deducted by fee, but the call to dodo router are using the full amount of `msg.value` which is insufficient and would lead to revert.

### Root Cause

[GatewayTransferNative.sol#L530-L555](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530-L555)
```solidity
    function withdrawToNativeChain(
...
        // Transfer platform fees
        uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); // platformFee = 5 <> 0.5%
@>        amount -= platformFeesForTx;

        // Swap on DODO Router
@>        uint256 outputAmount = _doMixSwap(decoded.swapDataZ, amount, params);
```

notice that here the amount is deducted by fees.

but in the `_doMixSwap` we forward the full amount of msg.value to the dodo router:
[GatewayTransferNative.sol#L435](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L435)
```solidity
    function _doMixSwap(
...
@>        return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
...
```

this means that the function would sent inflated amount, which if the contract does not have zeta inside then this function would revert.
worse if the contract held zeta, because of refunds, this would effectively use other funds to swap.

### Attack Path

the issue is simple as 
1. user try to swap zeta native token to ETH.ETH then withdraw it to ETH mainnet, the msg.value is 1 ZETA
2. if the fee is 0.5%, then 0.005 ZETA would be sent into treasury
3. but now contract still try to swap full amount of msg.value which is 1 ZETA
4. if there are dangling fund inside the contract from refunds, it try to use it, stealing user funds
5. if there are no ZETA inside, the function revert

### Impact

there are two impact:
1. another user ZETA refund would mistakenly used to swap into dodo router
2. core function breaks because insufficient funds

the function _doMixSwap should be fixed like:

```diff
-        return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
+        return IDODORouteProxy(DODORouteProxy).mixSwap{value: amount}(
```
