# Use `safeTransferETH` instead of `transfer` in `GatewaySend::onCall`

### Summary

Using [transfer](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L370-L371) can be dangerous, because it only forwards 2300 gas to the callee. If the calleee has any logic inside his `receive/fallback` functions, then he won't have enough gas to execute his logic.

This will most likely be account abstraction wallets or smart contracts build around the use of DODO's cross chain swap.

### Root Cause

Using `transfer` function

### Internal Pre-conditions

None

### External Pre-conditions

Receiver is address with code in `fallback` function

### Attack Path

It's simple

### Impact

Broken functionality

### PoC

_No response_

### Mitigation

Use `safeTransferETH` instead of the native `transfer`.
