# Data Format Decoding Causes Cross-Chain Transaction Failure

## Description
The `GatewaySend` contract implements two incompatible decoding systems to handle swap data in cross-chain transactions. The first system uses the internal functions `decodePackedMessage()` and `decodePackedData()`, while the second system uses `SwapDataHelperLib.decodeCompressedMixSwapParams()`.

These two systems expect completely different data formats, which will cause data encoded with one format to not be decoded with the other format and cross-chain transactions to fail due to incorrect data parsing.

## Root Cause
The root of the problem lies in the inconsistency of the decoding architecture:

In the `onCall()` function, using `decodePackedMessage()` and `swapData` from `decodePackedMessage()` is passed to `_doMixSwap()`.
```solidity
function onCall(
    MessageContext calldata /*context*/,
    bytes calldata message
) external payable onlyGateway returns (bytes4) {
    // ❌ PROBLEM: Using decodePackedMessage()
    (
        bytes32 externalId,
        uint256 amount,                 // ❌ FIRST DATA SOURCE
        bytes calldata recipient,
        address fromToken,
        address toToken,
        bytes calldata swapData
    ) = decodePackedMessage(message);
    
    // ...
    if(fromToken == toToken) {
        // ❌ PROBLEM: swapData from decodePackedMessage() is passed to _doMixSwap()
        outputAmount = _doMixSwap(swapData);    // ❌ NOT FORWARDING amount
    }
}
```
The `_doMixSwap()` function uses a second decoding system.
```solidity
function _doMixSwap(bytes calldata swapData) internal returns (uint256) {
    // ❌ PROBLEM: Expecting SwapDataHelperLib format
    MixSwapParams memory params = SwapDataHelperLib.decodeCompressedMixSwapParams(swapData);
    
    // ...
    // SWAP BASED ON params.fromTokenAmount
    return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
        params.fromToken,
        params.toToken,
        params.fromTokenAmount,    // ❌ MAY BE DIFFERENT FROM the amount FROM onCall!
        // ... other parameters
    );
}
```
Incompatible data formats:

`decodePackedData()` format (System 1).
```solidity
function decodePackedData(bytes calldata data) internal pure returns (...) {
    // FORMAT: [tokenA(20)] + [tokenB(20)] + [swapDataB(variable)]
    assembly {
        tokenA := shr(96, calldataload(data.offset))           // 20 bytes
        tokenB := shr(96, calldataload(add(data.offset, 20)))  // 20 bytes
    }
    
    if (data.length > 40) {
        swapDataB = data[40:];  // Remaining data
    }
}
```
Format `SwapDataHelperLib.decodeCompressedMixSwapParams()` (System 2).
```solidity
function decodeCompressedMixSwapParams(bytes calldata data) internal pure returns (MixSwapParams memory) {
    // FORMAT: [fromToken(20)] + [toToken(20)] + [fromTokenAmount(32)] + 
    //         [expReturnAmount(32)] + [minReturnAmount(32)] + [directions(32)] + 
    //         [deadline(32)] + [adapterLen(1)] + [adapters...] + [pairs...] + [moreInfo...]
    
    assembly {
        fromToken := shr(96, calldataload(add(data.offset, offset)))
        offset := add(offset, 20)
        toToken := shr(96, calldataload(add(data.offset, offset)))
        offset := add(offset, 20)
        fromTokenAmount := calldataload(add(data.offset, offset))
        offset := add(offset, 32)
        // ... other complex parsing
    }
}
```

## Impact
All cross-chain transactions that require swaps will fail and users will not be able to swap tokens between blockchains.

## Scenario Step by Step
1. User A on Chain A calls `depositAndCall()` with swap:
```diff
gatewaySend.depositAndCall(
    USDC,           // fromToken
    1000e6,         // amount
    swapData,       // Data in SwapDataHelperLib format
    targetContract, // Contract in Chain B
    WETH,           // asset output
    chainB,         // destination chain
    payload         // additional data
);
```
2. The GatewaySend contract on Chain A processes the transaction:
- `_doMixSwap(swapData)` succeeds because it uses the correct format
- Tokens are swapped from USDC to WETH
- Message is sent to Chain B with the format `buildOutputMessage()`
3. The Gateway receives the message on Chain B and calls `onCall()`:
```diff
// Message format: [externalId(32)] + [outputAmount(32)] + [receiverLen(2)] + 
//                 [crossChainDataLen(2)] + [receiver] + [crossChainData]
// 
// crossChainData format: [fromToken(20)] + [toToken(20)] + [swapDataB]
```
4. The `onCall()` function performs decoding:
```diff
(externalId, amount, recipient, fromToken, toToken, swapData) = decodePackedMessage(message);
```
5. PROBLEM OCCURRED: `swapData` returned from `decodePackedData()` has the format:
```diff
Format Actual: [arbitrary_data_from_position_40_onwards]
Format Expected: [fromToken(20)] + [toToken(20)] + [fromTokenAmount(32)] + ...
```
6. When `_doMixSwap(swapData)` is called:
```diff
// ❌ SwapDataHelperLib.decodeCompressedMixSwapParams() tries to parse:
// - Reading fromToken from position 0-19 (invalid data)
// - Reading toToken from position 20-39 (invalid data)
// - Reading fromTokenAmount from position 40-71 (invalid data)
// - etc...
```
7. Final result:
- Parsing fails or produces incorrect parameters
- Revert or swap transaction with invalid parameters

## Recommendation
Use one consistent decoding system across contracts.
```solidity
// ✅ FIX: Modify encodePacked Message() to use SwapDataHelperLib
function decodePackedMessage(
    bytes calldata message
) internal pure returns (
    bytes32 externalId,
    uint256 outputAmount,
    bytes calldata receiver,
    address fromToken,
    address toToken,
    bytes calldata swapDataB
) {
    uint16 receiverLen;
    uint16 crossChainDataLen;
    bytes calldata crossChainData;

    assembly {
        externalId := calldataload(message.offset)
        outputAmount := calldataload(add(message.offset, 32))
        receiverLen := shr(240, calldataload(add(message.offset, 64)))
        crossChainDataLen := shr(240, calldataload(add(message.offset, 66)))
    }

    uint offset = 68;
    receiver = message[offset : offset + receiverLen];
    offset += receiverLen;
    crossChainData = message[offset : offset + crossChainDataLen];

    // ✅ FIX: Use SwapDataHelperLib for consistency
    (fromToken, toToken, swapDataB) = _decodePackedDataConsistent(crossChainData);
}

// ✅ FIX: Helper functions consistent with SwapDataHelperLib
function _decodePackedDataConsistent(bytes calldata data) internal pure returns (
    address tokenA,
    address tokenB,
    bytes calldata swapDataB
) {
    assembly {
        tokenA := shr(96, calldataload(data.offset))
        tokenB := shr(96, calldataload(add(data.offset, 20)))
    }

    if (data.length > 40) {
        swapDataB = data[40:];
    } else {
        swapDataB = data[0:0];
    }
}
```
