# Zetachain MAX_PAYLOAD_SIZE can be exceeded in cross chain swaps

### Summary

GatewayEVM::depositAndCall requires the `payload.length + revertOptions.revertMessage.length` to be less than 1024:
```solidity
function depositAndCall(
        address receiver,
        bytes calldata payload,
        RevertOptions calldata revertOptions
) external payable  whenNotPaused {
...
>>>     if (payload.length + revertOptions.revertMessage.length > MAX_PAYLOAD_SIZE) {
            revert PayloadSizeExceeded(payload.length + revertOptions.revertMessage.length, MAX_PAYLOAD_SIZE);
        }
...
}
```

When `GatewaySend:depositAndCall` is called with the targetContract set to GatewayCrossChain and swaps are performed on both Zetachain and the destination chain, the total size can exceed 1024. 

### Root Cause

Dodo swap paramaters utilize a large number of bytes, especially will multi step swaps.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L292

### Internal Pre-conditions

1. User performs a cross chain swap
2. User swaps on both Zetachain and the destination chain

### External Pre-conditions

N/A

### Attack Path

See POC for an example that exceeds the MAX_PAYLOAD_SIZE.

### Impact

Some cross chain transactions will be impossible and users will waste gas.

### PoC

Create a new file in /test/ and title `PayloadSizeTest.t.sol`.

Paste the code below and run `forge test --mt test_exceedMaxPayloadSize --fork-url https://zetachain-evm.blockpi.network/v1/rpc/public -vv`

```solidity
// SPDX-License-Identifier: MIT

pragma solidity ^0.8.20;

import {BaseTest} from "./BaseTest.t.sol";
import "forge-std/Test.sol";


contract PayloadSizeExceeds1024Test is BaseTest {
    address public alice = makeAddr("alice");

    function setUp() public override {
        super.setUp();
    }

    function test_exceedMaxPayloadSize() public {
        bytes32 externalId = keccak256(abi.encodePacked(address(this), alice, uint256(1), block.timestamp));
        bytes memory revertMessage = bytes.concat(externalId, bytes20(alice));
        
        bytes memory swapDataZ = createSwapData(address(token2Z), address(token1Z), 100e18);
        bytes memory swapDataB = createSwapData(address(token1A), address(token2A), 100e18);

        bytes memory payload = encodeMessage(
            7000,
            address(token2Z),
            bytes.concat(bytes20(alice)),
            bytes.concat(bytes20(alice)),
            swapDataB,
            bytes.concat(bytes20(address(gatewayTransferNative))),
            swapDataZ,
            bytes.concat(bytes20(alice))
        );

        assertGt(payload.length + revertMessage.length, 1024);
        console.log("Total length: ", payload.length + revertMessage.length);
    }

    function createSwapData(
        address fromToken, 
        address toToken, 
        uint256 fromTokenAmount
    ) public returns (bytes memory) {
        bytes memory swapData = encodeCompressedMixSwapParams(
            fromToken,
            toToken,
            fromTokenAmount,
            0,
            0,
            new address[](3),
            new address[](3),
            new address[](3),
            0,
            new bytes[](3),
            abi.encode(address(0), 0),
            block.timestamp + 600
        );
        return swapData;
    }
}
```

### Mitigation

Possibly use another DEX if the payload size exceeds 1024 that utilizes less bytes for a swap.
