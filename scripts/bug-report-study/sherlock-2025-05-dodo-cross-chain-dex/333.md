# `GatewaySend::depositAndCall()` will revert with USDT permanetly.

### Summary

In [GatewaySend.sol::depositAndCall()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L238-L241), the function checks the return value from `transferFrom()`. However, some tokens like `USDT` does not return true when `transferFrom()` is succesfully called.



### Root Cause

In [GatewaySend.sol::depositAndCall()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L238-L241), the two same-named functions both check the return value from `transferFrom()`. However, some tokens like `USDT` does not return true when `transferFrom()` is succesfully called.
