# `GatewaySend` is not compatible with USDT on ethereum

### Summary

`GatewaySend` is not compatible with USDT on ethereum because of empty returned value from USDT

### Root Cause

[`GatewaySend`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L14) only uses IERC20 interface to handle ERC20 operations. Hence it is unable to work with USDT on Ethereum because USDT does not return value. So, the contract will revert at the below steps:
