# GatewayCrossChain contract will **revert DODO mixSwap calls**, wasting gas for end-users



### Summary

**Fee-deduction before approval** will cause a **reverting swap** for **users** as the **GatewayCrossChain contract** approves fewer tokens than it later asks the DODO RouteProxy to pull during `mixSwap`.

---

### Root Cause

In **`GatewayCrossChain.sol` – function `_doMixSwap`** the contract deducts the platform fee from `amount`, approves that smaller value, yet still passes the *original* `params.fromTokenAmount` to `mixSwap`.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L195

```solidity
// onCall()
uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount);
amount -= platformFeesForTx;                     // post-fee amount

// _doMixSwap()
IZRC20(params.fromToken).approve(DODOApprove, amount);          // allowance = A − fee
return IDODORouteProxy(DODORouteProxy).mixSwap(
        params.fromToken, params.toToken,
        params.fromTokenAmount,                                      // ← A (pre-fee)
        params.expReturnAmount, params.minReturnAmount,
        params.mixAdapters, params.mixPairs, params.assetTo,
        params.directions, params.moreInfo, params.feeData,
        params.deadline
); // ⇒ reverts: allowance < transfer amount
```

---

### Internal Pre-conditions

1. **Owner** sets `feePercent` to a value **greater than 0**.
2. **User** sends a cross-chain swap whose `swapDataZ` encodes `fromTokenAmount = A` equal to the full deposit.
3. The Gateway delivers `A` tokens to `onCall`.

---

### External Pre-conditions
NA
---

### Path

1. GatewayCrossChain receives `A` tokens.
2. `_handleFeeTransfer` moves `fee = A × feePercent / 1000` to the treasury.
3. Local variable `amount` becomes `A − fee`.
4. `_doMixSwap` approves `A − fee` for `DODOApprove`.
5. It then calls `mixSwap`, requesting `fromTokenAmount = A`.
6. DODO proxy executes `transferFrom`, sees allowance `A − fee < A`, and reverts.
7. GatewayCrossChain triggers `onRevert`/`onAbort`; user must claim a refund and has already paid destination-chain gas.

---

### Impact

The **user** loses the full destination-chain gas fee (tens to hundreds of USD in busy periods) for every attempted swap, while the intended cross-chain transfer is delayed and must be manually reclaimed. No direct monetary gain for an attacker, but persistent denial-of-service for normal operation when `feePercent > 0`.

---

### Mitigation

*Approve exactly what will be pulled*:

```solidity
IZRC20(params.fromToken).approve(DODOApprove, params.fromTokenAmount);
```
