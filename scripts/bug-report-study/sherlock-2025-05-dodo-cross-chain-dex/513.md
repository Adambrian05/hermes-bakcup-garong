# unsafe erc-20 transfer

### Summary

there an unsafe erc-20 operation inside `onCall` function , there no check if the transfer is done or not . 

Some tokens do not return a bool (e.g. USDT, BNB) on ERC20 methods. This will make the call break,
making it impossible to use these tokens.


### Root Cause

in `onCall` function there is token transfer that is uncheck , the contract will be deployed on ETH main net and USDT will be used . 

```solidity
IERC20(toToken).transfer(evmWalletAddress, outputAmount);
```

there is two problem here , one that USDT is not compliant with IERC20 interface because it don't return a value and the transfer is not checked if the transfer is done or not.
