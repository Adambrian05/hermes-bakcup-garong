# Users will lose platform fees when cross-chain swaps fail

## Summary

**The incorrect fee handling in `onCall` will cause a permanent loss of platform fees for users as failed cross-chain swaps will be unable to refund the full amount due to fees already being transferred to treasury.**

## Root Cause
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370-L395

In `GatewayTransferNative::onCall`, the platform fees are transferred to treasury but the full original amount is still used for swapping, causing insufficient balance and transaction reverts.

```solidity
// 1. Fees transferred to treasury (tokens leave contract)
uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount);

// 2. Full amount used for swap (insufficient balance!)
uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
```

## Internal Pre-conditions

1. Fee percent needs to be set to a non-zero value (normal operation)
2. Cross-chain swap needs to be initiated through `onCall` function

## External Pre-conditions

1. DODO swap needs to fail for any reason (slippage, insufficient liquidity, price impact, etc.)

## Attack Path

1. **User initiates cross-chain swap** that triggers `onCall` on ZetaChain
2. **Contract transfers platform fees to treasury** via `_handleFeeTransfer()`, reducing available token balance
3. **Contract attempts to swap full original amount** via `_doMixSwap()` but fails due to insufficient balance
4. **Transaction reverts** and `onRevert` callback is triggered
5. **`onRevert` attempts to refund full `context.amount`** but contract lacks sufficient tokens since fees were already transferred to treasury
6. **Refund transaction fails**, causing permanent loss of user funds

## Impact

**Users suffer permanent loss of platform fees (0.5% by default) on every failed cross-chain swap transaction.** The contract cannot refund the full amount during revert handling because the fee portion was already transferred to treasury, making these funds irrecoverable.


## Mitigation

Reduce the amount used for swapping by the platform fees:

```solidity
uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount);
amount -= platformFeesForTx; // Add this line
uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
```
