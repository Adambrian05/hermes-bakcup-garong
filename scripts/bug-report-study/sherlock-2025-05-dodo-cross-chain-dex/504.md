# `onAbort()` of GatewayCrossChain and GatewayTransferNative will refund to the source chain address

### Summary

`onAbort()` of GatewayCrossChain and GatewayTransferNative will refund to the source chain address

### Root Cause

[GatewaySend.sol#L299](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L299-L305) will include the source chain wallet address in the revertMessage, which will be used for the refund in `onRevert()`.
```solidity
        RevertOptions memory revertOptions = RevertOptions({
            revertAddress: address(this),
            callOnRevert: true,
            abortAddress: targetContract,
            revertMessage: bytes.concat(externalId, bytes20(msg.sender)),
            onRevertGasLimit: gasLimit
        });
```
But the problem here is that if the transaction aborts, according to the [documentation](https://www.zetachain.com/docs/developers/chains/zetachain/#revert-transactions)
, it will call the onAbort() function on ZetaChain, and onAbort() will refund to the source chain wallet address. If the source chain wallet address is a smart contract address, ZetaChain may refund to an address that does not exist on ZetaChain.
```solidity
    function onAbort(AbortContext calldata abortContext) external onlyGateway {
        // 52 bytes = 32 bytes externalId + 20 bytes evmWalletAddress
        bytes32 externalId = bytes32(abortContext.revertMessage[0:32]);
        bytes memory walletAddress = abortContext.revertMessage[32:];

        RefundInfo memory refundInfo = RefundInfo({
            externalId: externalId,
            token: abortContext.asset,
            amount: abortContext.amount,
            walletAddress: walletAddress
        });
        refundInfos[externalId] = refundInfo;
        
        emit EddyCrossChainRefund(
            externalId,
            abortContext.asset,
            abortContext.amount,
            walletAddress
        );
    }
```

### Internal Pre-conditions

None

### External Pre-conditions

None

### Attack Path

None

### Impact

ZetaChain may refund to an address that does not exist on ZetaChain.

### PoC

_No response_

### Mitigation

It is recommended to include the ZetaChain wallet address in the revertMessage in GatewaySend and use it as the refund recipient in the onAbort() function of GatewayCrossChain and GatewayTransferNative
