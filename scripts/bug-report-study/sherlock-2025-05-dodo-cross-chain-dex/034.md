# Platform Fee Calculations That Can Lead to Over-Charging Users

## Description
There is a critical actual implementation issue in the platform fee calculation. The documentation states that the `feePercent` parameter uses basis points (1% = 100), but the actual implementation uses per mille (1% = 10). This can cause the system to misconfigure the platform fee and result in users being charged much higher fees than intended.

## Code Snippet
-	https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L106
-	https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L298

## Root Cause
The comments on the `initialize()` function state:
```solidity
* @param _feePercent Platform fee percentage in basis points (e.g., 10 = 1%)
```
Implementation in `_handleFeeTransfer()` function:
```solidity
function _handleFeeTransfer(address zrc20, uint256 amount) internal returns (uint256 platformFeesForTx) {
    // Calculate platform fees based on percentage
    // Example: if feePercent = 5, then fee = 0.5% (5/1000)
    platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
    
    // Transfer fees to Eddy's treasury using a secure helper
    TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
}
```
The root of the problem is that the comment states to use basis points (÷10,000) where 100 = 1%, while the implementation uses per mille (÷1,000) where 10 = 1%. The inline comment shows an example that is consistent with the implementation (5 = 0.5%) but contradicts the comment.

## Impact
Users can be charged 10x more than expected.

## Scenario
1. Initial Setup:
- The system reads the documentation stating "basis point (example: 10 = 1%)"
- The administrator wants to set the platform fee to 1%
2. Incorrect Configuration:
```diff
// The system calculates using basis points
gatewayCrossChain.setFeePercent(100); // Guess this = 1%
```
3. Actual Calculation:
```diff
// For 1000 token transactions
platformFeesForTx = (1000 * 100) / 1000 = 100 token = 10%
```
4. Impact:
- Users are charged 10% when it should be 1%
- User loss: 9% more than it should be

## Recommendation
Standardization to Basis Point.
```solidity
function _handleFeeTransfer(address zrc20, uint256 amount) internal returns (uint256 platformFeesForTx) {
    // Calculate platform fee based on basis points
    // Example: if feePercent = 100, then fee = 1% (100/10000)
    platformFeesForTx = (amount * feePercent) / 10000; // Using standard basis points
    
    // Transfer fees to Eddy's treasury using a secure helper
    TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
}
```
