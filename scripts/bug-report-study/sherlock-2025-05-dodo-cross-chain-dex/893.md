# Approving an excessive amount to Gateway may result in the theft of refund funds.



## Summary
Both GatewayCrossChain and GatewayTransferNative incorrectly approve an excessive amount of ZRC20 to Gateway. This could potentially allow attackers to steal funds from GatewayCrossChain and GatewayTransferNative through Gateway.

It can be observed that the actual cross-chain amount is `outputAmount - gasFee`, while the gas fee consumed is `gasFee`. Therefore, the total amount involved is `outputAmount`, not `outputAmount + gasFee`.  

As a result, after the transaction is completed, an approved amount equal to `gasFee` remains unused.  

Both the `GatewayCrossChain` and `GatewayTransferNative` contracts hold funds that should be refunded to users.  
An attacker could exploit the `Gateway` to steal funds from the `GatewayCrossChain` and `GatewayTransferNative` contracts, each time taking an amount equal to `gasFee`.  

Notably, `GatewayTransferNative` has a `withdraw()` function that could serve as an attack vector for this exploit.
```javascript
   function withdraw(
        bytes32 externalId,
        bytes memory sender,
        address outputToken,
        uint256 amount
    ) public {
@>        gateway.withdraw(
            sender,
            amount,

            RevertOptions({
                revertAddress: address(this),

```
An attacker can exploit the `withdraw` function by setting the `sender` as their own address, `outputToken` as `gasZRC20`, and `amount` as the excess approved `gasFee`.  

Due to fluctuating network gas fees, the attacker may not profit every time, but they can consistently deplete the refund reserves on `GatewayTransferNative`.

## Attack Path
1. The attacker discovers the last cross-chain transaction of the GatewayCrossChain or GatewayTransferNative contract.  
2. The attacker confirms the excess authorization of the GatewayCrossChain or GatewayTransferNative contract to the zeta gateway contract.  
3. The attacker transfers the excess authorized funds to themselves cross-chain via the withdraw() function.
## Impact
 The  funds on GatewayTransferNative will suffer losses.
