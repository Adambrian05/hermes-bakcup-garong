# USDT will dos `depositAndCall` function

### Summary

the function `depositAndCall` will not work when token `fromToken` is USDT.

### Root Cause

when user call `depositAndCall` and `fromToken` used is USDT , the TX will revert 

```solidity
require(//@audit will not work for usdt
                IERC20(fromToken).transferFrom(msg.sender, address(this), amount), 
                "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
            );
``` 
that because USDT is Non-Compliant ERC20 and do not return a bool value .
