# Attacker can withdraw all token from the contract use `GatewayTransferNative::withdraw`

### Summary

The `GatewayTransferNative::withdraw` function has no access control and the sender provided by the external, anyone can call this function to withdraw contract asset:

<img width="662" alt="Image" src="https://sherlock-files.ams3.digitaloceanspaces.com/gh-images/bfe0b5d1-3ee7-468d-af7d-a565cf67eb46" />

### Root Cause

The `GatewayTransferNative::withdraw` has no access control and anyone can call this function to withdraw contract's assets.

### Internal Pre-conditions

No pre conditions

### External Pre-conditions

No pre conditions

### Attack Path

1. attacker specify the `sender` param as the attacker's wallet address
2. provide the target asset address as `outputToken` and call 
3. call the `GatewayTransferNative::withdraw` function
4. the attacker wallet should receive the asset belongs to the contract

### Impact

Attacker can steal all the asset in the contract

### PoC

_No response_

### Mitigation

Add access control modifier to ensure trusted person can call this function
