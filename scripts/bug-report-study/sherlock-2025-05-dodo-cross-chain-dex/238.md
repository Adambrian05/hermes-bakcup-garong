# `GatewayCrossChain` don't have a `gasLimit` setter

### Summary

`gasLimit` is an important variable, which specifies to ZetaChain contracts what is the amount, which the caller agrees to pay on destination, or if the message reverts. Part of the underlying zrc20 tokens may be swapped to cover the native gas funds spend.
However, the `GatewayCrossChain` sets the amount of [gasLimit](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L125-L126) only on initialization and there is no setter for it. In comparison, both `GatewaySend` and `GatewayTransferNative` has setters `setGasLimit` 

### Root Cause

Missing setter `setGasLimit` in `GatewayCrossChain`

### Internal Pre-conditions

None

### External Pre-conditions

Dynamic chain conditions.

### Attack Path

- `gasLimit` on initialization is set 1000000, which may not be enough

### Impact

Broken contract functionality

### PoC

_No response_

### Mitigation

Add the setter
