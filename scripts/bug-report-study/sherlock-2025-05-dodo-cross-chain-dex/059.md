# function `GatewayTransferNative::_handleFeeTransfer` would revert if the token used for is ZETA native token

### Summary

function `_handleFeeTransfer` only expect the `zrc20` is a zrc20 implementation contract.
if we use native zeta token for calling the `withdrawToNativeChain` using the `_ETH_ADDRESS_` then `_handleFeeTransfer` would revert because it would try to the fee using zrc20 transfer function where it should be using the native transfer function.

### Root Cause

[GatewayTransferNative.sol#L341-L347](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L341-L347)
```solidity
    function _handleFeeTransfer(
@>        address zrc20,
        uint256 amount
    ) internal returns (uint256 platformFeesForTx) {
        platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
@>        TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
    }
```

here the address provided can be `_ETH_ADDRESS_` which is a placeholder address (not real address). if the function `withdrawToNativeChain` are using this address as zrc20 address param, then when it try to transfer the fee it would revert

### Attack Path

the issue is straightforward
1. user call `withdrawToNativeChain` with param for address using `_ETH_ADDRESS_`  and providing amount in param and via msg.value
2. the line would proceed to fee handling
3. the function revert because the zrc20 transfer would fail as the address are not zrc20 contract

### Impact

break protocol function when handling fee if the function are using native zeta token

### Mitigation

change the following line:

```diff
    function _handleFeeTransfer(
        address zrc20,
        uint256 amount
    ) internal returns (uint256 platformFeesForTx) {
        platformFeesForTx = (amount * feePercent) / 1000; // platformFee = 5 <> 0.5%
-        TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
+       if (zrc20 != _ETH_ADDRESS_) {
+         TransferHelper.safeTransfer(zrc20, EddyTreasurySafe, platformFeesForTx);
+      } else {
+         TransferHelper.safeTransferETH(EddyTreasurySafe, platformFeesForTx);
+      }
    }
```
