# Loss of platform fees in `GatewayTransferNative::onCall`

### Summary

When [`GatewayTransferNative::onCall`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L357) is executed the platform fees is only deducted when `decoded.targetZRC20 == zrc20` leading to the loss of fees whenever that condition is not satisfied, however this should not be the case.

### Root Cause

In [`GatewayTransferNative.sol:370`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370) we can observe that the platform fees is being calculated, however it is not subtracted from the `amount` when `(decoded.targetZRC20 != zrc20)` but goes ahead to swap all the amount + fees and transfers to receiver after. This is an issue because user does not pay platform fees but ends up using platform.

### Internal Pre-conditions

upon execution of `GatewayTransferNative::onCall` require decoded.targetZRC20 != zrc20

### External Pre-conditions

N/A

### Attack Path

* Gateway must call `GatewayTransferNative::onCall`
* Make sure DecodedNativeMessage.targetZRC20 should not be equal to zrc20

### Impact

Whenever this happens the protocol suffers loss of fees 

### PoC

This is a bug because when you look at `GetwayCrossChain.sol::onCall`
```solidity
function onCall(
        MessageContext calldata context,
        address zrc20,
        uint256 amount,
        bytes calldata message
    ) external onlyGateway {
        ...

        // Transfer platform fees
        uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); 
        amount -= platformFeesForTx;

        // Swap on DODO Router
        uint256 outputAmount = _doMixSwap(decoded.swapDataZ, amount, params);

        ...
    }
```
we can see above that the platform fees is being deducted from the amount before the swap on DODO

But in comparison to GetwayTransferNative.sol it is not so when there is a DODO swap involved as we can see below

### Mitigation

Make sure to subtract platform fees from amount before calling `_doMixSwap`
