# ERC20.approve Used Instead of Safe Approvals, Causing Pool Failures with Some ERC20s

### Summary

some ERC20s on some chains don't return a value.
The most popular example is USDT and USDC on the main net, and as the docs mention it should be compatible on EVM chain main net and will support USDT, the current implementation of the approve function does not account for tokens like USDT , Therefore some function will never work.


### Root Cause

The protocol uses approve calls in functions like `_handleERC20Deposit` and `_doMixSwap` , and there is no consideration or error handling for approve calls when interacting with USDT.
