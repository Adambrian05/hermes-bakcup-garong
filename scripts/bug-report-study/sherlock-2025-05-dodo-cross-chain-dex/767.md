# Surplus ETH Not Returned in `depositAndCall`



## Finding description and impact

When `fromIsETH` evaluates to true, the function receives ETH through `msg.value`, and validates that `msg.value >= amount`. However, when `msg.value > amount`, the surplus ETH remains trapped within the contract without acknowledgment.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L229-L236

## Potential impact:

* Users could inadvertently send excess payments and forfeit ETH

This pattern is counterintuitive and may result in user dissatisfaction or potential security risks if funds are improperly managed.

## Mitigation

Implement a refund mechanism for surplus ETH:

```solidity
if (msg.value > amount) {
    payable(msg.sender).transfer(msg.value - amount);
}
```
