# Front-Running Attack Vector in Token Swaps

### Summary

The slippage protection mechanism is vulnerable to sandwich attacks and front-running due to predictable price calculations and fixed slippage parameters.

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L302C4-L336C1  

- Static slippage calculation
- Predictable swap amounts
- No dynamic price adjustment
- Public mempool visibility


### Internal Pre-conditions

- Active UniswapRouter
- Sufficient liquidity
- Valid token pairs
- Positive slippage value


### External Pre-conditions

- Public transaction visibility
- MEV bot activity
- Sufficient block space
- Price oracle functionality

    }
}
