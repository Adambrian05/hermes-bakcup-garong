# Incorrect Refund Claiming Logic

### Summary

The refund claiming logic contains a critical vulnerability that allows unauthorized users to steal funds intended for non-EVM (e.g., Solana) recipients. Here's the detailed analysis and fix:




function claimRefund(bytes32 externalId) external {
    RefundInfo storage refundInfo = refundInfos[externalId];
    // ...
    address receiver = msg.sender;  //  PROBLEM 1: Default receiver is msg.sender
    if(refundInfo.walletAddress.length == 20) {
        receiver = address(uint160(bytes20(refundInfo.walletAddress)));
    }
    require(bots[msg.sender] || msg.sender == receiver, "INVALID_CALLER");
    // ... sends funds to receiver ...
}


Forced Self-Payment for Non-EVM

Non-EVM addresses (length ≠ 20) always set receiver = msg.sender, making msg.sender == receiver always true. This allows ANY user to claim non-EVM refunds.

Incorrect Access Control

The condition bots[msg.sender] || msg.sender == receiver becomes true || true for non-EVM claims, completely bypassing security.





Exploit Scenario
Alice (Solana user) initiates cross-chain swap

Transaction fails, refund stored with Solana address

Attacker calls claimRefund for Alice's refund

Attacker receives Alice's funds on ZetaChain

### Mitigation


function claimRefund(bytes32 externalId) external {
    RefundInfo storage refundInfo = refundInfos[externalId];
    require(refundInfo.externalId != bytes32(0), "REFUND_NOT_EXIST");
    
    if (refundInfo.walletAddress.length == 20) {
        // EVM address refund
        address receiver = address(uint160(bytes20(refundInfo.walletAddress)));
        require(
            bots[msg.sender] || msg.sender == receiver, 
            "INVALID_CALLER_EVM"
        );
        TransferHelper.safeTransfer(refundInfo.token, receiver, refundInfo.amount);
    } else {
        // Non-EVM address refund (Solana/etc)
        require(bots[msg.sender], "ONLY_BOT_ALLOWED");
        TransferHelper.safeTransfer(refundInfo.token, msg.sender, refundInfo.amount);
        
        emit RefundForwarded(
            externalId,
            refundInfo.token,
            refundInfo.amount,
            refundInfo.walletAddress
        );
    }
