# Attacker can directly steal all tokens held by GatewayCrossChain via onCall.

### Summary

Currently, onCall does not check whether the path used in `_doMixSwap` includes the ZRC20 token sent by the current CCTX. This allows users to deceive the gateway by sending a lower-value token while making it appear as if a higher-value token is being used.










### Root Cause

Currently, onCall directly uses the amount for the swap but does not verify that the input token in MixSwapParams matches the received ZRC20 token.


https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L442C1-L510C6

```solidity
    function onCall(
        MessageContext calldata context,
        address zrc20,
        uint256 amount,
        bytes calldata message
    ) external onlyGateway {
        // Decode the message: 32 bytes(externalId) + bytes message
        (bytes32 externalId) = abi.decode(message[0:32], (bytes32)); 
        bytes calldata _message = message[32:];

        // Decode message and decompress swap params
        (DecodedMessage memory decoded, MixSwapParams memory params) = SwapDataHelperLib.decodeMessage(_message);

        // Check if the message is from Bitcoin to Solana
        // address evmWalletAddress = (decoded.dstChainId == BITCOIN_EDDY || decoded.dstChainId == SOLANA_EDDY)
        //     ? context.sender
        //     : address(uint160(bytes20(decoded.receiver)));

        // Transfer platform fees
        uint256 platformFeesForTx = _handleFeeTransfer(zrc20, amount); // platformFee = 5 <> 0.5%
        amount -= platformFeesForTx;

        // Swap on DODO Router
        uint256 outputAmount = _doMixSwap(decoded.swapDataZ, amount, params);

        // Withdraw
        ...
    }
```

This means an attacker can send a modified message to GatewaySend, achieving the following:

- Send `amount` of PEPE.ETH

- In the message, swap `amount` of BTC.BTC (which was never sent) for another token and send it to the attacker.



### Internal Pre-conditions

There are some funds held in `refundInfo` within GatewayCrossChain, such as BTC and SOL.

Or some other tokens are held in GatewayCrossChain.
