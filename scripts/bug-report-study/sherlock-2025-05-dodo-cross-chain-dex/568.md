# GatewaySend.sol is missing check if who targetContract is

### Summary

GatewaySend is missing check who the `targetContract` on Zetachain is, because of that users can deploy their own contract and skip the DoDo fees.

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewaySend.sol#L222C17-L222C31

Missing check if the `targetContract` is `GatewayCrossChain` or `GatewayTransferNative`.

### Internal Pre-conditions

User deploys his own contract with `onCall` on destination and pass it as `targetContract`.

### External Pre-conditions

None

### Attack Path

1. Use the DoDo `GatewaySend`, but with own `targetContract`.
2. Skip the protocol fees.

### Impact

Skip the protocol fees.

### PoC

N/A

### Mitigation

Add a check inside `GatewaySend` who the `targetContract` is.
