# Indiscriminate ETH Transmission in `_doMixSwap`



## Finding description and impact

The `_doMixSwap` function automatically transmits `msg.value` to the `mixSwap` call, irrespective of whether the trading route requires ETH.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L425-L450

If the swap route doesn't require ETH:

* The transmitted ETH could be squandered or trapped
* The external call might fail due to unexpected ETH receipt

This introduces instability in swap execution and risks transaction failures.

## Mitigation

Verify if the route necessitates ETH before transmitting it. Only include `msg.value` when required:

```solidity
bool fromIsETH = (params.fromToken == _ETH_ADDRESS_);
if (fromIsETH) {
    return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(...);
} else {
    return IDODORouteProxy(DODORouteProxy).mixSwap(...);
}
```

This prevents unnecessary ETH transfers and potential failures in non-ETH swap routes.
