# Non-EVM Refund Handling Causes Permanent Fund Loss

### Summary

The [refund](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayCrossChain.sol#L571-L589) mechanism incorrectly handles Bitcoin/Solana withdrawals by Storing non-EVM addresses as raw bytes in refund records,  then attempting to send tokens to EVM addresses during claims, and Allowing arbitrary users to claim non-EVM refunds. This results in permanent loss of user funds when Bitcoin/Solana withdrawals fail. 

### Root Cause

The contract assumes all refund addresses can be treated as EVM addresses.
a. Uses 20-byte check to differentiate address types b. Transfers tokens directly to EVM addresses during claims c. No functionality to process native-chain refunds for non-EVM destinations
```solidity
function claimRefund(bytes32 externalId) external {
        RefundInfo storage refundInfo = refundInfos[externalId];

        address receiver = msg.sender;
        if(refundInfo.walletAddress.length == 20) {   // @>
            receiver = address(uint160(bytes20(refundInfo.walletAddress)));
        }
        require(bots[msg.sender] || msg.sender == receiver, "INVALID_CALLER");
        require(refundInfo.externalId != "", "REFUND_NOT_EXIST");
        
        TransferHelper.safeTransfer(refundInfo.token, receiver, refundInfo.amount);   // @>
        delete refundInfos[externalId];
// @> No functionality to process native-chain refunds for non-EVM destinations
        emit EddyCrossChainRefundClaimed(
            externalId,
            refundInfo.token,
            refundInfo.amount,
            abi.encodePacked(msg.sender)
        );
    }
```

### Internal Pre-conditions

1. Withdrawal failure occurs for Bitcoin (chainId 8332) or Solana (chainId 1399811149)
2. onRevert/onAbort stores refund with raw address bytes (length ≠ 20)
3. refundInfos contains entry with non-EVM address format
4. User attempts to claim refund via claimRefund()

### External Pre-conditions

Cross-chain transaction to Bitcoin/Solana fails

Gateway triggers revert/abort with raw address bytes

Refund record contains non-20-byte address
