# The `abortAddress` is incorrectly set to `address(0)`.


## Summary
The `RevertOptions` parameter's `abortAddress` field was incorrectly configured in the `GatewayCrossChain` and `GatewayTransferNative` contracts.


## Root Cause
The `abortAddress` is the address designated to receive funds if the transaction is aborted. According to the Zeta documentation (https://www.zetachain.com/docs/developers/chains/zetachain/), this scenario is possible.  

One case is when the `amount` is insufficient to cover the `onRevert()` operation on the destination chain.  
Another case is when `onRevert()` execution fails on the Zeta chain, such as when the recipient's address does not comply with EVM rules.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L273

```javascript

```
Therefore, when an aborted situation occurs, Zeta needs to refund the user's funds. However, due to the incorrect setting of `address(0)`, the funds cannot be refunded.


The `GatewayCrossChain` contract has the same issue.
