# Parameter misarrangement in `getPathForTokens` will lead to wrong token path.

### Summary

In `GatewayCrossChain::onCall()` and `GatewayTransferNative::withdrawToNativeChain()` functions respectively, `_handleEvmOrSolanaWithdraw()` function is called which handles windrawals for Evm or solana chains, `_handleEvmOrSolanaWithdraw` function calls  `_swapAndSendERC20Tokens()` which is responsible for handling and calculating the output amount and gas fees in quote token needed for the withdrawal. `_swapAndSendERC20Tokens` further calls `getPathForTokens()`,  this function is responsible for handling:
1. The token path for calculating the amountOut for Input gasToken.
2. The swap path to swap the TargetZRC20 to gasZRC20 using uniswapv2Router1 `swapTokensForExactTokens()`.
The problem stems from  the  `getPathForTokens`. The arguments given to function is not the same as the function's expected parameter, the parameters were interchanged.

### Root Cause

This problem arises from the wrong arguments given to the `getPathForTokens` parameter.

```solidity
function getPathForTokens(
@>        address zrc20,
 @>       address targetZRC20
    ) internal view returns(address[] memory path) {
```

```solidity
.swapTokensForExactTokens(
                gasFee, // Amount of gas token required
                amountInMax,
@>          getPathForTokens(targetZRC20, gasZRC20), // path[0] = targetZRC20, path[1] = gasZRC20
                address(this),
                block.timestamp + MAX_DEADLINE
        );

```
from the two different code snippet provided above,  we can see that `getPathTokens` parameters were interchanged.

### Impact

 when swapping TargetZRC20 to gasZRC20 by calling uniswapv2Router01 `swapTokensForExactTokens` :
```solidity
 uint[] memory amounts = IUniswapV2Router01(UniswapRouter)
            .swapTokensForExactTokens(
                gasFee, // Amount of gas token required
                amountInMax,
            @>>    getPathForTokens(targetZRC20, gasZRC20), // path[0] = targetZRC20, path[1] = gasZRC20
                address(this),
                block.timestamp + MAX_DEADLINE
        );
```
The expected parameter is :
```solidity
 function getPathForTokens(
  @>     address zrc20,
    @>    address targetZRC20
    ) internal view returns(address[] memory path) {
```


If the intention was to swap TargetZRC20 to gasZRC20, this case will be inverted leading to wrong token paths and wrong  prices when calculating `amountsOut` by  subtracting `targetAmount - amounts[0];`
