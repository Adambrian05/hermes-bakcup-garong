# USDT incompatible with IERC20 approve, transferFrom, and transfer

### Summary

USDT on Ethereum is a whitelisted asset on Zetachain: https://www.zetachain.com/docs/developers/tokens/zrc20/#supported-assets

The `GatewaySend.sol` contract will be deployed on Ethereum and contains two instances where `IERC20(asset).approve()` is called, three instances where `IERC20(asset).transferFrom()` is called, and one instance of `IERC20(asset).transfer()`. 

If the ERC20 token being approved / transferred is USDT, the call it will revert because USDT doesn't return a boolean value.

### Root Cause

`IERC20(token).approve()` is incompatible with USDT because the interface expects a boolean returns value:
```solidity
interface IERC20 {
  ...
  function approve(address spender, uint256 value) external returns (bool);
  function transferFrom(address from, address to, uint256 value) external returns (bool);
  function transfer(address to, uint256 value) external returns (bool);
  ...
}
```

However, USDT doesn't return a boolean:
```solidity
function approve(address _spender, uint _value) public onlyPayloadSize(2 * 32) {...}

function transferFrom(address _from, address _to, uint _value) public whenNotPaused {...}

function transfer(address _to, uint _value) public onlyPayloadSize(2 * 32) {...}
```
