# Missing validation of DODO swap output

## Finding description and impact

The `depositAndCall` function calls `_doMixSwap`, which returns the swap `outputAmount`. But this value is never validated.

If the swap fails silently or returns an unexpectedly low amount, the function still proceeds, passing the invalid `outputAmount` to downstream logic.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L245

## Potential impacts:

* Cross-chain transfers or operations using near-zero or zero token value
* Unexpected behavior in downstream contracts expecting valid token amounts
* Loss of user funds if the swap fails or slippage is high

## Mitigation

Check that the returned `outputAmount` is within expected bounds before proceeding:

```solidity
require(outputAmount > 0, "SWAP FAILED: ZERO OUTPUT");
```

Optionally, compare it against the minimum return defined in `params.minReturnAmount` to reinforce slippage protection, depending on how `_doMixSwap` handles it internally.
