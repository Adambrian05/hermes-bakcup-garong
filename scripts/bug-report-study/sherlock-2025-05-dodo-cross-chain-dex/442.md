# Already deployed ZRC20 tokens are incompatible with Gateways

### Summary

Per the audit [docs](https://audits.sherlock.xyz/contests/991?filter=questions)

> Already deployed ZRC20 tokens by the ZetaChain team which can be found [here](https://www.zetachain.com/docs/developers/tokens/zrc20/#supported-assets)

### Root Cause

The problem is that the tokens do not implement the `withdrawGasFeeWithGasLimit()` function and as such the `GatewayCrossChain::_handleEvmOrSolanaWithdraw()` and `GatewayTransferNative::_handleEvmOrSolanaWithdraw()` will revert becuase this function does not exist
