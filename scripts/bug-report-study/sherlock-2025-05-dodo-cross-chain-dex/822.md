# `onCall()` will revert due to use of `transfer()`

### Summary

The [`onCall()`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L370) function uses `transfer()` to send `outputAmount` to the recipient.

### Root Cause

The problem is that the`transfer()` function consumes exactly 2300 gas. the problem is that if as shown below the `evmWalletAddress` is an account abstraction or even safe wallet, more that 2300 gas will be used for the transaction and as such the call will revert preventing the gateway from sending the tokens  to the recipients `evmWalletAddress` causing the funds to be stuck without a way to withdraw
