# Users Will Not Be Able to Deposit Native ETH into the `GatewaySend` Contract

### Summary

The `GatewaySend::depositAndCall` function will not be able to transfer back the native ETH deposited if the transaction reverts in the destination chain and calls the `onRevert` function in the contract. This is because the `safeTransfer` function is not able to transfer native ETH. This failure will happen to all native ETH transactions that are reverted in the destination chain. 

### Root Cause

The `GatewaySend` contract is used to deposit various tokens into the system. The user will call the `depositAndCall` function which will handle different types of deposit such as native ETH, and ERC20. The function also contains [`revertOptions`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L249-L255) which is a ZetaChain feature that triggers when the destination chain reverts. 

The problem with the [`onRevert`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L393-L404) function is that it does not handle native Ethereum refund as shown below: 

```solidity
function onRevert(RevertContext calldata context) external onlyGateway {
        bytes32 externalId = bytes32(context.revertMessage[0:32]);
        address sender = address(uint160(bytes20(context.revertMessage[32:])));
        TransferHelper.safeTransfer(context.asset, sender, context.amount);
        
        emit EddyCrossChainRevert(
            externalId,
            context.asset,
            context.amount,
            sender
        );
    }
```

The function tries to refund the tokens by using `safeTransfer(context.asset, sender, context.amount)`. This will not work for native Ethereum. 

When this reverts, the `onAbort` function is called, but that function also uses the same `safeTransfer` function.

### Attack Path

1. User needs to deposit native ETH. 
2. The transaction needs to fail in the destination chain. 
3. The user will not get their native ETH back due to the transfer failing. 

### Impact

The user will lose all their native ETH they tried to deposit.
