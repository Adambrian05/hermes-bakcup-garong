# Incorrect deadline logic in `GatewayTransferNative::_swapAndSendERC20Tokens`

### Summary

The deadline logic in [`GatewayTransferNative::_swapAndSendERC20Tokens`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L329) does not offer real protection during swaps

### Root Cause

The root cause is the setting of the deadline parameter in[ `GatewayTransferNative.sol::329` ](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L329)to `block.timestamp + MAX_DEADLINE`

### Internal Pre-conditions

NO pre-conditions

### External Pre-conditions

NO pre-conditions

### Attack Path

This will happen anytime `_swapAndSendERC20Tokens` is executed

### Impact

Deadline offers no real protection as the deadline check will always evaluate to true
