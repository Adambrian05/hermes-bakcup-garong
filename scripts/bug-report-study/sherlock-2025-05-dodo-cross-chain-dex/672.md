# Unconstrained DODO Router Trust and Approval Vulnerability

### Summary

The contract gives unlimited approval to a potentially malicious or misconfigured DODO router, risking token loss and system DoS.

### Root Cause

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L337C1-L362C1

### Internal Pre-conditions

- Valid DODO router address set
- Sufficient token balance
- Contract has admin permissions
- No approval limits implemented

### External Pre-conditions

- DODOApprove contract deployed
- Router contract accessible
- Token approvals possible
- Network supports token transfers

### Mitigation

```solidity
contract GatewayCrossChain {
    using SafeERC20 for IERC20;
    
    uint256 public constant MAX_SWAP_AMOUNT = 1000000e18;
    mapping(address => bool) public whitelistedRouters;
    
    function _doMixSwap(
        bytes memory swapData, 
        uint256 amount, 
        MixSwapParams memory params
    ) internal returns (uint256 outputAmount) {
        require(amount <= MAX_SWAP_AMOUNT, "Amount too large");
        require(whitelistedRouters[DODORouteProxy], "Router not trusted");
        
        // Use exact approval amount
        IERC20(params.fromToken).safeApprove(DODOApprove, 0);
        IERC20(params.fromToken).safeApprove(DODOApprove, amount);
        
        try IDODORouteProxy(DODORouteProxy).mixSwap(
            params.fromToken,
            params.toToken,
            params.fromTokenAmount,
            params.expReturnAmount,
            params.minReturnAmount,
            params.mixAdapters,
            params.mixPairs,
            params.assetTo,
            params.directions,
            params.moreInfo,
            params.feeData,
            params.deadline
        ) returns (uint256 result) {
            require(result > 0, "Zero output amount");
            
            // Reset approval
            IERC20(params.fromToken).safeApprove(DODOApprove, 0);
            
            return result;
        } catch {
            // Reset approval on failure
            IERC20(params.fromToken).safeApprove(DODOApprove, 0);
            revert("Swap failed");
        }
    }
    
    function whitelistRouter(address router, bool status) external onlyOwner {
        whitelistedRouters[router] = status;
        emit RouterWhitelistUpdated(router, status);
    }
}
```
