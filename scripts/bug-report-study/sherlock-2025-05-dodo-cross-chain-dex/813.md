# Precision loss in `quote`  function in contract `UniswapV2Library`

In `quote`  function in contract `UniswapV2Library`  while we divide with `reserveA`  it leads to precision loss . 

```solidity
  function quote(uint amountA, uint reserveA, uint reserveB) internal pure returns (uint amountB) {
        require(amountA > 0, 'UniswapV2Library: INSUFFICIENT_AMOUNT');
        require(reserveA > 0 && reserveB > 0, 'UniswapV2Library: INSUFFICIENT_LIQUIDITY');
        amountB = amountA.mul(reserveB) / reserveA; // q precision loss 
    }
```
