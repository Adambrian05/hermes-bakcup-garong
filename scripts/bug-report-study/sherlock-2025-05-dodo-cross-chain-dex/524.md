# `GatewayTransferNative.onCall()` calls `_doMixSwap()` with incorrect amount

### Summary

`GatewayTransferNative.onCall()` does not subtract platformFeesForTx from amount when calling `_doMixSwap()`

### Root Cause

[GatewayTransferNative.sol#L370](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370-L395) 
`onCall()` does not subtract platformFeesForTx from the amount when calling `_doMixSwap()`. When `swapData.length == 0`, this will cause the transaction to fail due to insufficient balance because platformFeesForTx has already been sent to EddyTreasurySafe.

### Mitigation

```diff
-           uint256 outputAmount = _doMixSwap(decoded.swapData, amount, params);
+           uint256 outputAmount = _doMixSwap(decoded.swapData, amount - platformFeesForTx, params);
```
