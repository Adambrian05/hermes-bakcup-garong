# `GatewayTransferNative`.`withdrawToNativeChain` fails `_doMixSwap` when `zrc20 == _ETH_ADDRESS_`

### Summary

`_handleFeeTransfer` deducts fee, so rest native assets must be swapped in `_doMixSwap`.
But `_doMixSwap` sends `msg.value`, this is greater than rest native assets and this reverts.

### Root Cause

`_handleFeeTransfer` deducts fee when [`GatewayTransferNative`.`withdrawToNativeChain`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L551-L552).
[`_doMixSwap`](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L435) sends native assets the amount of `msg.value`. 
```solidity
@>	return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
		params.fromToken,
		params.toToken,
		params.fromTokenAmount,
		params.expReturnAmount,
		params.minReturnAmount,
		params.mixAdapters,
		params.mixPairs,
		params.assetTo,
		params.directions,
		params.moreInfo,
		params.feeData,
		params.deadline
	);
```
But it fails when native assets stored in contract is not enough because fee is deducted.
Or it can cause loss funds to `GatewayTransferNative`.

### Internal Pre-conditions

`zrc20 == _ETH_ADDRESS_`

### External Pre-conditions

.

### Attack Path

.

### Impact

It can cause loss funds to `GatewayTransferNative`.
Or `withdrawToNativeChain` fails.

_No response_

### Mitigation

```diff
-	return IDODORouteProxy(DODORouteProxy).mixSwap{value: msg.value}(
+	return IDODORouteProxy(DODORouteProxy).mixSwap{value: amount}(
		params.fromToken,
		params.toToken,
		params.fromTokenAmount,
		params.expReturnAmount,
		params.minReturnAmount,
		params.mixAdapters,
		params.mixPairs,
		params.assetTo,
		params.directions,
		params.moreInfo,
		params.feeData,
		params.deadline
	);
```
