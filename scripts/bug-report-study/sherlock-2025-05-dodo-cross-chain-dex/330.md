# `GatewayCrossChain::_handleFeeTransfer` comment say only 0.5% fee will be charge, but there is no logic to ensure this

### Summary

`GatewayCrossChain::_handleFeeTransfer` comment say only 0.5% fee will be charge, but there is no logic to ensure this. A malicious admin may change the fee to very high percent to steal user's money.

### Root Cause

In the code, the comment says only 0.5% fee will be charge. But there is no logic to ensure the fee percent is 0.5%.

![Image](https://sherlock-files.ams3.digitaloceanspaces.com/gh-images/660eaa34-3dd6-421b-9b99-bc40e7797144)

The `feePercent` variable only assigned in `setFeePercent` and `initialize`. But both them not ensure the fee percent is 0.5% which is not match with the comment
