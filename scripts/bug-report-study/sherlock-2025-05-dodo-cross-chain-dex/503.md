# No function to accept ownership transfer


## Description
In the protocol the owner is allowed to transfer ownership to new owner if it deems so , However when transfering ownership , No function to accept the ownership transfer would prevent new owner from getting ownership of the protocol.

```solidity

    function setOwner(address _owner) external onlyOwner {
        transferOwnership(_owner);
    }
```
As we can see owner is allowed to transfer ownership of protocol anytime but lacks the critical function to accept the ownership transfer of this call
## Impact
Dos of ownership transfer
## Recommended Mitigation
Add the accept ownership function for the new owner
