# Paying gas fees two times in function `_handleBitcoinWithdraw` in contract `GatewayTransferNative.sol`

## Overview : 

In function `_handleBitcoinWithdraw` in contract `GatewayTransferNative.sol`  we take parameter for amount and gasfees , and call the function withdraw , while calling function withdraw and providing input parameter to it we deduct the gas fees from the amount and let the remaining amount be input for withdraw . 
But withdraw also calls the certain function which then takes the fees from the amount in withdraw function . 

So the user pays the fee two times , first when in start while calling the withdraw function then in withdraw function .

```solidity
  function _handleBitcoinWithdraw(
        bytes32 externalId, 
        DecodedMessage memory decoded, 
        uint256 outputAmount,
        uint256 gasFee
    ) internal {
        if(gasFee >= outputAmount) revert NotEnoughToPayGasFee();
        IZRC20(decoded.targetZRC20).approve(address(gateway), outputAmount + gasFee); // q here i should be outputAmount - gas fees or just output amount 
        withdraw(
            externalId, 
            decoded.receiver, 
            decoded.targetZRC20, 
            outputAmount - gasFee // q this pay gas fee two time  in whole process 
        );
    }
```
