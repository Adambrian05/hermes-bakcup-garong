# Platform Fee Not Deducted from Swap Input Amount in Cross-Chain Token Swaps

### Summary

In GatewayTransferNative.sol, the onCall function which is called by the gateway contract for incoming tokens to zetachain doesn't deduct the protocol fee from the amount if the targetZRC20 isnt the received zrc20. The onCall function in the GatewayTransferNative.sol will be called by the gateway contract when the user requires token to be sent to zetachain from other chain, Chain A -> Zetachain. The parameters sent will be :

      function onCall(
        MessageContext calldata context,
        address zrc20,
        uint256 amount,
        bytes calldata message
    ) external override onlyGateway

After decoding the message :

         (DecodedNativeMessage memory decoded, MixSwapParams memory params) = SwapDataHelperLib.decodeNativeMessage(_message);

There is a check : 

         if (decoded.targetZRC20 == zrc20)

And if the targetZRC20 isnt the zrc20 token being sent currently, it swaps to the targetZRC20. The issue is the `platformFeesForTx` is only being deducted in the if block, when the decoded.targetZRC20 == zrc20. 

### Root Cause

The protocol fee is being deducted in the if block [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L373-L379) , but its missing in the else block [here](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L395-L408) 




### Impact

Protocol loses on fee.

### PoC

- User initiates a cross chain token transfer to zetachain. 
- The targetZRC20 is different than the current zrc20. So it skips the if block which properly deducts the protocol fee from the amount.
- Performs the else block which doesn't deduct the protocol fee from the amount.


### Mitigation

Deduct fee in the else block also.
