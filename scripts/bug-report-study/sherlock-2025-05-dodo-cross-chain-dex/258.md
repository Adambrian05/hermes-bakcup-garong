# `GatewaySend::depositAndCall` function may lock user's ether when `msg.value > amount`

### Summary

`GatewaySend::depositAndCall` function should not receive more ether than the given param `amount`. If a user send more ether and give a small amount, the user's ether will lock in the contract

### Root Cause

The function require `msg.value >= amount`. That not make sense, user should provide ether amount exact the same with the `amount` param. If user made a mistake, provide more ether than passed amount, the ether will lock in the contract.

```diff
    function depositAndCall(
        address fromToken,
        uint256 amount,
        bytes calldata swapData,
        address targetContract,
        address asset,
        uint32 dstChainId,
        bytes calldata payload
    ) public payable {
        globalNonce++;
        bytes32 externalId = _calcExternalId(msg.sender);
        bool fromIsETH = (fromToken == _ETH_ADDRESS_);

        // Handle input token
        if(fromIsETH) {
            require(
-               msg.value >= amount, 
+               msg.value = amount, 
                "INSUFFICIENT AMOUNT: ETH NOT ENOUGH"
            );
        } else {
            require(
                IERC20(fromToken).transferFrom(msg.sender, address(this), amount), 
                "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
            );
        }
```
