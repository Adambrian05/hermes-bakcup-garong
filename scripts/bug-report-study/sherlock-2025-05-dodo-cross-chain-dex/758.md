# `decoded.targetZRC20` Trust Issue Enables Unauthorized Token Withdrawal

### Summary

In `withdrawToNativeChain`, the function assumes that the token returned by `_doMixSwap` matches `decoded.targetZRC20`. However, the swap itself (via `swapData`) determines the actual output token. This unchecked assumption allows an attacker to:

- Trigger a swap that returns low-value or junk tokens.
- Still withdraw high-value tokens (like those reserved from previous users) by setting `decoded.targetZRC20` to a valuable token that the contract holds.

Even worse, if `swapData `is empty (i.e., no actual swap is performed), the function blindly forwards the amount directly as `outputAmount`, blindly assuming the passed `zrc20 == decoded.targetZRC20`.



### Root Cause

The contract:

- Assumes `outputAmount` is in `decoded.targetZRC20`.
- Never checks if the token returned from `_doMixSwap` actually matches `decoded.targetZRC20`.

### Attack Path

**Reserve Setup:** An amount of `token1Z `(a high-value token) is already in the contract (e.g., via `onAbort`).

**Crafted Message:**

- `zrc20 `= `fakeToken` (new token minted by attacker).
- `targetZRC20 `= `token1Z `(valuable token contract holds).
- `swapData `= "" (empty, no swap actually happens).

**Call Function:**

- Attacker mints and approves `fakeToken`.
- Calls `withdrawToNativeChain`(fakeToken, <amount>, message).

**Exploit:**

`amount `is used as `outputAmount`.
`_handleBitcoinWithdraw `or `_handleEvmOrSolanaWithdraw `uses this `outputAmount `in `targetZRC20`, which pulls actual high-value tokens from the contract and sends to attacker.

**Funds Stolen:**
Reserved funds like abort/revert funds are drained.

### Impact

Loss of user funds: Reserved `targetZRC20 `balances meant for `onRevert` or `onAbort` refunds are stolen.

DoS risk: Legit users cannot claim the refunded funds anymore.

### Mitigation

Enforce strict token consistency:
1.  If swapData is empty:
Only allow this if `zrc20 == decoded.targetZRC20`

2. if swapData is not Empty
Only allow this if `swapData.toToken == decoded.targetZRC20`
