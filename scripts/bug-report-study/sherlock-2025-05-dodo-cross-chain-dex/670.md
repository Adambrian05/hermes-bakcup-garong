# _handleFeeTransfer on GatewayTransferNative doesnt handle native case leading to reverts

### Summary

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L341-L347 

in the above function, it asusmes the token is a zrc20 but in https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L530-L551 
the token can also be native zeta, hence the call would attempt to send data to the default native address causiig a revert 

### Root Cause

_handleFeeTransfer does not handle native case
