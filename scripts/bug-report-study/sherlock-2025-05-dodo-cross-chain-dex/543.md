# Extra gasFee approval and public withdraw in `GatewayTransferNative` allows anyone to steal funds from the contract

### Summary

[GatewayTransferNative::withdraw()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286) is public function while the similar universalContract `GatewayCrossChain`, `withdraw()` is [an internal function](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L277-L295)

On the other hand, extra amount of  `gasFee` is approved every time `_handleBitcoinWithdraw` or `_handleEvmOrSolanaWithdraw` is called within `onCall()`.

These two mistakes make abitrary attacker steal funds by simply calling `withdraw()`.

### Root Cause

[GatewayTransferNative::withdraw()](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L286) is public function while the similar universalContract `GatewayCrossChain`, `withdraw()` is [an internal function](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L277-L295)

These two mistakes make abitrary attacker steal funds by simply calling `withdraw()`, it  just needs check the allowance of certain zrc20 token for `GatewayZEVM` is enough and set `sender` as itself, the fund can be withdraw from zeta chain to the other chain to attacker's pocket.

### Internal Pre-conditions

1. visibility of withdraw is public
2. extra gasFee is approved each time the withdraw action starts in `onCall`

### External Pre-conditions

 `onCall` is called, and it starts to withdraw to bitcoin network or withdraw target token which is also gas token in solana or EVM chain

### Attack Path

1. when zeta chain calls `GatewayTransferNative::onCall()`, extra allowance of `gasFee` is still left
2. when enough allowance to `GatewayZEVM` is profitable, the attacker calls `withdraw()` and set input `sender` as its own address.
3. attacker can receive funds on the chain that the relavent zrc20 is burned in zetachain.

### Impact

Funds left due to `onRevert` or `onAbort` can be stealed by anyone. The GatewayTransferNative will loss funds due to this issue.

### PoC

_No response_

### Mitigation

Change the visibility of `withdraw()` from public to internal
