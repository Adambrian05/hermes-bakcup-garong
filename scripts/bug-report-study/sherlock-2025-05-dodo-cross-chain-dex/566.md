# _handleBitcoinWithdraw will fail if targetZRC20 and its gasZRC20 are not equal

### Summary

Just as Solana and Evm tokens (targetZRC) in Zetachain can have different `gasZRC20`, so can the assets in BTC. But `_handleBitcoinWithdraw` always assumes that the `targetZrc` and its `gasZrc` are the same token.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/d4834a468f7dad56b007b4450397289d4f767757/omni-chain-contracts/contracts/GatewayCrossChain.sol#L363-L377

```solidity
function _handleBitcoinWithdraw(
    bytes32 externalId, 
    DecodedMessage memory decoded, 
    uint256 outputAmount,
    uint256 gasFee
) internal {
    if(gasFee >= outputAmount) revert NotEnoughToPayGasFee();
    IZRC20(decoded.targetZRC20).approve(address(gateway), outputAmount + gasFee); <----------
    withdraw(
        externalId, 
        decoded.receiver, 
        decoded.targetZRC20, 
        outputAmount - gasFee
    );
}
```

If the targetZrc have different gasZrc it wont work.

### Root Cause

all Zetachain → Bitcoin tx assume that targetZrc = gasZrc

### Internal Pre-conditions

None

### External Pre-conditions

The targetZrc to have different gasZrc

### Attack Path

None

### Impact

Outbound tx to Bitcoin will not work

### PoC

N/A

### Mitigation

Check the gasZrc token like in the EVM flow.
