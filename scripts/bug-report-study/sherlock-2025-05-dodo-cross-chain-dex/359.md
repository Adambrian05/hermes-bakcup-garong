# `GatewayTransferNative`.`onCall` fails when `decoded.targetZRC20 != zrc20`

### Summary

In `GatewayTransferNative`.`onCall` deducts fee before `_doMixSwap` when `decoded.targetZRC20 != zrc20`.
This causes incorrect approval to `DODORouteProxy` in `_doMixSwap` and it can cause reversion in `_doMixSwap`.

### Root Cause

Before `_doMixSwap`, `onCall` transfers fee, so rest amount is not `amount`. It must be `amount - platformFeesForTx`.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L370
But `_doMixSwap` approved `amount`.
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L434
`amount` is greater than rest amount that fee is deducted.
It can cause failure for swapping.
