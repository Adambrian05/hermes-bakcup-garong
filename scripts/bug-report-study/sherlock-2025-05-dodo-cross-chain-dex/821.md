# Missing Slippage Protection in Cross-Chain Swap Function in `depositAndCall`



## Description

The `depositAndCall` function performs token swaps through the DODO Router without implementing any slippage protection mechanisms. The function calls `_doMixSwap(swapData)` and accepts whatever output amount is returned, regardless of how much it deviates from expected values.

### Vulnerable Code Location
```solidity
// Swap on DODO Router
uint256 outputAmount = _doMixSwap(swapData);
// @audit no slippage control 
```
https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L245

## Impact 
MEV bots can front-run user transactions with large trades to manipulate prices unfavorably leading to loss of user funds.

## Recommendation

Implement slippage protection by adding a minOutputAmount parameter.
