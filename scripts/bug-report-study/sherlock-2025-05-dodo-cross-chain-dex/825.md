# IUniswapV2Router01:swapTokensForExactTokens incompatible with native Zeta

### Summary

During a cross chain swap, when the `decoded.targetZRC20` does not equal the `gasZRC20`, the protocol uses Uniswap to swap into the gas token to pay the gas fee. 

The problem is `IUniswapV2Router01(UniswapRouter).swapTokensForExactTokens()` is only compatible when the path starts with a ZRC20. If we start with native Zeta, the swap will revert.

### Root Cause

`_swapAndSendERC20Tokens` only works when the swap in token is a zrc20, but not when it's native Zeta.
