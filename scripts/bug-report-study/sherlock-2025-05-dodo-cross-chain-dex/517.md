# Use `safeApprove` and `safeTransferFrom` Instead of `approve` and `transferFrom`

### Summary

The following functions across GatewayCrossChain, GatewayTransferNative, and GatewaySend contracts make unsafe use of transfer, transferFrom, or approve:  `_swapAndSendERC20Tokens`,  `_doMixSwap`, `_handleBitcoinWithdraw`, `_handleEvmOrSolanaWithdraw`, ` _handleERC20Deposit`, `depositAndCall`, `onCall` and `withdrawToNativeChain` . 
Tokens that do not comply with the ERC20 specification may return false from transfer and approve functions to indicate failure. The calling contracts do not check these return values, potentially missing failed transfers. USDT is a supported asset on ZetaChain, hence the issue.

### Root Cause

In `GatewayCrossChain`, `GatewayTransferNative`, and `GatewaySend`  the following functions : `_swapAndSendERC20Tokens`, `_doMixSwap`, `_handleBitcoinWithdraw`, `_handleEvmOrSolanaWithdraw`,  `_handleERC20Deposit`, `depositAndCall`, `onCall` and `withdrawToNativeChain`, use `.approve` or `.transferFrom` instead of `safeApprove` , `safeTransfer`, `safeTransferFrom`.
