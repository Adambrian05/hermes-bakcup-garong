# `GatewaySend::depositAndCall` would not work with ERC20 contract that does not return value at transfer

### Summary

the [supported asset](https://www.zetachain.com/docs/developers/tokens/zrc20/#supported-assets) list token like USDT on ETH mainnet which the contract implementation does not return a boolean value at transfer.
while the `GatewaySend` contract use normal IERC20 interface which does not handle such case, making the require line revert.

### Root Cause

[GatewaySend.sol#L317](https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L317)

```solidity
            require(
                IERC20(fromToken).transferFrom(msg.sender, address(this), amount), 
                "INSUFFICIENT AMOUNT: ERC20 TRANSFER FROM FAILED"
            );
        }
```

this require would fail even thought that the transfer is succeed in contract like USDT on ETH mainnet.
