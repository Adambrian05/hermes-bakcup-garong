# Excess ETH not refunded in `depositAndCall`

## Finding description and impact

When `fromIsETH` is true, the function accepts ETH via `msg.value`, and checks that `msg.value >= amount`. But if `msg.value > amount`, the extra ETH is silently held by the contract.

## code snippet: https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L229-L236

## Potential impact:

* Users may accidentally overpay and lose ETH

This behavior is unintuitive and can lead to user complaints or potential vulnerabilities if funds are mishandled.

## Mitigation

Add a refund for excess ETH:

```solidity
if (msg.value > amount) {
    payable(msg.sender).transfer(msg.value - amount);
}
```
