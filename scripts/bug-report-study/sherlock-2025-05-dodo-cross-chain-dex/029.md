# Protocol will lose DODO functionality when approve contract changes for GatewaySend

### Summary

The missing setDODOApprove() function in GatewaySend will cause permanent loss of DODO swap functionality for the protocol as the contract cannot update the DODOApprove address when the external DODO infrastructure changes.

### Root Cause

In `GatewaySend.sol` the contract has a `DODOApprove` state variable that is used for token approvals but lacks a `setDODOApprove()` function to update this address, while other contracts like `GatewayCrossChain` and `GatewayTransferNative` properly implement this setter function.

Other contracts has method to update approve and route proxy address.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayCrossChain.sol#L132-L140

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewayTransferNative.sol#L133-L141

But GatewaySend only has `setDODORouteProxy()` function to update route proxy address.

https://github.com/sherlock-audit/2025-05-dodo-cross-chain-dex/blob/main/omni-chain-contracts/contracts/GatewaySend.sol#L86-L89

### Internal Pre-conditions

N/A

### External Pre-conditions

1. DODO protocol changes their approve contract address

### Attack Path

1. **DODO protocol updates their infrastructure and changes the approve contract address**
2. **Admin attempts to update DODOApprove address in GatewaySend contract**
3. **No setDODOApprove() function exists in GatewaySend, unlike other gateway contracts**
4. **GatewaySend continues using the old DODOApprove address**
5. **All DODO swap operations in GatewaySend fail due to invalid approve contract**
6. **Cross-chain functionality becomes permanently broken for GatewaySend**

### Impact

The protocol suffers permanent loss of DODO swap functionality in GatewaySend when external DODO infrastructure changes. Users cannot perform cross-chain swaps through GatewaySend, breaking core protocol functionality.

_No response_

### Mitigation

Add the missing `setDODOApprove()` function to `GatewaySend` for consistency with other gateway contracts.
