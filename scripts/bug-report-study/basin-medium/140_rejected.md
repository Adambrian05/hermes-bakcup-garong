# Vulnerability details

## Impact

This issue can result in a security vulnerability that allows an attacker to create a collision with the ID generated by the function, potentially compromising the system.


## Proof of Concept
The encodeWellImmutableData function uses abi.encodePacked to concatenate several variables into a single bytes array. However, using more than one dynamic type in abi.encodePacked() can result in a collision due to the way that abi.encodePacked() packs its arguments.

```solidity


    function encodeWellImmutableData(
        address _aquifer,
        IERC20[] memory _tokens,
        Call memory _wellFunction,
        Call[] memory _pumps
    ) internal pure returns (bytes memory immutableData) {
        bytes memory packedPumps;
        for (uint256 i; i < _pumps.length; ++i) {
            packedPumps = abi.encodePacked(
                packedPumps,            // previously packed pumps
                _pumps[i].target,       // pump address
                _pumps[i].data.length,  // pump data length
                _pumps[i].data          // pump data (bytes)
            );
        }
        
        immutableData = abi.encodePacked(
            _aquifer,                   // aquifer address
            _tokens.length,             // number of tokens
            _wellFunction.target,       // well function address
            _wellFunction.data.length,  // well function data length
            _pumps.length,              // number of pumps
            _tokens,                    // tokens array
            _wellFunction.data,         // well function data (bytes)
            packedPumps                 // packed pumps (bytes)
        );
    }
```

## Recommended Mitigation Steps

```solidity

function encodeWellImmutableData(
        address _aquifer,
        IERC20[] memory _tokens,
        Call memory _wellFunction,
        Call[] memory _pumps
    ) internal pure returns (bytes memory immutableData) {
        bytes memory packedPumps;
        for (uint256 i; i < _pumps.length; ++i) {
            packedPumps = abi.encodePacked(
                packedPumps,            // previously packed pumps
                _pumps[i].target,       // pump address
                uint256(_pumps[i].data.length),  // pump data length
                _pumps[i].data          // pump data (bytes)
            );
        }

        immutableData = abi.encode(
            _aquifer,                   // aquifer address
            uint256(_tokens.length),             // number of tokens
            _wellFunction.target,       // well function address
            uint256(_wellFunction.data.length),  // well function data length
            uint256(_pumps.length),              // number of pumps
            _tokens,                    // tokens array
            _wellFunction.data,         // well function data (bytes)
            packedPumps                 // packed pumps (bytes)
        );
    }
```

In this modified version of the function, abi.encode is used instead of abi.encodePacked for concatenating variables that include dynamic types. The length prefix for each dynamic type ensures that collisions do not occur.
